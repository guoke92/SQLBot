## 计划：让局域网其他电脑访问本机 SQLBot

所有服务已绑定 `0.0.0.0`，只需修改 CORS 和前端 API 地址。假设局域网 IP 为 `192.168.1.100`（需要替换为你实际的 IP）。

### 修改 1：`/Users/fanjunwei/Projects/SQLBot/.env`

- **第 4 行** `BACKEND_CORS_ORIGINS` 加入局域网 IP：
  ```
  BACKEND_CORS_ORIGINS="http://localhost,http://localhost:5173,https://localhost,https://localhost:5173,http://192.168.1.100,http://192.168.1.100:5173"
  ```

- **第 34 行** `SERVER_IMAGE_HOST` 改为局域网可访问地址：
  ```
  SERVER_IMAGE_HOST=http://192.168.1.100:8001/images/
  ```

### 修改 2：`/Users/fanjunwei/Projects/SQLBot/frontend/.env.development`

- **第 1 行** API 地址改为局域网 IP：
  ```
  VITE_API_BASE_URL=http://192.168.1.100:8000/api/v1
  ```

### 之后
1. 重启服务：`./sqlbot-dev.sh restart all`
2. 检查 macOS 防火墙是否放行 5173/8000/3000 端口
3. 局域网其他电脑访问 `http://192.168.1.100:5173`
