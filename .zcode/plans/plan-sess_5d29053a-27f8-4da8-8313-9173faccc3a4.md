## 修复 3：`_column_stats` 增加 temporal 分支

### 根因
时间维度字段值如 "2021-08" 是字符串，`float("2021-08")` 失败 → 走 categorical 分支只返回 top-N 频次，没有 min/max。LLM 从频次推断时间范围，把高频月份误当边界。

### 改动

**`backend/apps/chat/graphs/nodes/nlq.py`**：

1. `_column_stats`（lines 352-395）在 numeric 和 categorical 之间增加 temporal 分支：
```python
import re as _re  # 文件顶部已 import re

_TEMPORAL_RE = re.compile(r"^\d{4}[-/]\d{1,2}([-/]\d{1,2})?$")

def _is_temporal_value(s: str) -> bool:
    return bool(_TEMPORAL_RE.match(s.strip()))

# 在 _column_stats 中，numeric 判定前增加 temporal 检测：
def _column_stats(rows, field):
    ...
    values = scan["values"]
    numeric_vals = scan["numeric_vals"]
    ...
    # temporal: string values matching YYYY-MM / YYYY-MM-DD
    str_vals = [str(v).strip() for v in values if v is not None and str(v).strip()]
    if str_vals and not numeric_vals:
        temporal_vals = [v for v in str_vals if _is_temporal_value(v)]
        if temporal_vals and len(temporal_vals) >= len(str_vals) * 0.5:
            temporal_vals.sort()
            stats.update({
                "type": "temporal",
                "min": temporal_vals[0],
                "max": temporal_vals[-1],
            })
            return stats
    # existing numeric / categorical branches...
```

2. `_format_assessment_block`（lines 542-557）增加 temporal 渲染分支：
```python
elif cs.get("type") == "temporal":

        f"{fname}: unique={cs.get('unique')} "
```

### 改动
