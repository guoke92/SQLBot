# pplatform-web 系统业务数据知识包 v3

本目录是面向 AI智能问数运行时的可导入知识包，不是项目文档摘要。每条知识都必须回答至少一个问题：

- 用户说到一个业务概念时，应该定位到哪些表、字段和值；
- 一个业务状态或范围应如何转换为查询条件；
- 表之间应通过什么字段连接；
- 哪类问题已有经过目标数据库验证的查询范式。

## 与 v2 的差异

v2 在尚未连接目标数据库时生成，因此包含空查询、候选关系、泛化治理提醒及若干错误字段解释。v3 基于当前代码和目标库只读画像重新整理，主动删除：

- “代码关系需要验证”等提取过程说明；
- `top_flag` 表示离职风险等缺少代码和数据依据的解释；
- `operation_user` 相关口径（目标库当前无数据）；
- 空 SQL、不可执行 SQL 和仅有题目的“查询示例”；
- 自关联、无法匹配或业务含义不明确的候选关系。

## 内容组成

| 类型 | 数量 | 用途 |
|---|---:|---|
| 术语 | 9 | 业务语言与表、字段、字典值的映射 |
| 查询口径 | 6 | 为明确业务对象补齐稳定过滤条件 |
| 字段关系 | 4 | 代码和数据库画像共同支持的连接关系 |
| 查询示例 | 4 | 已在目标库只读执行通过的 SQL 范式 |

## 导入要求

导入时必须选择已同步 `lowcode_pplatform` 表结构的 pplatform 数据源。知识包不写死 SQLBot 内部数据源 ID，避免不同环境使用错误 ID。

导入状态含义：

- **可发布**：结构、引用和必要验证均通过，可进入对应运行时资产；
- **待审核**：内容可以登记，但仍需要人工确认业务语义；
- **校验失败**：表字段不存在、结构不合法或查询为空，必须修正后重新校验；
- **仅登记**：只保存来源证据，不直接参与运行时召回；v3 不再显式导入此类条目；
- **待发布**：知识已通过审核但尚未发布到运行时资产。

关系类知识即使通过包校验，仍按系统统一规则创建为候选关系，由管理员确认后生效；这不是内容质量失败，而是关系变更的安全门禁。
