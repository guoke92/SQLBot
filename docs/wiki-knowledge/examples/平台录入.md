# 平台录入

业务术语"平台录入"落在物理口径 `cust_build_type = 'AGW_BUILD'`：
企业档案由平台/网关渠道录入创建（源码 CustBuildTypeConstant 注释为权威）。
注意：PC_BUILD 是"客户录入"，不是"平台录入"——159 病例中模型曾混淆。

## 边界（与"认证方式"的裁决）

"平台录入"回答**档案从哪来**（录入渠道），不回答"企业如何完成认证"。
若用户意图是认证渠道，应使用 `identify_style`（见[[identify-style]]）。
混用后果：两种过滤的企业集合不同，统计结果差异显著。
