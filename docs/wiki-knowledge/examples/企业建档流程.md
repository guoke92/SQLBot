# 企业建档流程

企业从创建档案到生效的完整流程。建档渠道由[[cust-build-type|建档录入方式]]决定；
建档后的认证由[[identify-style|认证方式]]决定。只有建档成功且客户状态生效的
企业才算[[有效企业]]。

```ground:process
process: 企业建档流程
entry: 管理端新建企业
stages:
  - stage: 创建建档
    trigger: 管理端保存
    effects:
      - { op: insert, table: cust_company_info, fields: [cust_build_type, cust_build_status] }
    transitions:
      - { from: null, event: 保存, to: CREATED, field: cust_company_info.cust_build_status }
  - stage: 建档校验
    trigger: 提交建档
    effects:
      - { op: update, table: cust_company_info, fields: [cust_build_status] }
    transitions:
      - { from: CREATED, event: 校验通过, to: BUILD_SUCCESS, field: cust_company_info.cust_build_status }
  - stage: 生效
    trigger: 人工或自动审核
    effects:
      - { op: update, table: cust_company_info, fields: [cust_status] }
    transitions:
      - { from: BUILD_SUCCESS, event: 生效, to: EFFECT, field: cust_company_info.cust_status }
```
