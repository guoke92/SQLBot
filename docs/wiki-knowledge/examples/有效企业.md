# 有效企业

"有效企业"是统计口径的默认过滤条件。用户问"企业清单/企业数"而未说明
包含无效企业时，默认采用本口径。时间基准默认按 `create_time`
（档案创建时间），用户提及"认证/审核时间"时改用对应业务时间字段。

```ground:caliber
caliber: 有效企业
field_targets: [cust_company_info.cust_status, cust_company_info.cust_build_status]
predicate: "cust_company_info.data_type = '1' AND cust_company_info.enable = 'Y' AND cust_company_info.cust_build_status = 'BUILD_SUCCESS' AND cust_company_info.cust_status = 'EFFECT'"
scope: global
boundary: 回答"哪些企业有效"；与认证方式/录入方式的选择正交
```
