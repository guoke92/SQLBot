短链是「一条 number 换取一次跳转」的映射凭证。系统内存在两条访问链路，取键方式完全不同：一条按业务编码 number 直查，另一条把 number 当作含校验位的 Base64 串解出主键。讨论短链时必须先说明走的是哪条链路，否则「用 number 还是 id 查」会直接对不上。

## 需求背景

v0 语义分析未提供 reqdoc_claims，本节暂无需求文档主张可锚定。
