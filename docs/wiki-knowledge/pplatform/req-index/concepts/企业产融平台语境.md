# 企业（产融平台语境）

企业是[[chanrong-platform|产融平台]]所有业务操作的执行主体。企业可以关联到[[project-chanrong|项目]]上，在开展业务时按照项目上的配置去跑流程。

## 企业类型

企业按照类型可以分为：

| 企业类型 | 说明 |
|---|---|
| 供应商 | 供应链上游企业 |
| 核心企业 | 供应链核心企业（链主） |
| 资金方 | 金融机构 |
| 区域公司 | 虚拟企业 |
| 项目公司 | 项目关联企业 |
| 运营方 | 平台运营企业 |
| 经销商 | 经销商企业（AMS流转相关） |

## 企业角色

一个企业可以同时拥有多个角色。当企业拥有多个角色时，系统按以下优先级校验：核心企业、资金方、平台运营方 > 核心子公司、供应商。

企业角色的状态分为：
- **未激活**：企业尚未认证成功时展示的角色状态
- **已激活**：企业认证成功后展示的角色状态
- **冻结**：被平台冻结的角色

## 企业状态

企业状态由[[enterprise-authentication|企业认证]]流程决定，包括：初始化、待客户提交、审批中、认证失败、认证成功、退回、冻结、注销。

## 组织机构管理

企业通过组织机构树状展示层级关系：
- 一级节点：未关联父级企业的企业
- n-1级：企业被授权人的部门
- n级：企业被授权人及其创建的联系人

企业认证后组织机构树中即新增一个数据节点，根据"是否归属集团或核心企业"和"是否分公司"确定挂载位置。

## 企业信息维护

客户端的企业信息包括：
- **企业基础信息**：基本信息、账户信息、企业联系人
- **银行账户**：企业银行账号管理，支持小额打款验证
- **企业协议查询**：查看企业签署的所有协议文本
