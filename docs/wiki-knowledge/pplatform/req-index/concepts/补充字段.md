# 补充字段（产融平台语境）

补充字段是[[产融平台]]在[[数据迁移]]过程中为解决各业务系统特殊字段需求而设计的机制。部分企业在特定项目中会有定制化的字段（如"工行供应链编号"），这些字段原先由各业务系统自行管理，迁移后需要在产融平台上统一承接。

## 背景

不同业务系统存在各自特有的企业信息字段：
- 线上保理有展示特殊字段的页面
- 多级流转有20多个补充字段（已完成梳理）

迁移后，这些字段需要在产融平台上统一实现，以确保业务系统可以从产融侧获取其所需的字段。

## 实现思路

### 第一步：租户配置层面配置

在[[配置中心]]的租户配置-产品配置层面，配置该租户有哪些补充字段，并标记哪些字段需要在客户端建档流程中填写。

### 第二步：内管端展示和编辑

内管端企业信息-补充字段会展示出所有补充字段：
- 所有字段客户端都可以编辑
- 如客户端有填写，则反显出来值
- 内管端也可以修改

### 第三步：与业务系统对接

补充字段的使用需要和业务系统之间跑通，业务系统可以从产融侧拿到其需求的字段。

## 使用场景

- 当企业为金融机构时，新增"金融机构身份标识"字段（必填，下拉枚举，选择银行大类）
- 部分企业在特定项目中的定制化字段（如工行供应链编号），在企业信息中增加该字段（非必填）
- 简易建档支持录入银行账号（供应商、金融机构角色下为必填，其他角色为非必填）
