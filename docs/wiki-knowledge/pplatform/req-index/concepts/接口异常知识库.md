# 接口异常知识库

## 概述

接口异常知识库是产融平台V1.30版本的产品优化需求，管理接口异常信息并在前端以用户友好的方式展示报错详情，旨在提升问题排查效率和用户体验。

## 需求详情

具体业务规则详见外部文档（doc.linklogis.com），由产品经理[[顾亚芳]]负责。

## 设计目标

- 建立接口异常信息的管理机制
- 在前端实现报错信息的可视化展示
- 提升运营和开发人员的问题排查效率
- 改善用户遇到接口异常时的体验
