# 贴牌建档流程定制化

## 定义

贴牌建档流程定制化是指不同贴牌（租户）在供应商建档环节存在差异化的业务规则和流程，需在[[产融平台]]统一框架下实现。这是产融平台作为多租户SaaS平台面临的核心挑战之一。

## V1.18版本中的体现

V1.18版本是贴牌建档流程定制化的集中体现版本，涉及8个贴牌的迁移适配：

| 贴牌 | 状态 | 主要定制化内容 |
|------|------|--------------|
| [[山东高速]] | 不做升级 | 小程序建档渠道、客商主数据对接、登录页定制 |
| [[宏胜云链]] | 不做升级 | 白名单查询接口、商圈信息保存接口 |
| [[怡亚通]] | 需改造 | 多级流转标准建档接口、非自主建档功能 |
| [[天合光能]] | 需改造 | 单独建档渠道、跳过短信/人脸验证、单点登录 |
| [[环球易链]] | 需改造 | H5建档提示文案、资金方数据隔离 |
| [[融易富]] | 无需改造 | 经核实实际未完成接口对接 |
| [[赢链]] | 需改造 | 企业信息查询接口 |
| [[深天马]] | 需改造 | 供应商建档接口对接 |

## 定制化模式分类

1. **渠道号定制**：不同贴牌使用不同的建档渠道号（如山东高速 `operation-wec-common-sdhs`、天合光能 `operation-wec-reg-trinasolar`）。
2. **流程定制**：部分贴牌跳过短信验证、人脸验证等标准环节（如天合光能建档时）。
3. **接口定制**：对接不同的外部系统接口（如宏胜云链白名单接口、深天马建档接口）。
4. **展示定制**：登录页、门户页、提示文案等UI层面的定制。
5. **数据隔离**：资金方只能关联特定贴牌下的项目（如环球易链）。

## 与标准化的张力

贴牌建档流程定制化与平台标准化目标之间存在持续张力。一方面，平台致力于用通用流程和配置（如租户配置）替代代码级定制（如怡亚通、深天马的门户定制已可通过租户配置实现）；另一方面，天合光能等贴牌仍需独立的建档渠道和特殊流程，表明完全标准化在短期内难以实现。详见[[标准化与定制化张力]]。
