# KA标准化接口支持变更

## 概念定义

KA标准化接口支持变更是指在产融平台已有的核心企业（KA）标准化数据接口基础上，增加对企业信息变更场景的支持能力。此前KA标准化接口仅覆盖企业信息的初始录入和同步，无法处理企业名称、统一社会信用代码等关键信息的后续变更。

## V1.29版本需求背景

该需求由[[中交疏浚]]提出，产品经理为[[周水平]]，列为V1.29版本【高】优先级需求。核心目标是提升KA标准化接口的灵活性，使其能够完整覆盖企业信息全生命周期的管理场景。

## 与标准化接口对接的关系

- [[中交疏浚]]：在已有标准化接口上增加**变更**场景支持（扩展）
- [[中铁四局]]：新建标准化接口对接（初始对接）

两者共同体现了产融平台持续推进与核心企业标准化接口对接的战略方向。
