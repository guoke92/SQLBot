# 用户角色（产融平台语境）

在[[chanrong-platform|产融平台]]中，人员代表[[enterprise-chanrong|企业]]在平台上做操作。根据人员权限可分为两大类型：

## 被授权人（企业管理员）

- 拥有比经办人更多的操作权限
- 可以为企业添加人员（经办人）
- 首次认证成功即成为被授权人
- 被授权人拥有完整的非认证状态下的菜单权限（首页+企业信息）
- 可进行产品开通、企业变更等高级操作

## 经办人

- 仅拥有业务办理相关权限
- 菜单权限受限，仅显示首页
- 未开通产品不可点击开通，提示"仅企业管理员允许开通产品"
- 有办理权限的产品可点击"去办理"
- 无产品角色权限时显示"去办理（置灰）"，提示"请联系企业管理员添加权限"
- 首次签署合同前需补充身份证件并完成人脸识别

## 联系人管理

企业联系人在内管端进行维护，类型包括：

- **企业管理员**：需企业授权书和人脸识别
- **经办人**：无需企业授权书，可由企业管理员创建管理

联系人+企业为一个组合，一个联系人关联多个企业时，各组合的数据和状态需独立，互不影响。

## 关键校验规则

- 企业仅剩1个企业联系人时不允许删除
- 存在在途的企业认证任务、变更任务或待提交申请单时不允许删除联系人
- 删除认证成功的注册认证/邀请认证企业管理员需上传变更确认书

## 角色权限配置

客户端支持自定义角色管理：
- 新增角色时需选择产品类型（单选）
- 同一产品支持分配多个角色
- 支持设置菜单及按钮权限
- 系统可预置部分角色供使用
