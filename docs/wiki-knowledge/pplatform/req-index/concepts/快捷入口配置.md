# 快捷入口配置

## 定义

快捷入口配置是[[产融平台]]V1.8版本新增的功能，允许客户端为用户新增跳转至内部或外部系统的产品入口，以单点登录形式交互。此类产品可以不在产融上配置租户、项目。

## 功能设计

### 入口位置

- 左侧菜单新增【快捷入口配置】
- 配置好的快捷入口展示在"我的产品"区域
- 可切换"我的产品"与"快捷入口"
- 快捷入口下没有开通状态
- 快捷入口配置下为0条数据时，首页不展示快捷入口tab页
- 快捷入口配置下大于1条数据时，展示快捷入口tab页

### 权限模型

- 企业维度配置
- 管理员拥有快捷入口菜单，配置后同企业的经办人都可以看到配置的入口
- 游客状态不可看到配置的入口

### 配置字段

| 字段 | 限制 |
|------|------|
| 名称 | 20个字符 |
| 跳转链接 | 500个字符 |
| 图标 | 1MB，限制仅能上传一个图片，支持jpg、jpeg、png、bmp图片类型 |
| 更新时间 | 系统自动 |

### 操作

- 列表页操作列可编辑、删除
- 右上方有新增按钮
- 点击删除需进行弹窗二次确认
