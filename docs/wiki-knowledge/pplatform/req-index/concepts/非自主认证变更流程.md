# 非自主认证变更流程

非自主认证变更流程描述了在邀请认证和简易认证方式下，企业信息变更和企业管理员变更的完整业务流程。变更流程高度依赖原认证方式，不同认证方式下的变更路径、是否需要运营中台处理存在显著差异。

## 变更类型

### 企业信息变更（11项）

产融平台与运营中台的变更类型映射关系：

| 产融平台 | 运营中台 | 备注 |
| --- | --- | --- |
| 企业信息变更 | 工商信息变更 | |
| 法定代表人变更 | 法定代表人变更 | |
| 法定代表人手机号码变更 | 法人手机号变更 | |
| 法定代表人证件有效期变更 | 法定代表人证件有效期变更 | |
| 总公司企业信息变更 | 总公司工商信息变更 | 总公司时不显示 |
| 总公司法定代表人变更 | 总公司法定代表人变更 | 总公司时不显示 |
| 总公司法定代表人手机号变更 | 总公司法人手机号变更 | 总公司时不显示 |
| 总公司法定代表人证件有效期变更 | 总公司法定代表人证件有效期变更 | 总公司时不显示 |
| 企业授权书 | | 本期运营中台需新增 |
| 增加企业角色 | | 本期运营中台需新增 |
| 重新建档 | | 本期运营中台需新增 |

支持多选，多个变更类型取最大并集进行处理。

### 企业管理员变更（3项）

| 产融平台 | 运营中台 |
| --- | --- |
| 企业管理员变更 | 联系人变更 |
| 企业管理员手机号变更 | 联系人手机号变更 |
| 企业管理员证件有效期变更 | 联系人证件有效期变更 |

## 变更方

变更方指明变更由"平台变更"（运营人员操作）还是"企业自行变更"发起。

| 产融平台 | 运营中台 |
| --- | --- |
| 平台变更 | 客服变更 |
| 企业自行变更 | 客户变更 |

变更方式规则：
- 所选变更类型均支持平台录入、企业自行录入的，两种方式支持选择其一
- 所选变更类型存在仅支持平台录入的或不支持企业自行录入的（例：讯易链核企变更管理员手机号），默认选择平台变更，企业自行变更置灰

## 验证方式

必填，多选，两种验证方式支持同时选择或选择其一。所选变更类型包含"企业管理员变更、企业管理员手机号变更、企业授权书、增加企业角色-核心企业、简易认证-重新建档"时需展示验证方式字段。

| 产融平台 | 运营中台 |
| --- | --- |
| 企业管理员授权 | 被授权人人脸识别 |
| 法定代表人授权 | 法代授权 |

- **企业管理员授权**：若选择需要，平台变更完成企业信息确认时需进行企业管理员授权，企业自行变更过程中需进行企业管理员授权
- **法定代表人授权**：若选择需要，平台变更完成企业信息确认时需进行法代授权，企业自行变更过程中需进行法代授权

## 按认证方式分类的变更流程

### 邀请认证（客户录入/平台录入）

变更需要运营中台处理。变更类型、企业管理员授权、法定代表人授权、企业是否开通CA需要产融平台推送至运营中台，后续变更由运营中台处理。

- **平台变更**：根据所选变更类型进行平台变更，变更完成后对变更企业发送信息确认提醒待办和短信通知。变更企业登录客户端点击待办，根据企业认证方式走相应的信息确认流程，不展示账户信息步骤页。
- **企业自行变更**：对企业发送变更提醒待办和短信通知，根据所选变更类型及企业认证方式走对应的企业信息变更流程，同建档页面。

### 简易认证

企业变更走产融平台页面，是否需要运营中台处理与变更类型有关：

| 变更类型 | 变更方 | 验证方式 | 运营中台处理 | 说明 |
| --- | --- | --- | --- | --- |
| 企业信息变更 | 默认平台变更 | 无需授权 | 需处理数据同步 | |
| 增加企业角色 | 默认平台变更 | 无需授权 | 无需处理 | 自动生效 |
| 企业管理员变更 | 默认平台变更 | 无需授权 | 无需处理 | 自动生效 |
| 企业管理员手机号变更 | 默认平台变更 | 无需授权 | 无需处理 | 自动生效 |
| 企业管理员证件有效期变更 | 默认平台变更 | 无需授权 | 无需处理 | 自动生效 |
| 企业信息变更+增加企业角色 | 默认平台变更 | 无需授权 | 需处理数据同步 | 跳转至简易认证企业信息详情页 |
| 重新建档 | 平台变更/企业自行变更 | 默认需要授权 | 需处理 | 根据变更方走对应建档流程 |

### 简易认证-重新建档

- 统一社会信用代码不支持变更
- 变更方=平台变更：默认走"邀请认证-平台录入"建档流程
- 变更方=企业自行变更：默认走"邀请认证-客户录入"的建档流程，且默认需要企业管理员、法定代表人授权

## 变更任务互斥规则

- 企业联系人变更中，不支持发起企业信息变更，企业信息列表不展示【变更】按钮
- 当前企业信息变更中，企业信息列表不展示【变更】按钮
- 企业信息变更中，不支持发起企业管理员变更，联系人列表不展示【变更】按钮
- 当前企业管理员信息变更中，联系人列表不展示【变更】按钮

## 变更类型校验

简易认证时若同时选中"企业信息变更"和"重新建档"，则进行提示。

## 增加企业角色特殊规则

变更类型包含"增加企业角色"时：
- "选择变更方式"展示"增加企业角色"行，必填，单选
- 已有角色不显示，仅显示待增加的角色
- 变更方默认为"平台变更"，"企业自行变更"置灰不可选择
- 仅新增角色为"核心企业"时，展示验证方式字段
