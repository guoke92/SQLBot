# 非手机号账号登录

## 需求背景

为兼容[[多级流转]]产品下有用户需要使用非手机号码做登录的场景，产融平台需要支持非手机号码作为账号名称登录，并配套邮件通知功能。

## 登录改造

产融登录部分需要做调整，支持以下登录方式：
- 手机号登录
- 账号名称登录
- 手机号+账号名称登录

## 新增用户支持

新增经办人时支持录入账号名称（非手机号）：

- 用户可以选择录入手机号/账号名称/手机号+账号名称
- 一个账号名称仅仅支持对应一个手机号
- 输入账号名称后点击【确定】时，系统需要校验该名称在当前租户下是否已经存在
- 如果已存在，提示"账号名称已被占用，请修改"

## 邮件通知功能

### 场景1：新增经办人通知

企业管理员在新增经办后，因为邮箱为必填，故向经办人员发送邮件提醒：

**标题**：企业添加经办人通知

**正文**：
```
尊敬的用户您好，您已被{xxx（企业名称）}添加为经办人员，请尽快登录平台进行账号激活。
平台网址：{xxx}
用户名称：{xxx}
初始密码：{xxx}
```

### 场景2：非手机号码用户修改密码

点击"忘记密码"后，通过邮件发送验证码：

**标题**：重置用户密码

**正文**：
```
尊敬的用户您好，您正在重置您在{xxx(平台名称)}上账号{xxx（账号名称）}的密码，验证码为{xxx}，10分钟内有效，请在规定时间内使用。
```

### 场景3：验证码登录

非手机号码使用验证码登录时，通过邮件发送验证码：

**标题**：通过验证码登录平台

**正文**：
```
尊敬的用户您好，您正在使用账号{xxx（账号名称）}登录平台{xxx（平台名称）}，验证码为{xxx}，10分钟内有效，请在规定时间内使用。
```
