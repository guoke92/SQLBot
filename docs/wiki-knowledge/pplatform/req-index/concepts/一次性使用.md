# 一次性使用

一次性使用是 [[验证码缓存机制]] 的另一项核心安全保障。它规定缓存的验证码校验结果在成功使用一次后即被删除，从而防止重放攻击。

## 实现方式

在 [[sso-cache-util]] 的 `checkBehaviorCaptchaCache` 方法中，当 [[参数一致性校验]] 通过后，会立即执行 `redisClient.delete(redisKey)` 操作，将对应的缓存条目从 [[redis]] 中删除。

## 安全意义

- **防止重放**：确保同一个验证码校验结果无法被用于多次登录尝试。
- **强制刷新**：用户每次登录都需要进行新的行为验证码校验（或使用刚刚校验成功的新缓存），增加了攻击者的成本。
- **与参数一致性校验协同**：共同构成了缓存复用的安全闭环。
