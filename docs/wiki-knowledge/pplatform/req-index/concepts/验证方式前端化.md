# 验证方式前端化

## 概述

V1.25版本将企业信息及联系人变更时的验证方式从系统硬编码限制改为根据前端页面勾选决定，增加业务流程灵活性。

## 背景

前期因考虑金融机构、核心企业实际建档流程为线下面签，变更场景下系统限制仅能线下签署授权书。近期实际业务诉求有调整，需要支持线上验证方式。

## 业务规则

- **企业信息变更**：验证方式按照前端页面勾选的验证方式进行处理
- **企业联系人变更**：验证方式按照前端页面勾选的验证方式进行处理

不再根据企业类型或建档方式硬编码限制验证方式。
