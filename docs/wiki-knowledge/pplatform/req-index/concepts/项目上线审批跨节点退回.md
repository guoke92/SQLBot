# 项目上线审批跨节点退回

## 概述

项目上线审批跨节点退回是产融平台V1.35版本对现有退回逻辑的重大优化。此前审批退回只能逐级退回，不满足实际业务诉求。本功能支持审批人将流程退回到任意历史业务节点，提升审批灵活性。

## 业务规则

### 退回按钮展示

- 第一个审批节点：不展示【退回】按钮
- 非第一个审批节点：正常展示【退回】按钮

### 退回弹窗优化

新增退回节点选择板块：
- 必填项，下拉框单选
- 无默认值，占位文字："请选择退回节点"
- 枚举值为当前待办节点之前的所有业务节点，倒序展示
- 枚举展示内容：节点对应的流程图中固定的人员名称 + 对应的审批节点

### 退回业务逻辑

- 未选择退回节点就点击【提交】时需提示
- 当前节点可选择任意历史经过的业务节点进行退回
- 跨节点退回审批轨迹展示样式与此前逐级退回展示样式一致
- 被退回的节点人员重新提交时，需逐级再次进行审核，不可跨节点审核
- 无转审人员时退回节点展示

### 适用范围

涉及PC端及H5页面。
