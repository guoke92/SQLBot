# 产品入口统一

产品入口统一是[[产融平台]][[数据迁移]]的两大核心目标之一，指企业不再需要单独登录多个系统开展业务，而是通过产融平台的[[统一门户]]访问所有已开通的产品。

## 目标

- 企业通过一个统一的入口（产融平台）登录后，即可访问其已开通的所有产品（多级流转、订单融资、线上保理、AMS等）
- 简化客户操作，提升用户体验

## 实现方式

### PC端登录入口统一

- 多级流转、订单融资和线上保理在迁移后仍使用原来的域名，但注册和登录入口统一到产融平台
- 存量用户首次登录后（针对当前迁移批次内的用户），页面弹出升级提示
- AMS用户可通过旧域名直接访问产融（调整后的方案）

### 登录后页面展示逻辑

- 如企业对应的[[租户]]下配置了多个产品，默认展示产品中心页面
- 如企业对应的租户下仅配置了1个产品，默认进入该产品的内页
- 新用户登录后进入产融的产品中心页面

### 待办及站内信归集

- 产融平台的待办区域展示产融自身待办和各业务系统待办（按产品维度汇总）
- 立内信统一至页面右上角的"小铃铛"符号处，业务系统原有的小铃铛不再保留

## 与企业认证数据统一的关系

产品入口统一与[[企业认证数据统一]]互为支撑：企业只需认证一次（认证数据统一），即可通过统一入口申请开通和访问多个产品（入口统一）。
