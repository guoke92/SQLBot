# 行为验证码

## 概述

行为验证码是[[产融平台]]V1.3版本引入的安全机制，在发送短信验证码前进行交互式验证，用于防止恶意刷短信。

## 功能描述

在注册时点击"发送验证码"时，先调用行为验证码做一次校验，校验通过之后再触发发送短信。

## 应用场景

- 注册流程中的短信发送环节
- 作为短信发送的前置校验步骤

## 设计目的

- 防止恶意刷短信
- 降低短信发送成本
- 提升系统安全性
