# AMS联系人同步

## 概述

V1.25版本在产融平台与[[AMS]]系统间建立金融机构联系人的同步机制，包括在产融平台新增AMS联系人和从AMS系统拉取联系人两种方式。这是对[[ams建档互通-金融机构|AMS建档互通]]概念的具体落地和优化。

## 背景

AMS迁移产融平台时双方约定金融机构不做迁移，需在AMS系统和产融平台分别建档。实际业务中发现当前逻辑不能满足业务诉求，双方未做到建档互通。

## 功能设计

### 维护AMS联系人

原【新增AMS联系人】按钮调整为【维护AMS联系人|V】按钮组，下拉选择：

1. **新增AMS联系人**：适用于产融平台与AMS系统均无联系人场景。同步增加金融机构类型，放开金融机构限制，与现有项目公司、供应商逻辑一致。
2. **从AMS同步联系人**：适用于AMS系统有联系人但产融平台无联系人的场景。

### 从AMS同步联系人流程

1. 点击【从AMS同步联系人】，展示弹窗，支持选择租户、企业列表、企业角色（默认展示金融机构）
2. 点击"从AMS查询"，支持输入姓名、手机号进行AMS联系人查询及多选
3. 已添加过的联系人在查询弹窗中置灰不可选择
4. 确认后产融平台企业联系人列表新增所选联系人，联系人类型为经办人

### 企业建档相关

- 授权书：平台录入、简易认证开通电子签章=是时，企业授权及确认书调整为必填
- 产融平台需同步AMS系统电子签章开通结果（金融机构、项目公司、供应商）
- AMS接收产融平台同步的金融机构建档信息，AMS侧需自行限制同步的管理员不发起建档流程
- 建档中金融机构支持跳转AMS

### 历史数据处理

AMS系统将存量在产融平台贴牌下建档成功的金融机构数据（企业信息及联系人信息）迁移至产融平台。

**限制**：本期不支持在途数据迁移，不支持自营数据迁移。

### 企业类型映射

产融平台跳转AMS时，AMS将核心企业映射为项目公司。

### 变更场景

考虑实际业务中变更场景较少，本期暂不接入变更。产融平台变更联系人需可正常跳转至AMS系统。

## 渐进性特征

虽然解决了联系人同步问题，但明确"本期暂不接入变更"，且历史数据迁移存在限制（不支持在途数据迁移、不支持自营数据迁移），表明集成仍是渐进式的，存在业务场景覆盖缺口。AMS变更场景计划在后续版本接入。
