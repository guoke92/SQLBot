# 游客处理

## 问题背景

产融平台为开放式的注册和认证，游客可以使用任意一个企业发起注册。当前系统存在以下问题：

- 一旦游客关联了某个企业，内管不可以再新增该企业
- 不可以为企业新增真实的管理员
- 只能引导真实的管理员也去操作自主注册并发起认证
- 当某个贴牌不支持自主注册时，流程就会被阻塞住

## 解决方案

### 方案1：游客类用户查询

在"企业中心"下新增二级菜单"游客类用户查询"：

- 该表中的企业及用户数据与"企业信息维护"表和"企业联系人维护"表中的数据**隔离**
- 当游客真实拉起了某个企业的建档审核任务时，企业和用户数据才会进入正式表
- 游客才转化成了企业的管理员
- 即使游客关联了某个企业，也不影响内管在"企业信息维护"菜单下去新增该企业

### 方案2：内管编辑功能

针对游客自主关联的企业且企业暂未拉起运营中台的建档流程：

- 内管可以进行编辑，新增真实的管理员
- 原来的游客还不能被赋予管理员的身份
- 点击编辑后，企业信息进入可编辑状态
- "统一社会信用代码"字段不可修改，其他信息都可以修改
- 企业管理员信息处显示为空
- 填写完企业信息点击提交后，仍会触发邀请短信给到新增的企业管理员

### 联系人类型枚举

"联系人类型"增加"游客"枚举：
- 仅仅关联了该企业的用户：类型为"游客"
- 自主发起了企业认证的用户：类型为"管理员"
- 内管新增的企业管理员：类型为"管理员"

## 用户场景

### 场景1：游客占位

**前置操作**：游客A自主注册且关联了某个企业a

**客户端表现**：
- 游客A见到的企业建档状态是"未认证"
- 游客B也可以再关联企业a，见到的企业建档状态也是"未认证"

**内管端表现**：
- 内管"企业信息维护"列表可以见到该企业a
- 游客A的身份为"管理员"

**进一步操作**：
- 内管需要先对企业a操作[[终止认证]]
- 企业状态翻转为"认证失败"
- 再点击"编辑"，添加管理员C

**最终状态**：
- 游客A/B的身份变为"游客"
- C的身份变为"管理员"
- 管理员C可以正常操作企业认证
- 游客A/B点击认证时会引导上传营业执照，不允许重复发起认证流程

### 场景2：退回长时间不处理

**前置操作**：用户A发起了针对企业a的建档流程，运营中台审核退回至A，A长久不做处理

**客户端表现**：
- 用户A登录平台，见到的企业建档状态是"认证中"
- 游客B可以通过自主认证关联企业a，见到的企业状态是"未认证"
- 点击认证时，平台会提示引导上传营业执照

**进一步操作**：同场景1

## 最终决策

经过需求评审决议，需求第10节（游客处理）和第11节（[[终止认证]]）都采用方案2（内管编辑功能）。
