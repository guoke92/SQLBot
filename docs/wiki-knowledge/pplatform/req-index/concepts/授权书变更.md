# 授权书变更

## 需求背景

原实现中授权书的变更逻辑存在瑕疵，需要将授权书的变更移动到联系人维度进行管理。

## 变更维度调整

- **原实现**：授权书变更在企业维度
- **新实现**：授权书变更调整到企业人员（联系人）维度

## 授权书新旧判断逻辑

### 存量迁移企业

根据其建档时的渠道号来判断：
- 如果是新的自动化建档的渠道 → 新版授权书
- 其他 → 旧版授权书

### 内管变更授权书

根据变更的时间来判断：
- 变更时间早于企业迁移至产融的时间 → 旧版授权书
- 变更时间晚于企业迁移至产融的时间 → 新版授权书

## 与新产品开通的关系

当用户去开通新的产品时，会根据其授权书的新旧来判断是否要再拉起一个补签授权书的流程。

## 与补签授权书的关系

当企业拥有不同角色时，可以为各角色指定不同的企业管理员，每个企业管理员都需要出具【人】维度的企业授权书。当新的管理员登录产融客户端，点击业务系统的产品小卡片入口，系统如校验到该人员名下无授权书，则会触发进入补签授权书的流程（引用运营中台的页面）。

## 特殊情况

当企业角色=供应商/经销商/项目公司时，企业授权及确认书字段不显示。对于这类角色，在产融侧新增角色后立即就会生效。
