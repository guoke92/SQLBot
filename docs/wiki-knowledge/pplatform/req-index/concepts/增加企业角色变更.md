# 增加企业角色变更

## 概述

增加企业角色变更是产融平台14类变更类型中的第14类，指企业在已有角色基础上新增其他企业角色的操作。该变更的关键特点是：**新增核心企业角色需走授权书流程，新增其他角色自动生效**。

## 变更规则

### 变更发起方式

- 仅支持**运营中台录入**
- 不支持企业自行发起

### 角色类型决定流程

| 新增角色类型 | 流程 | 后置流程 | 是否需审核 |
|-------------|------|---------|----------|
| 核心企业 | 走变更企业授权书流程 | 审核通过后客户确认信息 | 是 |
| 资金方 | 自动生效 | 无 | 是 |
| 供应商/经销商 | 自动生效 | 无 | 是 |
| 项目公司 | 自动生效 | 无 | 是 |
| 区域公司 | 自动生效 | 无 | 是 |

### 按认证方式的差异

**邀请认证（客户录入/平台录入）**：
- 核心企业角色：走变更企业授权书流程，审核通过后客户确认信息
- 其他角色：自动生效

**简易认证**：
- 新增角色后即生效
- 无需审核

## 典型场景

1. **原供应商/经销商角色增加核心企业角色**：需法人面签授权书，内管发起提交面签材料，审核通过后客户确认信息
2. **原核心企业角色增加供应商角色**：内管发起并提交，自动通过
3. **原项目公司角色增加供应商角色**：根据是否已开通CA决定流程
