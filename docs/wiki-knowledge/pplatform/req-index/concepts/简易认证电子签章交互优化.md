# 简易认证电子签章交互优化

简易认证电子签章交互优化是产融平台中关于企业简易认证流程的功能，涉及多个版本的改进和调整。

## V1.10版本交互缺陷修复

### 问题描述
V1.10版本修复的一个客户端交互缺陷。问题复现步骤：

1. 后台新增简易认证企业，选择不开通电子签章
2. 客户登录客户端确认企业信息
3. 人脸认证失败，联系运营后台人工改为"人工认证通过"
4. 客户端点击"刷新结果"按钮 → 再次变为"自动认证不通过"（错误行为）

### 预期行为
后台人工翻转为"人工认证通过"后，客户端再次点击"刷新结果"按钮应得到认证通过提示，关闭弹窗后点击确认可正常提交。

## V1.26版本限制性调整

在[[4-需求文档--18-产融平台v126版本需求文档0129--eyrepd|产融平台V1.26版本]]中，对该功能进行了限制性调整：当企业通过简易认证方式发起企业信息变更时，“开通电子签章”字段将被置灰，不可编辑。这进一步明确了在该认证方式下对电子签章状态的管理规则。
