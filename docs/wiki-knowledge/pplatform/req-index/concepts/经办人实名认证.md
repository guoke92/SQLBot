# 经办人实名认证

## 概述

经办人实名认证是产融平台V1.6版本新增的安全与风控功能，要求经办人首次登录产融客户端时完成身份验证。该功能为通用功能，适用于所有产品的经办人。

## 触发条件

- 经办人**首次登录**产融客户端时弹窗要求实名认证
- 仅针对维护了**手机号**的经办人触发；仅维护账号名称（未维护手机号）的经办人不触发
- 存量迁移过来的用户**不需要**验证，仅迁移之后在产融平台新增的经办人需要验证

## 认证流程

1. 弹窗要求实名认证
2. 上传身份证正反面（支持OCR自动识别）
3. 点击"确定"后校验手机号是否实名认证
4. 认证通过：提示"实名认证成功"，可前往办理业务
5. 认证失败：提示"实名认证失败，请联系企业管理员重新添加本人实名认证的手机号"

## 关键规则

- **证件限制**：经办人先只支持身份证
- **阻断机制**：实名验证不通过会卡住流程，每次登录都会再次弹出认证窗口
- **结果同步**：验证结果需要推送给 [[ams]]

## 待确定事项

- AMS系统中展示验证结果的具体位置待产品确认
- 企业联系人列表需增加"实名验证结果"字段，枚举值待开发提供

## 与企业认证的关系

经办人实名认证是 [[企业认证]] 体系的补充环节。企业认证关注企业主体的资质验证，而经办人实名认证关注具体操作人员的身份真实性，两者共同构成产融平台的身份验证体系。
