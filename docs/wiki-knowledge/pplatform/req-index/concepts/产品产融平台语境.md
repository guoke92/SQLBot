# 产品（产融平台语境）

在[[chanrong-platform|产融平台]]中，产品是[[tenant|租户]]层定义的基本业务单元。租户可定义要向终端用户提供什么产品，产品只能从联易融的产融底座已上架产品列表中选择。

## 可选产品

目前产融底座已上架的产品包括：
- [[multi-level-factoring|多级流转]]
- [[ams|AMS]]
- [[online-factoring|线上保理]]
- 场景数据产品

## 产品配置

通过产品配置功能可将产品上架到平台，维护产品的要素及介绍材料。V1.0版本不开放内管端自由新增产品，采取后台初始化方式。

### 产品字段定义

| 字段名称 | 格式 | 长度要求 |
|---|---|---|
| 产品名称 | 文本 | 最多10个汉字 |
| 产品类型 | 枚举 | 强确权、弱确权、信用类 |
| 产品概述 | 文本 | 最多50个汉字 |
| 产品详细描述 | 文本 | 最多200个汉字 |
| 客户群体 | 文本 | 最多50个汉字 |
| 融资期限上限 | 枚举 | 6个月、12个月、18个月、24个月、36个月、不限 |
| 融资金额上限 | 数值（万元） | - |
| 增信措施 | 枚举 | 担保、抵质押、保证金 |
| 交易结构 | 图片 | 仅1张 |
| 产品状态 | 枚举 | 待生效、已生效 |

### 产品状态流转

产品状态仅支持单向流转：
- **待生效** → **已生效**：操作员点击"生效"按钮并确认后生效
- 产品一旦被生效后，"产品名称"和"产品类型"不再可编辑

## 产品开通

企业开通产品后，其终端用户可使用该产品的业务功能。产品开通与[[enterprise-authentication|企业认证]]状态、授权书版本等密切相关。详见产品中心状态逻辑。

## 产品互引

产品间可互相引流，是产融平台"扎下去"价值主张的重要组成部分，支持客户营销做广、做深。
