# 租户配置查看

## 定义

租户配置查看是产融平台V1.20版本新增的功能，允许用户以只读方式查看租户（客户）的详细配置信息，包括基础信息配置、注册配置和产品配置三个步骤。该功能旨在避免在编辑状态下查看配置时可能出现的误操作，同时支持不同权限用户查看配置内容。

## 功能设计

### 入口与导航

- 租户配置列表页中，"租户名称"字段为蓝色文字链接，点击后进入查看页面。
- 按照步骤条样式展示三个阶段：基础信息配置 → 注册配置 → 产品配置。
- 表头显示"←查看租户配置"，点击"←"返回租户配置列表页。

### 各步骤内容

1. **基础信息配置**：即"租户配置-基础信息配置"模块的只读样式，图片文件类型的字段支持预览（如网站logo）。
2. **注册配置**：即"租户配置-注册配置"模块的只读样式，文件类型的字段支持预览（如授权书协议、用户协议等）。
3. **产品配置**：即"租户配置-产品配置"模块的只读样式，操作列不显示按钮。已开通的产品名称为蓝色文字链接，点击后展示产品详情页的只读样式。多级流转产品的更多配置不支持从产融平台入口跳转查看。

### 底部按钮

- 首页（基础信息配置）：【返回】、【下一步】
- 中间页（注册配置）：【上一步】、【下一步】
- 末页（产品配置）：【返回】、【上一步】
- 【返回】时均返回至租户配置列表页。

### 权限设计

本期租户配置列表权限细化到按钮级别（包括顶部按钮和操作列按钮），其他页面后续均需优化到按钮级别。

## 与现有概念的关系

- 与[[租户配置暂存]]相关：租户配置暂存处理的是配置编辑过程中的暂存逻辑，而租户配置查看提供的是只读查看能力，两者互补。
- 合同文件模板支持预览功能。

## 版本历史

- **V1.20**：首次引入租户配置查看功能。
