# 额度管理

额度管理是[[产融平台]]V1.21版本新增的功能模块，用于对客户融资额度进行配置、查询和管理。

## 背景

额度管理作为独立的功能模块在V1.21版本中首次引入，由产品经理[[余蔷]]负责。具体的功能定义、字段设计和业务流程详见外部文档《额度管理模块V1.0》。

## 待明确事项

- 额度管理模块的具体功能范围和字段定义
- 与现有产品（多级流转、线上保理等）的额度关联逻辑
- 额度管理与运营中台的对接方式
- 额度审批流程和权限控制
