# 租户配置增加短信签名展示

## 概念定义

在产融平台内管端的"租户管理"列表页新增"短信签名"字段，直接展示各贴牌维护的短信签名信息，方便运营人员进行短信报备时快速查询。

## 需求背景

贴牌短信时常出现不稳定或短信模板更新后需要重新报备的情况。报备过程中，相同短信模板存在不同短信签名均需逐一报备，运营人员需要频繁查找各租户的短信签名信息，效率较低。

## 业务规则

- 在"租户管理"列表页增加"短信签名"字段
- 取值逻辑：短信模板处该贴牌维护的短信签名
- **导出**文件需一并增加该字段
- 存量贴牌需同步新增该字段数据
