# 企业关联项目配置

## 需求背景

针对[[多级流转]]的运营反馈需求，优化企业关联项目配置的交互，避免运营侧漏配，减少沟通成本。

## 优化内容

### 1. 新增企业后引导配置

新增企业后立马引导进行企业关联项目配置：

- 如果新增企业时关联的是多级流转的项目，在点击最后一步的【提交】拉起[[运营中台]]的建档流程时
- 同时在页面上增加一个操作按钮【前往项目关联配置】
- 该按钮为更突出的蓝色，【关闭页面】按钮为白色
- 引导操作者需要完成企业维度的关联项目配置

点击【取消】：返回"企业信息维护"的列表页

点击【确认前往】：打开企业关联项目配置页面（与手工点击"前往关联项目配置"按钮看到的是同一个页面）

### 2. 按角色维度解绑

企业解绑项目可以按照角色维度去解绑：

- **原逻辑**：将一个角色与某项目解绑，另外一个角色也会跟着被解绑掉
- **新逻辑**：角色可以一个一个去解绑，不存在相互间的影响关系

## 与建档派单的关系

企业关联项目配置是[[企业建档派单]]流程中的重要环节。在建档完成后，运营人员需要将企业与具体的项目进行关联，以便企业能够在正确的项目下开展业务。

## 项目码录入

对于建档完成的供应商/经销商，当建档完成之后，出现【录入项目码】的按钮：
- 该按钮一直显示在页面上，不用消失
- 用途是系统可基于客户录入的项目码自动关联企业和项目
- 当有多个项目时，用户可以操作多次
