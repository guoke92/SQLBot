# 租户间关联

## 概述

租户间关联是[[产融平台]]内建立不同[[租户]]（贴牌）之间的父子或关联关系的功能，使主租户能查看关联租户。该功能最初在V1.14版本引入，主要用于迁移和保留[[湖北联投]]复杂的"贴中贴"业务结构。

## 配置方式

在【租户配置-基础信息配置-基础配置】模块中，新增"**主定制项目标识（中文）**"字段：

- **字段属性**：非必填，下拉选格式
- **枚举值**：湖北联投
- **悬浮提示**：仅限湖北联投多租户项目使用，其他项目请勿使用

## 关联关系逻辑

选择主定制项目标识后，即与主定制项目标识租户建立关联关系。具体逻辑沿用[[讯易链]]现有规则：

1. **数据可见性**：主定制项目标识租户可看到所属全部关联该租户的其他租户
2. **门户页/登录页**：当主定制项目标识(中文)=湖北联投时，隐藏登录入口
3. **单点登录**：产融平台针对关联贴牌配置单点登录，与湖北联投本地化平台实现单点登录及企业建档互通
4. **退出登录**：退出登录按钮隐藏

## 历史数据迁移

讯易链侧"湖北联投"贴中贴项目已配置主定制项目标识（中文），迁移产融平台时需同步迁移该逻辑。

## 湖北联投贴中贴清单

襄链通、罗田云链、楚堰通、江汉云链、联链通(AMS)、铜都云链、应融通、利好融、邕链通、第五师供销社农业社会化服务平台，均为湖北联投贴中贴平台，均从湖北联投本地化单点登录，与讯易链平台做建档互通。

## 与其他概念的关系

- 本功能是[[门户登录页定制化]]的基础，贴中贴租户的登录入口隐藏依赖于此关联关系
- 与[[租户]]概念密切相关，是租户配置能力的扩展
- 从[[讯易链]]迁移而来，保留了原有业务逻辑
