# 法人签章开通

## 概述

法人签章开通是[[产融平台]]V1.3版本为特定融资产品（中行订单融资）支持的电子签章能力开通流程。

## 需求背景

订单融资-中行发起融资时需要使用法人签章。目前[[讯易链]]实现的方式是单独设置了一个法人签署授权书和开通CA的流程，支持客户端触发和内管触发。

## 功能描述

- 支持客户端触发和内管触发两种方式
- 内管触发方案参考讯易链的文档管理平台
- 涉及法人签署授权书和开通CA的流程

## 与其他概念的关系

- 与[[讯易链]]的现有实现方案相关
- 是特定融资产品（中行订单融资）的前置能力
