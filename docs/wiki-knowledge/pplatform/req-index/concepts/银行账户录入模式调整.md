# 银行账户录入模式调整

## 概述

V1.25版本针对平台录入（非自主）建档模式下银行账户信息的录入责任进行调整，将银行账户信息的录入从内管运营人员转移至客户端客户自行维护，以减少信息传递错误和误操作。

## 背景

业务侧反馈核企&供应商非自主建档（平台录入）模式下，银行账号信息由内管运营人员录入，存在信息传递错误或误操作影响后续业务开展。结合实际业务及友商处理方式，提出此优化。

## 业务规则

### 产融平台侧

- 平台录入建档模式下，取消"③账户信息"模块，不区分企业类型
- 企业信息变更-增加企业角色录入银行账户处保留（考虑变更时涉及银行账户的影响）

### 运营中台侧

- 平台录入建档模式下，客户认证页面录入银行账户信息调整为**必填**
- 账号类型与现有保持一致

## 影响范围

仅影响平台录入（非自主）建档模式，自主建档模式不受影响。
