# 企业信息同步业务系统

企业信息同步业务系统是[[4-需求文档--18-产融平台v126版本需求文档0129--eyrepd|产融平台V1.26版本]]中提出的核心功能，旨在解决前期因资源问题未完全实现的数据打通问题，以支持下游业务系统的数据权限需求。

## 业务背景
前期集团成员单位管理和企业组织架构功能已上线，但未将运营方（集团成员）的企业信息同步至已开通的业务系统。随着各业务系统接入集团公司角色，并产生数据权限需求，需要在本版本补充实现信息同步功能。

## 核心规则
1. **存量同步**：系统上线前，需将存量运营方的信息推送至其已开通产品的所有业务系统（如[[多级流转]]、[[线上保理]]、[[订单融资]]等）。
2. **增量同步**：后续当为运营方开通新产品时，系统需增加将该运营方信息推送至对应新业务系统的动作。

## 关联功能
该功能是[[运营方管理]]模块的一部分，其推送的企业信息将为业务系统中的权限管理（如数据可见性）提供基础。
