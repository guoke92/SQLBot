# 租户配置更新人分离

## 概述

租户配置更新人分离是产融平台V1.30版本的产品优化需求，将"租户配置"与"租户运营配置"的更新人、更新时间记录独立，避免相互覆盖，解决数据责任归属不清的问题。

## 背景

目前租户配置与租户运营配置共用一个数据表，导致任意一方更新配置，另一方更新人同步更新。但实际业务中这两个模块由不同部门同事负责，需要保证数据展示正确及方便定位异常问题。

## 优化方案

【租户配置】、【租户运营配置】更新人、更新时间分别记录，以当前操作系统记录为准。两个模块的更新人和更新时间互不影响。
