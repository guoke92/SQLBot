# 变更运营轨迹留痕

## 概述

变更运营轨迹留痕是产融平台V1.28版本新增的功能，在企业联系人维护的【变更运营】弹窗中增加"变更记录"tab页，记录运营人员变更的历史轨迹。该功能与 [[concepts/运营人员取值逻辑优化]] 配合，因运营人员取值逻辑优化后存在系统自动更新运营人员的场景，需要留痕以方便定位和查询。

## 功能设计

### 入口

企业联系人维护列表点击【变更运营】按钮，弹窗包含两部分：
1. **变更运营**：现有逻辑，用于执行运营人员变更操作。
2. **变更记录**：新增tab页，展示变更历史。

### 记录内容

变更记录按时间倒序排列，每条记录包含：
- **时间**：变更成功的时间
- **操作人**：经办人（系统自动更新时显示为"系统"）
- **变更前运营**：变更前的运营人员
- **变更后运营**：变更后的运营人员

### 记录场景

以下操作均需进行记录：
1. 批量变更运营
2. 单笔变更运营
3. 系统自动更新运营（操作人显示为"系统"）
