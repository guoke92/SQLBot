# 组织架构树

## 概述

组织架构树是[[产融平台]]V1.3版本中完善的功能，用于建立和维护企业间的层级关系（集团-总-本），供业务系统在实际业务活动中查询使用。

## 需求背景

利用"组织机构管理"功能建立企业间的层级关系，当实际的业务活动中需要使用该关系时，业务系统可来产融做查询。此前该菜单还未真正实现需求。

## 功能描述

### 左侧树形结构

层级关系为：租户 → 集团公司（如有；可有多级） → 总公司（如有） → 本企业。"核心企业"和"核心企业管理机构"放在一起展示。

### 右侧企业信息表单

表单字段包括：序号、租户名称、企业名称、企业社会信用代码、企业类型、企业角色、父企业名称、创建人、创建时间、操作（仅有"查看详情"按钮）。

**企业类型枚举**：
- **父机构**：当企业存在下一级企业时
- **子机构**：当企业存在上一级企业时
- **单一企业**：既无上级也无下级时

点击"查看详情"跳转企业信息详情页面，如企业未在产融平台上做过建档，则按钮置灰。

### 树形结构新增功能

- 支持为已建档企业做"增加上级"和"增加下级"操作
- 被增加的企业可以是已建档企业，也可以是未建档企业
- 未在系统上建档的企业可以被删除
- 一个企业仅可被增加1个上级企业，可被增加多个下级企业
- 企业架构树需要支持动态渲染

### 动态渲染示例

为A添加上级企业B，为C添加上级企业A，则渲染出 B → A → C 的关系。

## 与其他概念的关系

- 企业建档时"是否归属集团或核心企业"字段调整为必填，选择"是"后集团/核心企业名称为必填
- "是否总公司"字段也调整为必填
- 集团/核心企业名称改为用户手工录入（模糊匹配），可选择企业表中所有企业（不区分建档状态）
- 需要把"集团公司（如有）-总公司（如有）-本企业"的关系记录下来，供组织架构树渲染使用
