# 客户端菜单优化（V1.28）

## 概述

客户端菜单优化是产融平台V1.28版本的产品优化，针对客户端菜单结构和名称进行调整，解决部分菜单内容及名称容易造成歧义的问题。

## 调整内容

### 企业信息

- 【企业信息-企业协议】菜单位置调整至【企业信息-企业基础信息】菜单下，作为新增tab页展示。
- 原企业协议内容不做调整，仅做位置调整。

### 用户中心

- 【用户中心】菜单位置调整至【企业信息】下方。
- 【角色权限配置】菜单名称调整为【角色配置】。
- 【用户角色配置】菜单名称调整为【用户管理】，同时取消tab页。

### 权限分配

- **删除**：原【企业协议】菜单及按钮同步删除。
- **新增**：【企业基础信息】菜单下新增"批量下载、下载"按钮。

## 存量数据处理

1. **菜单权限**：原【企业协议】菜单权限按照【企业基础信息】菜单权限升级。
2. **按钮权限**：原【企业协议】按钮权限按照原配置按钮权限升级。
