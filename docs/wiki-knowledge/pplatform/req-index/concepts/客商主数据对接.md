# 客商主数据对接

## 概述

客商主数据对接是[[山东高速]]贴牌的深度定制化需求，指建档审核通过后，[[产融平台]]与外部客商管理系统（如山东高速的速链云客商系统）同步企业基础数据的集成机制。这是山东高速定制化需求的关键部分。

## 对接流程

### 建档流程及状态

运营中台建档审核通过后，产融平台**不做**常规的建档审核状态更新，而是走以下特殊流程：

1. 运营中台审核通过。
2. 产融平台调用"新增客商申请单"接口（参考接口规范：新增客商申请单（第三方系统到中台）），向速链云客商系统推送企业数据。
3. 等待速链云客商系统处理，并通过"客商申请单状态反馈接口"（参考接口规范：客商申请单状态反馈接口（中台到第三方系统））接收状态反馈。
4. 根据返回结果更新企业状态。

### 接口对接

使用[[讯易链]]现有接口监控功能：

| 配置项 | 值 |
|-------|-----|
| 对接方 | 速链云客商系统 |
| 接口名称 | 新增客商申请单、客商申请单状态反馈 |

接口规范参考：新增客商申请单（第三方系统到中台）、客商申请单状态反馈接口（中台到第三方系统）。

### 定时任务及邮件告警

使用讯易链现有定时任务及邮件告警机制：
- 企业状态=冻结时，无需重推，沿用现有逻辑。

## 设计特点

该对接方案复用了讯易链现有的基础设施（接口监控、定时任务、邮件告警），降低了迁移成本，同时保持了山东高速贴牌的业务连续性。

## 技术实现

- 接口地址详见相关文档。
- 使用讯易链现有接口监控功能。
- 使用讯易链现有定时任务及邮件告警。
