# 企业管理员变更流程优化（V1.17版本）

## 概述

V1.17版本对企业管理员信息变更流程进行了重大改造，核心目标是解决"原管理员联系不上、无法登录系统确认"导致变更流程停滞的业务痛点。改造后支持由**新管理员**进行信息确认，无需旧管理员或法人授权。

## 变更类型

企业管理员信息变更涵盖三种类型，且三者与"企业管理员证件有效期变更、企业授权书"**不能同时勾选**：

1. **企业管理员变更**：更换管理员身份
2. **企业管理员手机号变更**：仅变更管理员手机号
3. **企业管理员邮箱变更**：仅变更管理员邮箱

同时选中多种变更类型时，取变更内容并集展示。变更方由"平台变更"调整为"平台变更（需面签完成）"。

## 两种变更路径

### 平台变更

适用于企业认证方式=平台录入、客户录入、自主注册。

**核心流程**：
1. 产融平台发起变更，录入新的管理员信息
2. 推送变更流程至[[运营中台]]
3. 运营中台审核（不支持修改推送信息，仅支持上传面签材料）
4. 审核通过后触发客户端待办
5. **新管理员**做信息确认，补录人脸识别
6. 无需旧管理员授权或法代授权
7. 客户端完成确认前，运营中台可结束流程，信息不做更新

**消息通知**：短信、邮件、待办发送至新的管理员。

### 企业自行变更

适用于企业认证方式=客户录入、自主注册。

**核心流程**：
1. 产融平台发起变更，录入新管理员信息
2. 推送变更流程至运营中台，同时触发客户端待办
3. **新管理员**确认并更新信息（姓名、手机号不支持修改）
4. 触发法代实名短信验证或人脸识别认证
5. 运营中台审核，通过则更新，拒绝则不更新

## 各变更类型的字段与验证差异

### 企业管理员变更

| 维度 | 平台变更 | 企业自行变更 |
| :--- | :--- | :--- |
| 验证方式 | 企业管理员授权（禁用） | 默认均勾选（禁用） |
| 法代授权选项 | 取消 | 取消 |
| 字段编辑权限 | 全部字段均支持编辑 | 除"证件类型"外均可编辑 |
| 确认人 | 新管理员 | 新管理员（姓名、手机号不可改） |

### 企业管理员手机号变更

| 维度 | 平台变更 | 企业自行变更 |
| :--- | :--- | :--- |
| 验证方式 | 取消 | 法人代表人授权（禁用） |
| 字段编辑权限 | 仅手机号、运营、授权书可编辑 | 仅手机号、运营、授权书可编辑 |
| 校验 | 新旧手机号不能相同 | 新旧手机号不能相同 |
| 确认人 | 新管理员 | 新管理员 |

### 企业管理员邮箱变更

| 维度 | 平台变更 | 企业自行变更 |
| :--- | :--- | :--- |
| 验证方式 | 取消 | 法人代表人授权（禁用） |
| 字段编辑权限 | 仅邮箱、运营、授权书可编辑 | 仅邮箱、运营、授权书可编辑 |
| 校验 | 新旧邮箱不能相同 | 新旧邮箱不能相同 |
| 确认人 | 当前管理员（需企业管理员授权） | 当前管理员 |

## 附加变更

- **企业授权书**：企业认证方式=邀请认证-平台录入时，增加提示文案"认证方式需一事一议，请联系直接上级确认后再发起"。
- **增加企业角色**：企业认证方式=邀请认证-平台录入时，增加提示文案说明不同注册方式下新增角色的认证要求。

## 设计要点

1. **新管理员确认机制**：核心创新点，解决了原管理员失联导致的流程死锁问题。
2. **面签要求**：平台变更路径统一调整为"需面签完成"，增强了变更的安全性。
3. **运营中台协同**：运营中台审核不支持修改推送信息，仅支持上传面签材料，保持了数据来源的一致性。
4. **流程可中断**：客户端完成信息确认前，运营中台可结束流程，信息不做更新，提供了灵活的流程控制。

## 与其他概念的关系

- 本流程与[[企业认证]]密切相关，不同认证方式决定了适用的变更路径。
- 与[[企业管理员邮箱变更]]（V1.8版本）存在演进关系，V1.17版本将邮箱变更纳入了统一的管理员变更框架。
- 与[[简易认证升级建档]]共享管理员信息字段的定义。
