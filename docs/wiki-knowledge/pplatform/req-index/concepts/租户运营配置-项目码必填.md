# 租户运营配置-项目码必填

## 概述

租户运营配置-项目码必填是产融平台V1.28版本在租户运营配置的建档相关配置模块中新增的字段，用于控制客户端自主注册时项目码是否为必填项。该配置从[[entities/讯易链]]运营管理配置迁移至产融平台。

## 配置规则

### 字段定义

- **字段名称**：项目码是否必填
- **位置**：租户运营配置列表-建档相关配置模块
- **必填性**：必填
- **枚举值**：是、否

### 联动规则

"默认关联项目"字段的必填性与"项目码是否必填"联动：
- 项目码必填时：默认关联项目非必填
- 项目码非必填时：默认关联项目必填

### 客户端应用

自主注册页面项目码根据"项目码是否必填"配置展示及校验：

| 配置 | 缺省值 | 校验规则 |
| --- | --- | --- |
| 项目码必填 | "请输入项目码（必填）" | 必填性校验 + 项目码正确性校验 |
| 项目码非必填 | "请输入项目码（非必填）" | 现有逻辑 |

## 存量数据处理

原讯易链运营管理（wec-客服配置-贴牌配置-贴牌自主注册配置）中的"项目专属服务码是否必填"及"默认关联项目"需同步升级至产融平台租户运营配置-建档相关配置。
