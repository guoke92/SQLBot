# 客服名片类型配置调整

## 概述

客服名片类型配置调整是产融平台V1.28版本的运营配置优化，将客服名片类型配置从项目维度调整为租户维度，统一配置逻辑，简化管理。

## 配置变更

### 配置维度调整

| 维度 | 调整前 | 调整后 |
| --- | --- | --- |
| 配置层级 | 项目运营配置 | 租户运营配置 |
| 默认值 | 发送企微名片 | 发送微信名片 |

### 字段定义

- **字段名称**：客服名片类型
- **位置**：租户运营配置
- **必填性**：必填
- **枚举值**：发送企微名片、发送微信名片（默认值）

原项目运营配置中的该字段隐藏，名片发送逻辑需同步调整为按租户维度取值。

## 存量数据处理

从项目维度改为租户维度时，存量数据按以下规则合并：

| 场景 | 处理结果 |
| --- | --- |
| 同一租户下只要有项目配置了"发送微信名片" | 该租户配置为"发送微信名片" |
| 全部项目均未配置名片类型 | 该租户配置为"发送微信名片" |
| 存在部分项目配置"发送企微名片"、部分未配置，或全部配置"发送企微名片" | 该租户配置为"发送企微名片" |

新增项目默认为"发送微信名片"。

## 文档修订说明

本需求在文档评审过程中经历了修订：默认值从"发送企微名片"改为"发送微信名片"。
