# 建档运营名片展示

## 概述

建档运营名片展示是产融平台V1.35版本的运营需求优化。此前建档流程卡点时展示运营经办人员的二维码，当建档量大时运营人员无法及时处理，导致超时等问题。本版本将建档全线接入在线客服，客户有问题时先咨询在线客服，分流运营压力。

## 业务规则

### 配置项

运营配置-项目运营配置-建档运营名称展示。

### 数据同步

产融平台项目运营配置已支持按照项目维度配置讯易链、产融平台建档运营名片展示字段。V1.35版本需将该字段同步给运营中台，或运营中台进行查询后，在客户端对应流程展示。

### 客户端

该部分需求由运营中台实现。
