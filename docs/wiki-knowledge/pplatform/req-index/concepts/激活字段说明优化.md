# 激活字段说明优化

## 概述

V1.17版本针对运营侧常混淆的"激活"字段增加了说明提示，以区分产融平台与多级流转系统中同名字段的不同含义。

## 问题背景

产融平台联系人维护列表上的"激活"字段与[[多级流转]]联系人列表上的"激活"字段名称相同但含义不同，运营人员在日常操作中容易混淆。

## 改造内容

在产融平台的"账号状态"字段旁增加小问号提示：

> "该状态仅指用户是否登录过产融平台，不代表区块链账号是否激活"

## 设计要点

- 产融平台的"激活/账号状态"：仅表示用户是否登录过产融平台
- 多级流转的"激活"：表示区块链账号是否激活
- 两者为独立概念，不可混用
