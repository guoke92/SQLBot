# 项目（产融平台语境）

在[[chanrong-platform|产融平台]]中，项目是[[product-chanrong|产品]]之下的配置层概念。在同一个产品下会存在不同的差异化流程，故产融平台上增加了项目概念，不同的项目可以拥有不同的配置项，实现流程上的差异化。

## 核心特征

- 项目是产品之下的粒度，一个产品可包含多个项目
- 不同项目可拥有不同的流程和协议配置
- 企业在开展业务时按项目上的配置来跑流程

## 项目数据同步

项目数据从业务系统同步至产融平台，无需新增：

### 字段定义

| 字段名称 | 格式 | 长度 | 说明 |
|---|---|---|---|
| 项目名称 | 文本 | 256 | 由业务系统同步 |
| 产品名称 | 枚举 | - | 业务系统同步时由产融做映射 |
| 项目状态 | 枚举 | - | 待生效、已生效、已失效 |
| 项目创建时间 | 时间格式 | - | 如2024-05-05 12:12:12 |
| 项目生效时间 | 时间格式 | - | 如2024-05-05 12:12:12 |
| 渠道码 | 文本 | 32 | 自动生成 |

### 同步时点

项目创建后即可同步至产融侧，不需要等待项目生效后再同步。

### 项目状态映射

| 业务系统 | 业务系统状态 | 映射至产融状态 |
|---|---|---|
| 多级流转 | 待提交 | 待生效 |
| 多级流转 | 已生效 | 已生效 |
| 订单融资/经销商融资 | 待提交 | 待生效 |
| 订单融资/经销商融资 | 已生效 | 已生效 |
| 线上保理 | 待生效 | 待生效 |
| 线上保理 | 已生效 | 已生效 |
| 线上保理 | 已失效 | 已失效 |

## 与企业的关系

企业可关联到项目上，企业在开展业务时按照项目上的配置去跑流程。关联项目时：
- 若项目关联的产品为企业已开通的产品，开通状态为已开通
- 若项目关联的产品为企业未开通的产品，开通状态为开通中

## 项目协议

不同项目可以配置不同的项目协议（如项目要素表）。首个办理关联项目业务的被授权人或经办人需在业务系统页面中签署项目协议。

## 渠道码

每个项目同步至产融平台时会自动生成唯一的[[channel-code|渠道码]]，用于邀请注册等场景。
