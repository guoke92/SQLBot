# 租户配置支持修改名称和统码

## 概念定义

允许已生效的租户在基础信息配置中直接修改"租户名称"和"统一社会信用代码"字段，无需通过icase工单处理，从而降低icase比例并提升运营操作效率。

## 需求背景

此前租户配置一旦生效后，租户名称和统码无法自行修改。实际业务中，租户对应的具体企业存在变更企业名称和统一社会信用代码的情况，每次变更都需要走icase处理流程，增加了运营负担。

## 业务规则

- 已生效租户进行基础信息配置时，"租户名称"和"统一社会信用代码"字段支持直接调整
- 目标：降低icase比例，方便运营操作
