# 额度审核工作流

## 概念定义

额度审核工作流是为产融平台的[[额度管理|额度维护]]功能增加的可配置多级审批流程。该功能允许运营方自行配置额度维护的审批层级和审批人员，使额度变更需经过预设的审核流程后方能生效。

## 需求背景

[[湖北联投]]贴牌提出需增加额度审批功能。此前额度维护无审核流程，额度维度完成后立即生效。为完善额度管理功能，V1.29版本新增审核工作流。

## 功能设计

### 审核流程配置入口

- 用户中心菜单下新增"审核流程配置"二级菜单
- 适用企业角色：核心企业、运营方、集团公司、金融机构
- 菜单展示逻辑与"额度管理"菜单保持一致（仅配置了额度管理菜单的企业同步展示审核流程配置菜单）

### 额度维护审核流程

- 系统默认**无审核层级**，即额度维护不设置审批流程，额度完成后立即生效
- 支持手动配置审核层级，最多可配置到**十级**
- 每一层级支持配置：
  - 审核角色和审核人员
  - 是否支持批量操作（默认勾选）
  - 全部审核结果（默认勾选）
- 多个节点和单个节点均支持删除
- 支持查看已配置层级及工作流流程图

### 联动机制

额度维护审核流程需要与额度维护功能一起应用。
