# 客户录入审核流程节点优化

V1.21版本对"邀请认证-客户录入"建档方式的审核流程进行了优化，增加了异常情况的处理入口。

## 背景

认证方式为"邀请认证-客户录入"的企业建档时，[[产融平台]]内管端提交建档后企业认证状态变为"待客户认证"，此时[[运营中台]]无该审核流程，需要客户登录客户端点击待办后，该笔建档申请才会推送至运营中台。

实际业务中出现以下问题：
- 建档信息录入有误
- 管理员无法配合操作

导致运营中台无法处理该条数据。

## 业务规则

针对"邀请认证-客户录入"建档提交后，认证状态变更为"待客户认证"时，如客户未点击客户端待办、未同步推送运营中台审核流程，预留后台手动触发推送的入口，用于异常情况处理。其他处理逻辑同现有。

## 优先级

本需求标记为【高】优先级。
