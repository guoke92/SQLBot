# 企业管理员变更专题

## 概述

企业管理员变更是产融平台中流程最复杂的变更类型，涉及企业管理员身份信息更新、授权书重签、法定代表人身份验证等多个环节。该变更包括三个子类型：企业管理员变更（序号9）、企业管理员手机号变更（序号10）、企业管理员证件有效期变更（序号11）。

## 变更类型详解

### 企业管理员变更（序号9）

**涉及字段**：
- 姓名、姓名（英文）
- 证件类型、证件号码、证件有效期
- 出生日期
- 手机号码、邮箱

**所需材料**：
1. 企业管理员身份证正反面
2. 企业授权确认书
3. 人脸识别

**后置流程**：需重签企业授权书（根据业务系统配置项决定）

### 企业管理员手机号变更（序号10）

**涉及字段**：手机号码

**所需材料**：企业授权书（新）

**后置流程**：需重签企业授权书（根据业务系统配置项决定）

### 企业管理员证件有效期变更（序号11）

**涉及字段**：证件有效期

**所需材料**：企业管理员身份证正反面

**后置流程**：无需重签授权书

## 按企业角色的流程差异

### 供应商、经销商、项目公司（AMS）等

**网关发起的变更**：
- 变更完成后，需要企业做确认
- 需做法人人脸或验短
- 无需企业管理员人脸

**企业自行发起的变更**：
- 在变更流程内做法人验短或人脸
- 可全线上完成

### 核心企业（讯易链）

- **仅支持网关发起变更**：不支持企业自行发起
- **授权书仅可线下面签**
- 变更完成后给到企业做确认
- 确认时需法人验短或人脸

## 按认证方式的流程差异

### 邀请认证（客户录入/平台录入）

- **是否需内管审核**：是
- **后置流程**：需重签授权书（序号9、10）；无需重签（序号11）
- **变更发起方式**：运营中台录入 / 企业自行录入（核心企业不支持）

### 简易认证

- **是否需内管审核**：否
- **后置流程**：无
- **变更发起方式**：产融平台录入
- **变更后立即生效**

## 确认方式与身份验证

### 法定代表人验证

企业管理员变更后，需法定代表人进行身份验证：
- **人脸识别**：通过生物特征确认法人身份
- **验短**：通过短信验证码确认法人身份

### 企业授权确认书

企业管理员变更需提交企业授权确认书，确认新管理员的授权：
- **网关发起**：线下签署
- **企业自行发起**：线上签署
