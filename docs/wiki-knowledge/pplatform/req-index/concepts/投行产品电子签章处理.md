# 投行产品电子签章处理

## 概述

V1.9版本明确了开通[[投行产品]]且未开通电子签章的处理方案，解决当前强制开通逻辑的不合理问题。

## 背景

当前问题：
- 客户建档时选择不开通电子签章
- 若开通了投行产品，则会在开通时强制阅读上上签再开通电子签章
- 但开通电子签章处依旧显示"否"
- 逻辑不一致，用户体验混乱

## 新处理方案（V1.9）

| 阶段 | 操作 | 说明 |
|------|------|------|
| 建档时 | 客户选择不开通电子签章 | 尊重客户选择 |
| 开通投行产品 | 正常开通，不强制开通电子签章 | 保持逻辑一致 |
| 办理业务时 | 若需在线签署，联系运营人员开通电子签章 | 按需开通 |
| 开通电子签章 | 阅读[[cfca]]和上上签协议后开通 | 合规流程 |

## 设计要点

1. **按需开通**：不再强制，由业务场景驱动
2. **逻辑一致**：开户选择与实际状态保持一致
3. **合规保障**：开通电子签章时仍需阅读CFCA和上上签协议
