# 在途业务校验（产融平台语境）

在途业务校验是[[产融平台]]在企业信息变更流程中的一项关键安全机制。当企业在产融上发起变更时，需要校验该企业是否在任何业务系统中存在在途业务，以防止数据不一致和业务冲突。

## 校验规则

- 当在产融上发起企业变更时，需要校验是否有在途业务
- **任何一个系统上有在途都算**——产融调用各个业务系统的接口做判断
- 提示语为："该企业在【xxx】产品下存在在途业务，暂不支持发起"
- 如多个产品有在途业务："该企业在【xxx】、【xxx】产品下存在在途业务，暂不支持发起"

## 审核过程中的校验

- 发起变更流程之后，流程在审核过程中时，业务系统可以继续做业务
- [[运营中台]]在审核通过变更时会再次校验是否有在途业务
- 如果有在途业务，则不允许通过审核

## 取消关联项目时的校验

企业取消关联项目时也需要做校验：当有业务在进行时，不允许解除关联。

## 与其他系统的关系

在途业务校验体现了[[产融平台]]与各业务系统（[[讯易链]]、[[ams]]等）之间的深度协同。产融平台需要调用各业务系统的接口来判断在途状态，这要求各业务系统提供相应的查询接口。
