# 运营方数据合并

## 概述

运营方数据合并是[[产融平台]]V1.3版本确认的业务逻辑，解决同一企业既作为核心企业/金融机构又作为运营方的角色冲突问题。

## 需求背景

目前的运营方常常由核心企业/金融机构来担任，故需要支持同一个企业既作为核心企业/金融机构，又可以作为运营方。

## 功能描述

### 新增运营方时的选择方式

1. **从已有企业中选择**：选择已建档审核通过的企业，页面上的字段根据已有数据反显（除银行账户外），不支持修改
2. **手动新增**：用户手填各字段，提交时校验统一社会信用代码是否已存在于企业信息列表中（不区分建档审核状态），如已存在则提示"统一社会信用码已存在，请确认"

## 内部张力

该功能通过"选择已有企业"来复用数据，简化了用户操作，但未从根本上厘清企业实体与业务角色（运营方）之间的关系模型。数据唯一性和业务角色多样性之间的矛盾仍然存在。
