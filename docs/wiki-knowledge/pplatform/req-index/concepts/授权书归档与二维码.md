# 授权书归档与二维码

## 概述

授权书归档与二维码是产融平台V1.6版本引入的授权书管理机制，通过在授权书中植入编号和二维码，实现线下签署文件的便捷归档。该机制是 [[产融平台]] 与 [[运营中台]] 协同的核心流程之一。

## 背景

此前KA业务中未对企业授权书做规范管理，存在以下不确定问题：
- 客户是否正确签署授权书
- 客户是否将线下签署的授权书回寄
- 收到的授权书是否都统一归档

## 核心机制

运营中台新增授权书归档功能菜单。各业务系统拉起建档/变更流程时，运营中台相应触发授权书归档流程。业务系统需在授权书中新增【编号】和【二维码】（调用运营中台接口生成）。

## 配置项

运营配置-租户配置增加配置项"是否需回收授权书"：
- 默认值："是"（历史存量租户+新增租户）
- 运营可手动修改
- 产融在拉起运营中台建档流程时需将该字段传给运营中台

## 各场景处理方式

### 客户端录入信息场景

不区分线上签署还是线下签署，统一生成编码和二维码：

| 签署方式 | 处理方式 |
| --- | --- |
| 线上签署 | 线上生成授权书时自动插入编码和二维码，签署完成后可自动归档 |
| 线下签署 | 客户下载模板时在模板内插入编码和二维码；回寄文件后运营同事用 [[蜜蜂扫码工具]] 扫描二维码实现归档 |

### 平台录入信息场景

产融向运营中台传输网关建档字段（新增字段）。

## 涉及的产融侧流程

### 建档流程

| 建档方式 | 授权书处理 |
| --- | --- |
| 自主注册 | 可线上或线下签署，自动插入编码和二维码 |
| 邀请认证-客户录入 | 可线上或线下签署，自动插入编码和二维码（内管端帮传授权书的情况极少） |
| 邀请认证-平台录入 | 授权书由内部同事在内管上传，传网关建档标识 |
| 简易认证 | 授权书非必填，与运营中台无交互 |

### 变更流程

| 变更类型 | 触发条件 | 授权书处理 |
| --- | --- | --- |
| 变更授权书 | 授权书模板更新、开通新产品、跨租户同步企业信息 | 平台录入由内管上传；客户端录入由客户端签署 |
| 变更企业信息 | 新增企业角色（新管理员需补签授权书） | 同上 |
| 变更人员信息 | 管理员变更、人员/手机号/邮箱变更（产融暂未实现） | 同上 |

## 与企业授权书配置的关系

本机制是对 [[企业授权书配置]] 的重大扩展。企业授权书配置关注授权书模板的管理与配置，而授权书归档与二维码机制在此基础上增加了归档流程、编号生成、二维码植入和扫描归档等全生命周期管理能力。
