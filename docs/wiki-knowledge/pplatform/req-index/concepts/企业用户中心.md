# 企业用户中心

企业用户中心是[[chanrong-platform|产融平台]]客户端中面向[[user-roles-chanrong|被授权人（企业管理员）]]开放的一级菜单，用于管理企业内部的人员、角色和组织机构。

## 功能模块

### 用户角色配置

以用户维度展示该用户关联的产品及分配的用户角色，支持以下操作：
- **新增**：录入用户信息及分配角色信息，分配角色需先勾选产品后再分配用户角色
- **编辑**：用户账号和手机号不可编辑，其他同新增
- **冻结/解冻**：管理用户状态
- 初始化用户角色为"企业管理员"

### 角色权限配置

以角色维度展示角色关联的产品，支持：
- **新增角色**：录入角色名称、选择产品类型（单选）、录入角色说明
- **编辑角色**：产品类型自动反显不可编辑
- **分配权限**：设置每个菜单及按钮权限
- **删除角色**：二次提示确认删除
- 系统可预置部分角色供使用

### 组织机构查看

与内管端的组织机构管理功能相比，取消操作层级的功能，仅支持查看及数据导出。

### 审核流程配置

按照tab页展示各业务系统工作流流程，可编辑：
- 审核层级
- 审核结果
- 审核角色
- 审核人员
- 批量操作
