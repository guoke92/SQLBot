# 企业数据合并

企业数据合并是[[数据迁移]]过程中的关键环节，指当存量企业在[[讯易链]]和[[ams]]平台上都有建档时，需要将多条数据合并为一条，以实现[[企业认证数据统一]]的目标。

## 合并策略

### 基本流程

1. 导出存在多条建档数据的企业
2. 通过RPA抓取最新的企业关键字段（企业名称、统一社会信用代码、法人名称等）
3. 对比定位建档数据中最准确的一条
4. 如对比后所有建档数据关键字段一致，取用建档时间最晚/变更时间最晚的那一条
5. 影像件也留用对应的那一套

### 跨租户数据同步规则

当一个企业在A租户下已建档，且A租户在【租户配置】-【注册配置】中同意了客户数据可被其他贴牌平台使用时：

- 企业只需点击【确认】，即可将建档数据从A租户复制一份到B租户
- 复制时仅复制企业数据，不复制企业身份、开通的产品及关联的企业信息
- 使用【统一社会信用代码+手机号】去匹配，企业状态需为已建档成功
- 金融机构和运营方不需要做数据互通处理

### 复制数据范围

- 企业信息、企业影像件
- 法人信息、法人影像件
- 被授权人信息、被授权人影像件（除开授权书之外）

### 多份数据取用规则

当拉取数据查询到多份时：
- 如多份数据的建档方式都是简易建档/非简易建档，按建档完成时间取用最晚的那份
- 如多份数据的建档方式不一样（既有简易建档又有非简易建档），取用非简易建档下建档完成时间最晚的那一份

## 跨平台同步后的授权书处理

对于跨平台同步认证数据的企业，需要补签新贴牌平台上的授权书：
- 补签逻辑可复用已有逻辑——核心企业只能走线下，其他企业可以线上或线下签署
- 如果是线上签署，签署完成之后即生效，不用经过运营中台审核
- 核心企业点击【确定】后，出现弹窗提示"已同步企业基础数据，请联系平台运营更新授权书"

## 配置控制

租户维度有一个开关，控制是否授权同步数据（即"客户认证数据是否可用于其他贴牌平台"配置项）。
