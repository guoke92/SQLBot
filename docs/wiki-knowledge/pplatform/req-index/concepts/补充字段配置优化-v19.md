# 补充字段配置展示优化

## 概述

V1.9版本（遗留需求）对注册配置中的[[补充字段]]配置展示进行优化，通过联动逻辑减少误配置。

## 优化规则

| 补充字段必填状态 | 适用角色下拉框状态 |
|------------------|---------------------|
| 必填 | **可选**（启用） |
| 非必填 | **置灰禁选**（禁用） |

提交后生效。

## 设计要点

1. **联动控制**：必填状态决定适用角色是否可配置
2. **防误操作**：非必填字段不允许配置适用角色，避免配置歧义
3. **即时生效**：提交后即生效
