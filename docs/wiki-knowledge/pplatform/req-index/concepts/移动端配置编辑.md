# 移动端配置编辑

## 定义

移动端配置编辑是[[产融平台]]V1.19版本放开的功能权限，允许租户在生效状态下直接编辑其移动端（如小程序）的背景图、Logo等UI素材，解决了此前生效后UI调整需提数据工单的效率问题。

## 业务背景

此前，租户配置-基础信息配置-移动端配置中，"小程序首页背景图、移动端首页logo"在租户生效后不支持编辑。实际业务中遇到需要更换UI效果时无法手动处理，必须提交数据修改工单，流程低效。

## 业务规则

- **配置位置**：租户配置 → 基础信息配置 → 移动端配置
- **可编辑项**：小程序首页背景图、移动端首页logo
- **生效条件**：租户在**生效状态**下即可编辑
- **操作方式**：支持删除文件后重新上传，与PC端配置逻辑一致

## 设计要点

该功能将移动端UI配置的编辑权限从"仅限未生效状态"扩展到"生效状态也可编辑"，使移动端配置与PC端配置的编辑权限保持一致。这提升了运营灵活性，但可能对已生效租户的UI一致性带来管理挑战。

## 潜在风险

放开生效状态下的编辑权限意味着运营人员可以随时更改已上线租户的移动端UI，需要关注：
- UI变更是否需要审批流程
- 变更历史是否可追溯
- 是否存在误操作导致UI异常的风险
