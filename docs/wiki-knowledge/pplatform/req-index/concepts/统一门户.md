# 统一门户

统一门户是[[chanrong-platform|产融平台]]V1.0.0的首要交付目标，旨在为客户端提供统一的登录、注册、产品中心和待办入口，全面提升客户多产品的业务体验。

## 核心功能

### 门户页
根据[[tenant|租户]]配置进行企业营销页面展示，包含首页、产品服务、公司介绍、新闻动态、加入我们等。

### 注册/登录
- **自主注册**：凭手机号+企业名自主注册
- **邀请注册**：凭平台端邀请的手机号+邀请码登录注册
- **登录方式**：邮箱/手机号+密码或手机验证码登录
- **忘记密码**：凭手机验证码重置密码

### 企业认证
进表企业认证，认证成功即成为被授权人，并可使用开通产品。

### 产品中心
- 查看各产品概要介绍
- 已开通产品可打开产品业务操作页面
- 未开通产品可进行产品开通
- 展示平台公告和操作指引
- 查看各开通产品的待办、消息通知

### 待办栏
展示全部待办事项和快捷办理入口，及核心业务指标概览。

## 用户认证状态与门户功能映射

统一门户的功能显示高度依赖用户的[[enterprise-authentication|企业认证]]状态和角色（被授权人/经办人），形成了复杂的条件显示逻辑。详见产品中心状态逻辑。

## 价值目标

统一门户的建设是产融平台"扎下去"价值主张的核心组成部分：
- 提升客户体验：自主注册，一次建档即可
- 支持平台营销：从项目营销转平台营销模式
- 产品互引：支持客户营销做广、做深
