# 登录审计日志

## 概述

登录审计日志是SSO单点登录系统对所有登录操作进行完整记录的机制，用于异常行为识别、安全审计和合规追溯，满足"系统可对异常登录进行日志记录"的合规要求。

## 设计目标

- 记录所有登录/登出操作，包括成功和失败
- 支持异常登录行为识别和分析
- 提供完整的审计追溯能力
- 满足安全合规的审计要求

## 日志记录

### 记录存储

所有登录日志存储在 [[sso-user-login-history]] 表中。

### 记录场景

| 场景 | 操作结果 | 记录内容 |
|------|---------|---------|
| 登录成功 | 成功（1） | 用户ID、登录名、系统编号、登录IP、登录时间 |
| 登录失败 | 失败（0） | 登录名、系统编号、登录IP、失败时间、失败原因 |
| 账户锁定 | 失败（0） | 锁定原因、锁定时间、剩余锁定时间 |
| 密码过期 | 失败（0） | 密码过期信息 |
| 登出操作 | 成功（1） | 用户ID、登录名、系统编号、登出时间 |

### 失败原因分类

- "登陆用户不存在"
- "用户未开通此系统"
- "密码错误"
- "账户已被锁定"
- "密码已过期，需要修改密码"

## 异常登录识别

系统通过以下维度识别异常登录行为：

| 维度 | 说明 |
|------|------|
| 登录失败记录 | 记录所有登录失败的尝试，包括失败原因 |
| IP地址 | 记录每次登录的IP地址，用于识别异常IP访问 |
| 时间 | 记录登录时间，用于识别异常时段登录 |
| 设备信息 | 记录用户代理（UA）信息，用于识别异常设备访问 |

## 日志查询与分析

- **日志查询接口**：支持按用户、时间、IP、操作结果等条件查询
- **异常行为分析**：支持异常登录行为分析和统计
- **审计功能**：所有关键操作均记录审计日志，支持回溯与审计

## 关键代码示例

```java
SsoUserLoginHistoryDO history = SsoUserLoginHistoryDO.builder()
    .loginType("登录")
    .loginName(loginName)
    .sysChannel(sysChannel)
    .loginIp(NetworkUtil.getIp(request))
    .ssoId(ssoUserDO.getSsoId())
    .operatorResult(1) // 0-失败，1-成功
    .remark("SSO密码 登陆成功")
    .build();

ssoUserLoginHistoryService.saveOrUpdate(history);
```
