# 登录页配置

## 概述

登录页配置是[[产融平台]]V1.3版本新增的租户级配置功能，支持租户自定义登录页的主题色和视觉元素，与门户页配置分离。

## 功能描述

### 配置内容

租户可上传和配置以下元素用于登录页渲染：
- 主题色（用于文案、登录框背景色、输入框选中时的外框颜色等）
- 其他视觉元素

### 自动渲染

产融会基于上传的要素自动渲染一个租户的登录页效果。原来的门户页配置只负责配置门户，登录页配置独立管理。

### 数据迁移相关

对于存量迁移的租户：
- 后台自动打上标签"使用旧版登录页配置"
- 客户打开链接时自动跳转登录界面，维持原有界面一致
- 存量租户系统根据从[[多级流转]]侧同步过来的元素完成页面渲染，不需要人工再进行配置

新增的租户引导同时使用门户页+登录页。

## 与其他概念的关系

- 与[[统一门户]]功能互补，门户页和登录页分别配置
- 是[[租户]]配置能力的重要扩展
- 存量数据迁移逻辑与[[数据迁移]]相关
