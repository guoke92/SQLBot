# 批量替换运营（按项目维度）

## 概述

V1.17版本在企业联系人维护功能中新增了按"项目"维度批量导出和替换运营人员的能力，是对现有"人员维度"替换模式的补充。该功能直接回应了运营侧按项目维度调整人员的诉求。

## 功能描述

### 项目维度替换

- 在企业联系人维护菜单中选择"项目维度"进行替换操作
- 导出的Excel模板包含项目名称等字段
- 支持按项目维度批量替换运营人员

### 人员维度优化

- 原有的"人员维度"替换模式继续保留
- 导出的文件内增加"项目名称"字段，提升数据可读性

## 业务价值

- **效率提升**：运营侧可按项目维度一次性完成人员调整，无需逐人操作
- **数据完整性**：人员维度导出也增加项目名称，便于运营人员理解数据上下文

## 与其他概念的关系

- 本功能位于[[产融平台]]的企业联系人维护模块
- 与[[运营分配机制]]相关，是运营人员管理能力的扩展
- 与[[项目产融平台语境]]概念相关，以项目为组织维度进行人员管理
