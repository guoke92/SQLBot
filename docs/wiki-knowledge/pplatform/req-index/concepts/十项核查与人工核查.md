# 十项核查与人工核查

十项核查和人工核查是产融平台企业认证流程中的两层审核机制，由运营中台执行。

## 十项核查

十项核查是运营中台对企业认证信息进行的自动化审核规则集合。当认证流程中的各项验证（被授权人手机号实名、人脸识别、授权书签章核验及比对）均通过时，企业认证信息进入十项核查环节，十项核查通过即认证通过。

## 人工核查

当自动化核查不通过时，转入人工审核流程。具体触发条件包括：

- 被授权人手机号实名不通过但人脸识别通过，且授权书签章核验及比对不通过
- 被授权人手机号实名通过但人脸识别不通过（无论授权书签章是否通过）
- 被授权人手机号实名不通过但人脸识别通过，且授权书签章核验及比对通过时，走十项核查路径（不进入人工核查）

## 简易认证中的人工识别

简易认证流程中存在特殊的"人工识别"机制，与人工核查不同：

- 触发条件：企业状态为"待客户确认"+认证方式为简易认证+系统人脸识别状态为识别失败
- 操作方式：运营人员点击"人工识别"按钮，弹窗展示客户的人脸认证视频
- 结果：可点击"识别成功"人工修改人脸认证状态为"识别成功（人工）"
