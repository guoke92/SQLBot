# 企业建档派单

## 概述

企业建档派单是[[产融平台]]V1.3版本引入的业务流程，在企业建档时分配运营人员，并与[[运营中台]]同步信息，实现建档流程的运营人员自动分配和管理。

## 功能描述

### 新增企业时的运营分配

- 新增企业时维护"运营"字段，该字段通过查询[[运营中台]]的接口获取
- 在拉起运营中台的建档流程时，将该字段传输给运营中台
- 企业管理员信息和运营字段会一起同步到"企业联系人维护"表单上

### 企业联系人维护表单上的运营字段

运营字段数据来源有三种途径：

1. **从企业信息同步**：运营中台建档完成后返回运营字段，用该值填充"建档经办人"字段。运营中台返回的值可能与产融侧录入的运营不同，是否覆盖取决于运营配置-租户维度配置上的"是否覆盖运营信息"配置项。

2. **新增角色时分配**：当一个企业拥有多个角色，在为企业新增角色时可另外新增管理员，新增时也会分配一个运营。

3. **手动分配**：当运营字段没有保存成功时，对应联系人的操作栏上有"分配运营"按钮，可再次分配运营。

### 运营配置-租户维度关联配置

增加配置项"是否覆盖运营信息"（开关类）：
- 当为开时，用运营中台返回的运营值覆盖产融侧原来维护的运营值
- 当为关时，保持产融侧原有值

### 存量数据同步

业务系统中存量的数据需要同步至产融。

- 该流程是[[企业认证]]流程的重要环节
- 与[[运营中台]]深度集成，依赖其接口获取运营人员信息
- 配置项整合在[[运营配置]]模块中
