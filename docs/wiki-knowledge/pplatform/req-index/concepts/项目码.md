# 项目码

## 概述

项目码是[[产融平台]]V1.3版本中引入的新字段，用于替代原有的[[渠道码]]，在企业建档流程中关联企业与项目，是企业认证的关键输入。

## 与渠道码的关系

项目码是对[[渠道码]]的替代。项目中心页面上的"渠道码"字段被替换为"项目码"字段，可双击进行编辑，不可为空，并提供"复制"功能。

## 功能特性

- 项目码在项目中心页面可双击编辑
- 不可为空
- 提供"复制"功能
- 用于关联企业与项目

## 在企业建档流程中的作用

项目码是企业建档前置校验的第一步：

1. **第一步**：如果用户和企业建立关联关系时未填写项目码（注册时/登录后再新增企业时），会弹出引导录入项目码的弹框
2. 对于未认证的企业，点击"企业认证"时如未录入项目码，会出现弹窗供其再次确认是否需要录入项目码
3. 对于未填写邀请码的企业，如果后台已建立该企业和项目之间的关联关系，则使用后台已维护的关系

## 企业建档前置校验优先级

文档定义了完整的四步校验流程，项目码校验为第一步：
1. 校验是否录入项目码
2. 校验该租户下企业是否已在建档中
3. 校验企业是否满足跨租户同步数据场景
4. 校验企业走哪种建档方式（PC端/小程序端）
