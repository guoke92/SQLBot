# 项目公司信息推送

## 需求背景

[[线上保理]]的业务中有项目公司的角色，[[多级流转]]侧目前没有使用该角色。如果该角色需要经过多级做中转的话，多级涉及较大的改造工作量。

## 解决方案

经过讨论之后达成一致意见：**项目公司角色由产融直接推向线上保理**。

## 与资产派单的关系

在向业务系统推送企业数据时，需要把【运营】字段也推送过去：
- 当【运营】字段有更新时，也需要再次推送
- 线上保理在向运营中台推送资产审核任务时，需要把该字段也推给运营中台，用于派单

## 实现状态

该需求标记为"后置"，需要结合线上保理的排期去安排。线上保理安排在1024版本。

## 与数据迁移的关系

在数据迁移过程中，项目公司相关的数据需要正确处理，确保迁移到产融平台后能够正常推送到线上保理系统。
