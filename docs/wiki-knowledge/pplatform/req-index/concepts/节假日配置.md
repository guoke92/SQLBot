# 节假日配置

节假日配置是[[chanrong-platform|产融平台]]V1.0（0628版本新增）的平台配置功能，用于管理节假日日历。

## 使用场景

1. **导入资产时**：业务系统会查询到期日是否在节假日内。如果在节假日内，需将该部分资产独立展示出来，引导用户做确认或者修改到期日。

2. **资产即将到期时**：提前x天对资产进行跑批，识别资产到期日是否在节假日内。如果在节假日内，需提示核心企业做确认或者修改到期日。

## 业务影响

配置的节假日可以对业务系统产生影响。当修改了节假日后，业务系统上的校验结果会相应出现差异。

## 实现说明

节假日配置可复用标品（已有系统）的界面和逻辑。
