# 系统配置驱动

系统配置驱动是指通过数据库配置来动态控制功能是否启用的设计模式。在SSO验证码登录改造中，它体现在通过 [[sso_system表]] 的 `captcha` 字段来决定特定系统渠道是否需要验证码。

## 配置项

- **`captcha` 字段**：位于 [[sso_system表]] 中。
  - `0`：表示该系统渠道可以不加验证码。
  - `1`：表示该系统渠道需要图片验证码或行为验证码。

## 应用逻辑

在 [[sso-code-provider]] 的 `validateCaptcha` 接口和 [[login-captcha-ck]] 的 `checkCaptcha` 方法中，都会查询此配置：

1.  **参数不完整时**：如果行为验证码参数（`challenge`, `validate`, `seccode`）为空，会先检查此配置。若 `captcha=0`，则直接返回成功或跳过校验；若 `captcha=1`，则抛出异常。
2.  **登录时**：如果系统配置要求验证码（`captcha=1`）但未传入任何验证码参数，将抛出错误码为 `10930` 的异常。

## 优势

- **灵活性**：无需修改代码即可为不同业务系统启用或禁用验证码功能。
- **兼容性**：可以平滑地从不需要验证码的系统过渡到需要验证码的系统。
