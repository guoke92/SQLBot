# 客户端在途变更自动结束

## 概述

客户端在途变更自动结束是产融平台V1.28版本新增的功能，优化了客户端自主发起企业信息变更时的体验。此前，若存在在途变更流程，系统无法自动拒绝，需要运营人员手动结束在途流程后客户端才能重新发起。本次优化支持系统自动结束在途流程。

## 业务流程

### 触发条件

客户端点击【变更企业信息】按钮时，满足以下条件触发：
- 存在变更流程（即产融变更待办）
- 该流程未提交运营中台审核

### 交互流程

1. **弹窗提示**：系统弹窗提示存在在途变更流程。
2. **用户选择**：
   - 点击【重新发起】：弹出二次确认提示"重新发起将结束在途变更流程"，提供【取消】和【确定】按钮。
     - 【确定】：系统自动结束当前在途变更流程（运营中台拒绝在途流程），产融平台待办消失，重新发起新流程。
     - 【取消】：弹窗关闭，数据不做更新。

### 存量数据处理

存量在途变更任务需支持系统自动结束流程。

## 与现有概念的关系

该功能是对 [[concepts/企业信息变更-平台录入自行变更]] 的进一步优化，解决了在途流程阻塞新变更发起的痛点，减少了人工干预。
