# 中间页

## 定义

中间页是产融平台V1.10版本中，系统互通跳转流程中的一个关键页面。当用户首次点击系统互通产品时，会进入中间页进行授权确认，然后前往目标第三方系统。

## 触发条件

中间页仅在以下条件下展示：

1. 企业已完成认证（状态为"已认证"）
2. 租户配置中已开通该系统互通产品
3. 已在系统互通配置菜单配置了跳转信息
4. 用户尚未进行过首次跳转（未在中间页进行授权并前往操作）

## 未满足条件时的行为

| 条件 | 行为 |
|------|------|
| 企业未认证 | 系统互通产品不展示在"我的产品"下 |
| 已认证但未配置跳转信息 | 提示"{产品名称}未完成相关配置，请联系客服！" |
| 已认证且已配置跳转信息 | 进入中间页 |

## 授权后行为

用户在中间页完成授权并前往操作后：
- 产品开通状态更新为"已开通"
- 后续点击该产品将直接跳转，不再展示中间页

## 设计意义

中间页在系统互通功能中承担用户体验和授权控制的关键角色：
- **用户体验**：明确告知用户即将跳转至第三方系统
- **授权控制**：确保用户主动确认跳转行为
- **状态管理**：标记用户已完成首次授权，优化后续交互流程
