# 产融首页

## 概述

产融首页是[[产融平台]]V1.3版本重新设计的核心页面，基于与各方调研的结果进行了重大调整，旨在提升产品导航和用户自助服务体验。

## 主要调整

### 新增"我的产品"区域

- 作为快捷入口，显示"已开通"和"开通中"的产品
- 开通产品需由企业管理员发起，且签署产品服务协议
- 完成产品开通后，企业可开始办理业务

### "产品中心"位置调整

- 由原来的中心位置移动至右下角
- 用户仅可查看产品的介绍信息，不可自主开通产品

### 帮助中心固化显示

- 由原来的点击右上角小图标后出现，调整为固定显示在页面上
- 点击"立即查看"后出现新页面
- "问题分类"对应产品类型，如融易单、投行产品

## 引导文案

首页包含引导用户操作的文案：
- 开通产品引导：提示在"我的产品"区域进行产品开通
- 业务办理引导：提示通过"我的产品"区域进入业务产品界面
- 待办/公告引导：提示先完成待办处理/公告查看

## 与其他概念的关系

- 与[[统一门户]]共同构成用户入口体系
- 是[[产融平台]]用户引导与自助服务体验增强的核心体现
- 首页展示的客服配置内容来源于[[运营配置]]模块
