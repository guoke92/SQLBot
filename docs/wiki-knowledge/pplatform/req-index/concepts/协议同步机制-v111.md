# 协议同步机制（V1.11版本）

## 概念定义

协议同步机制是产融平台V1.11版本明确的业务系统向产融平台同步各类协议的规则和流程，主要涉及订单融资和线上保理两个业务系统在迁移至产融平台时及迁移后的协议同步节点、内容和失败处理机制。

## 订单融资协议同步

### 同步节点

**迁移时同步存量**

### 同步内容

| 协议类型 | 同步时机 | 说明 |
|----------|----------|------|
| 用户注册协议 | 迁移时同步存量 | 必须同步 |
| 隐私政策协议 | 迁移时同步存量 | 如有则同步 |
| 企业授权书 | 迁移时同步存量 | 必须同步 |
| 项目要素确认书 | 迁移时同步存量 | 必须同步 |
| CFCA协议 | 迁移时同步存量 | 必须同步 |

## 线上保理协议同步

### 同步节点

#### 1. 迁移时同步存量

**同步内容**：
- 企业授权书（仅此节点同步）
- 隐私政策协议（如有，仅此节点同步）
- CFCA协议（仅此节点同步）
- 产品服务协议（迁移时也需同步存量）
- 用户注册协议（迁移时也需同步存量）

**失败处理**：
- 产融拉取业务系统的协议
- 失败保存在失败表中
- 定时任务定时重拉

#### 2. 迁移时在途数据

**触发条件**：审核通过后，同步企业信息给产融时

**同步内容**：产融拉取业务系统协议

**失败处理**：
- 失败保存在失败表中
- 定时任务定时重拉

#### 3. 迁移后增量同步

**触发条件**：客户关联新产品/新项目后，进入业务系统签署协议

**同步内容**：
- 产品协议
- 用户注册协议

**同步流程**：
1. 客户关联新产品/新项目
2. 进入业务系统签署协议
3. 签署完成后业务系统推给产融

### 字段调整

将"签署完成日期"调整为"签署/确认完成日期"，因为有部分协议不需要做签署。

## 同步机制对比

| 维度 | 订单融资 | 线上保理 |
|------|----------|----------|
| 同步节点 | 仅迁移时 | 迁移时 + 迁移后增量 |
| 失败处理 | 未明确 | 失败表 + 定时重拉 |
| 增量同步 | 未涉及 | 涉及产品协议、用户注册协议 |
| 字段调整 | 未涉及 | 签署完成日期 → 签署/确认完成日期 |

## 失败处理机制

### 失败表设计
- 用于存储协议拉取失败的记录
- 包含失败原因、重试次数等信息

### 定时重拉策略
- 定时任务定期扫描失败表
- 对失败记录进行重试拉取
- 可能包含重试次数限制和告警机制

## 实施要点

1. **同步范围明确**：各业务系统需明确需要同步的协议类型
2. **失败处理完善**：建立完善的失败记录和重试机制
3. **字段映射**：确保各系统间协议字段的正确映射
4. **监控告警**：建立协议同步的监控和异常告警机制
5. **数据一致性**：确保同步后的协议数据与源系统一致

## 待确认事项

1. 订单融资的失败处理机制是否与线上保理一致
2. 定时重拉的具体策略（重试间隔、最大重试次数等）
3. 失败表的具体字段设计
4. 增量同步的触发时机和边界条件
