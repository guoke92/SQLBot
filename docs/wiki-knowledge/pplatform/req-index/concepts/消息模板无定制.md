# 消息模板无定制

消息模板"无定制"是V1.13版本新增的[[租户]]配置优化功能，允许租户直接使用通用消息模板，简化消息配置流程。

## 背景

租户对建档模块的消息在内容上很少有定制，大多只做签名替换。此前每新增一个贴牌都需要手动导入Excel模板，操作繁琐。

## 功能描述

### 短信模板

新增短信时可选择"使用通用模板"，只需录入"短信签名"字段即可实现导入。

### 邮件/待办/站内信模板

新增邮件、待办、站内信时可选择"使用通用模板"，即可实现自动导入。

## 与短信中台的配合

选择"无定制"时，系统自动同步一份通用模板至该租户下，同时配合[[短信中台]]的短信签名自动同步功能，实现一键配置。
