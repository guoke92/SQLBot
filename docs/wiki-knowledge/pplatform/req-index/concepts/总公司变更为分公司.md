# 总公司变更为分公司

## 概述

"总公司变更为分公司"是[[产融平台]]V1.15版本新增的一种企业信息变更类型，用于支持实际业务中总公司变为分公司的场景。此前[[讯易链]]建档不区分总分公司类型，迁移产融后根据讯易链推送的总分公司字段进行展示，产融平台支持总分公司功能。

## 业务规则

### 变更类型

认证方式=注册认证、邀请认证-客户录入、邀请认证-平台录入，且企业为总公司时，企业信息变更时，变更类型增加"总公司变更为分公司"。

### 变更方式配置

| 配置项 | 说明 |
|-------|------|
| 变更方 | 平台变更、企业自行变更（单选） |
| 验证方式 | 企业管理员授权、法人代表人授权（多选） |
| 企业角色 | 展示当前企业对应的全部企业角色（单选） |

**变更方规则**：
- 【邀请认证-平台录入】：默认变更方为"平台变更"，不支持选择。
- 其他认证方式：支持自行选择变更方式。

**其他默认行为**：
- 验证方式默认展示两种，自行选择。
- 企业角色默认展示全部，自行选择。

**互斥规则**：
"总公司变更为分公司"的变更项**不支持**与其他变更类型同时选中，提示："总公司变更为分公司"和其他变更类型不支持同时变更，请重新选择！

### 业务逻辑

点击"选择变更方式"弹窗【确定】按钮，根据变更方展示不同页面及提示，同时拉起对应企业信息变更流程。**产融平台传输本次变更类型的标识为变更为分公司。**

- **平台变更**：提示同现有流程。
- **企业自行变更**：
  - 企业管理员授权：提示同现有流程。
  - 法人代表人授权：提示同现有流程。

## 提交材料

该变更类型需提交"企业授权书"作为变更材料。

## 在变更类型列表中的位置

该变更类型位于现有变更类型列表的最后。
