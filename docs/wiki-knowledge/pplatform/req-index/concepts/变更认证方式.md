# 变更认证方式

变更认证方式是[[4-需求文档--18-产融平台v126版本需求文档0129--eyrepd|产融平台V1.26版本]]中针对企业自主注册认证失败场景新增的功能，旨在解决因存在关联资产而导致无法删除企业信息、无法重新认证的业务连续性问题。

## 问题背景
企业通过自主注册方式进行认证，若认证失败，原有流程支持通过【删除】企业信息后重新发起认证。但在实际业务中，企业可能在认证成功前已导入相关资产（如应收账款）。此时，由于存在关联资产，系统会阻止删除操作，导致企业认证流程卡死，业务无法继续。

## 解决方案
在V1.26版本中，当企业的认证方式为“自主注册”且认证状态为“认证失败”时，系统在操作列【删除】按钮后新增【变更认证方式】按钮。

### 操作流程
1. **触发**：管理员点击【变更认证方式】按钮。
2. **选择**：系统弹窗，提供三种认证方式选项：[[简易认证电子签章交互优化|简易认证]]、[[接口建档|接口认证]]、保持现状。
3. **确认**：
   - 选择一种新方式并点击【确定】，系统变更该企业的认证方式。之后，企业可以像其他认证失败的企业一样，通过【编辑】功能继续完成认证流程。
   - 点击【取消】则关闭弹窗，不进行任何操作。
