# 订单融资确认生效跳转优化

## 概述

订单融资确认生效跳转优化是产融平台V1.30版本的产品优化需求，调整订单融资项目中心【确认生效】按钮的处理逻辑，避免项目数据填写不完整就生效。

## 背景

订单融资需要在项目配置新增【暂存】操作，为避免项目数据填写不完整就生效，需要调整订单融资【确认生效】按钮处理逻辑。

## 优化方案

订单融资项目点击【确认生效】按钮，跳转至项目配置编辑页面，不直接生效项目。用户可在编辑页面完善数据后再进行生效操作。
