# 单点登录跳转至指定系统

## 概述

单点登录跳转至指定系统是产融平台V1.30版本的产品优化需求，针对[[中铁四局]]的定制化登录体验需求，在单点登录流程中支持根据配置直接跳转到特定业务系统。

## 需求详情

具体业务规则详见外部文档（doc.weixin.qq.com），由产品经理[[周水平]]负责。

## 与现有概念的关系

本需求延续了产融平台在标准化产品与满足大客户个性化需求之间的固有张力，与[[单点登录自动建档]]等概念相关但侧重不同——前者关注登录后的自动建档流程，本需求关注登录后的系统跳转目标。
