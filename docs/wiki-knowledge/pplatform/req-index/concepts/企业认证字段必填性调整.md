# 企业认证字段必填性调整

本文档记录了非自主认证建档流程中，产融平台企业建档字段的必填性调整需求，包括从非必填改为必填的字段以及运营中台需新增的字段。

## 从非必填改为必填的字段

以下字段在产融平台中当前为非必填，需改为必填：

### 企业信息模块
- **企业名称(英文)**：企业名称的英文翻译
- **注册省市**：企业注册所在省市
- **注册省市（英文）**：根据所选省市自动带出
- **是否分公司**：标识企业是否为分公司，为"是"时需要填写总公司信息和总公司法人信息

### 法定代表人信息模块
- **法人姓名（英文）**：法定代表人姓名的英文翻译

### 企业管理员信息模块
- **姓名（英文）**：企业管理员姓名的英文翻译
- **邮箱**：企业管理员邮箱

### 总公司企业信息模块（是否分公司为"是"时显示）
- **企业名称(英文)**：总公司企业名称的英文翻译
- **注册省市（英文）**：根据所选省市自动带出

## 运营中台需新增的字段

以下字段在运营中台中缺失，需新增，位于上传企业信息tab页中的有效期限后：

- **是否境外**：仅金融机构有该字段，单选（是/否），必填
- **外部机构**：仅金融机构有该字段，单选（是/否），必填

## 字段完整性对照

文档第6节定义了企业建档的完整字段列表，涵盖以下模块：

1. **企业基本信息**：企业角色、租户、产品、关联项目、认证方式、开通电子签章
2. **企业信息**：营业执照、企业授权书、企业名称、统一社会信用代码、营业执照有效期、注册省市、注册地址、注册日期、企业性质、所属行业、经营状态等
3. **法定代表人信息**：法人证件、姓名、证件类型、证件号码、证件有效期、出生日期、手机号码、邮箱
4. **企业管理员信息**：证件、姓名、证件类型、证件号码、证件有效期、出生日期、手机号码、邮箱
5. **总公司企业信息**（分公司时显示）：营业执照、企业名称、统一社会信用代码、营业执照有效期、注册省市、注册地址、注册日期
6. **总公司法定代表人信息**（分公司时显示）：法人证件、姓名、证件类型、证件号码、证件有效期、出生日期、手机号码
7. **银行账户**（供应商、经销商必填）：银行账户名、银行账号、银行名称、开户行所在城市、开户行、联行号、认证状态、是否默认账户、账户说明

## 运营中台字段可编辑性

银行账户相关字段在运营中台均为不可改状态。企业管理员手机号码和邮箱在运营中台也不可改。
