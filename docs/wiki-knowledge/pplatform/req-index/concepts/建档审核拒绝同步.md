# 建档审核拒绝同步讯易链

## 概述

V1.9版本要求在企业建档审核被拒绝时，将拒绝状态同步通知[[讯易链]]，以解决当前状态不一致的问题。

## 背景问题

当前存在以下数据不一致问题：
- 建档审核拒绝后，若产融重新提交时将原项目A改成B，讯易链该企业会**同时保存**项目A、B的关联关系
- 讯易链中除审核拒绝状态外，企业只关联一个项目时不能删除关联关系（至少要有一个项目）

## 处理方案

### 审核拒绝时

1. 企业建档审核拒绝时，产融将企业拒绝状态及项目关联关系的拒绝状态同步给讯易链
2. 讯易链翻转企业建档状态，同时去掉企业与项目的关联关系

### 重新提交时

1. 产融修改后重新提交建档审核，将企业信息及新的项目关联关系同步给讯易链
2. 讯易链更新企业信息及状态，同时增加企业与新项目的关联关系

## 设计要点

1. **双向状态一致**：确保产融和讯易链的企业建档状态保持一致
2. **关联关系清理**：拒绝时去掉旧的项目关联关系，避免脏数据残留
3. **重新提交时全量更新**：用新数据覆盖旧数据，确保一致性
