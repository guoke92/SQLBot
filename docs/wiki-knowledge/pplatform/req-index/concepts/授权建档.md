# 授权建档

## 定义

授权建档是产融平台V1.10版本中，第三方系统跳转至产融场景下的一个可配置开关。该开关控制企业从第三方系统跳转至产融平台时的初始认证状态和建档流程。

## 配置效果

| 授权建档状态 | 第三方跳转至产融时的企业状态 | 后续行为 |
|-------------|---------------------------|----------|
| 开启 | "已认证" | 企业可直接使用产融平台功能 |
| 关闭 | "认证中" | 运营中台自动拉起建档流程，企业需完成建档 |

## 数据交互流程

第三方系统跳转至产融的数据交互过程为：

```
外部系统 → 运营中台 → 产融平台
```

运营中台在此流程中承担数据中转和流程控制的角色。

## 变更控制

由第三方推送至产融侧的企业信息（含用户信息），后台可配置是否支持在产融上做变更：

- **一般情况**：不支持在产融发起变更
- **变更路径**：只能KA侧变更后再同步至产融

## 与企业认证的关系

授权建档本质上是对[[企业认证]]流程在第三方系统互通场景下的定制化控制。当授权建档关闭时，企业进入"认证中"状态，需要走完完整的建档流程才能获得"已认证"状态。
