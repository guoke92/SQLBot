# 参数一致性校验

参数一致性校验是 [[验证码缓存机制]] 中的关键安全保障措施。它确保在登录时复用缓存的验证码结果时，所使用的验证码参数必须与最初校验时完全一致，从而防止参数替换攻击。

## 实现方式

在 [[sso-cache-util]] 的 `checkBehaviorCaptchaCache` 方法中实现：

1.  **缓存存储**：在 [[行为验证码校验]] 成功时，将 `challenge|validate|seccode` 三个参数用竖线拼接成一个字符串，作为缓存值存入 [[redis]]。
2.  **参数比对**：在登录检查缓存时，将当前传入的 `challenge`、`validate`、`seccode` 参数以相同方式拼接。
3.  **字符串比较**：将拼接后的当前参数字符串与缓存中的值进行精确的字符串比较。只有完全一致，才认为参数校验通过。

## 安全意义

此机制确保了验证码的“绑定”关系。攻击者即使获取了缓存的验证结果，也无法通过替换其中的参数来通过校验，因为任何参数的改变都会导致拼接后的字符串不匹配。
