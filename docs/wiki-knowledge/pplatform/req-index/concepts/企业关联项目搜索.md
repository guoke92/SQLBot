# 企业关联项目搜索

## 概述

企业关联项目搜索是产融平台V1.23版本中在企业信息维护列表的二级表单中新增的项目名称查询条件，支持模糊搜索，便于运营人员快速定位企业关联的特定项目。

## 业务背景

企业关联多个项目时需要快速定位某个特定项目，此前缺少查询条件，无法快速搜索和定位，影响运营效率。

## 功能规则

- 企业信息维护列表展开二级表单企业信息时，增加项目名称查询条件
- 缺省值："请选择项目名称"
- 支持模糊搜索
