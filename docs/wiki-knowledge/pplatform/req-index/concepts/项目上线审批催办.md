# 项目上线审批催办

## 概述

项目上线审批催办是产融平台V1.35版本新增的功能，允许相关人员对处于"审批中"状态的流程发送企微通知，提醒当前审批人尽快处理，解决此前需人工线下确认待办人员的繁琐问题。

## 业务规则

### 当前审批人展示

项目上线管理页面新增"当前审批人"信息展示：
- 审批状态为"审批中"：取值当前任务待办人员
- 审批状态非"审批中"：显示"-"

### 催办按钮

- 操作列新增【催办】按钮
- 仅审批状态为"审批中"时展示

### 催办功能逻辑

1. 点击【催办】按钮，进行二次提醒
2. 操作频率控制：5分钟内不可重复催办
3. 触发企微通知

### 企微通知内容

- **发送对象**：当前审批所处的审批节点对应的人员
- **发送内容**：
  - 项目名称：取值项目配置名称
  - 产品名称：取值项目配置对应的产品名称
  - 租户名称：取值项目配置对应的租户
  - 信息提示：xxx进行催办：请尽快进行审批操作！（xxx取值点击催办按钮人员名称）
  - 详情：点击可进入对应H5项目审批办理页面
