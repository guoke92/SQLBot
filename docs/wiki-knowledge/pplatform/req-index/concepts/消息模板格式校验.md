# 消息模板格式校验

## 概述

消息模板格式校验是产融平台V1.35版本的配置准确性优化功能。此前部分场景下消息模板导入时未按消息类型进行格式校验，导致导入模板有误无法在实际业务中应用。本版本增加模板格式校验和短信签名一致性校验。

## 业务规则

### 模板格式校验

四种消息类型（短信、邮件、通知、待办）进行模板导入时，需分别校验导入的模板格式：
- 格式不符时提示："导入模板有误，请检查"
- 格式不符时无法导入成功

### 短信模板校验

- 短信列表下导入短信模板时，需对同一租户下的短信签名做一致性校验
- 不一致时提示："同一租户下短信签名需保持一致，请检查"

### 短信签名同步

后续短信模板配置处短信签名更新后，需自动同步至租户配置-基础信息配置-"产融平台短信签名"字段。

## 存量数据处理

存量租户的短信签名需要回显至租户配置-基础信息配置页。
