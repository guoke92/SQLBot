# 项目配置pro功能新增

## 概述

项目配置pro功能新增是产融平台V1.23版本中为配合多级流转业务而对项目中心进行的一系列功能增强，涵盖项目类型区分、快捷变更、生效流程优化、授权书版本提示等多个方面。

## 业务背景

多级流转业务的项目配置pro相较于标准项目配置有更复杂的管理需求。V1.23版本需要在产融平台的项目中心中增加相应功能，以配合多级流转侧的功能新增。

## 功能清单

### 1. 项目类型区分

项目中心菜单列表增加字段区分"项目配置"与"项目配置pro"：
- 仅针对多级流转项目该字段有值
- 查询条件同步新增该字段
- 该字段在新增项目时选择

### 2. 快捷变更

针对多级流转旧的项目配置（版本为"项目配置"的项目）增加"快捷变更"操作项：
- 点击后跳转多级流转界面
- 仅多级流转项目配置版本为"项目配置"的项目有该操作项

### 3. 生效流程优化

新增多级流转项目时，操作"生效"时进入编辑页面，表单上不再支持直接生效：
- 点击"确认生效"时进入编辑页面
- 增加审核环节，避免误操作

### 4. 授权书版本提示

核心企业关联新项目时，系统提示确认授权书版本能否覆盖新产品：
- 点击"提交"时提示："请提前确认核心企业的授权书是否能覆盖新产品，如不能覆盖，需联系企业补签"
- 仅针对存量迁移的企业存在该校验逻辑
- 设计意图：尽早提示相关同事联系企业签署授权书，避免实际业务时才发现授权书不覆盖

### 5. 关联企业页跳转

项目中心的关联企业页支持跳转企业关联项目配置的界面（1114新增），页面与从企业中心处看到的一致。

### 6. 修改日志（已实现）

项目中心菜单增加"修改日志"操作项，已生效和未生效的项目均可查看修改日志。经产品确认该需求已实现，无需新增开发。

### 7. 管理员编辑（多级流转实现）

项目配置pro的"管理员编辑"操作项因非高频使用功能，倾向于放到多级流转界面上实现。

## 与其他功能的关联

- 与[[线上保理支持二级租户]]同属项目中心的功能扩展
- 授权书版本提示机制可能影响后续其他产品线的项目关联流程
- "快捷变更"功能体现了从旧项目配置向项目配置pro迁移的过渡策略
