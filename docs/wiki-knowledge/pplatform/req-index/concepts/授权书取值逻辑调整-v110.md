# 授权书取值逻辑调整

## 变更内容

法务提出授权书参数调整要求，将授权书中的表述从"将【人】注册为用户"调整为"将【企业】注册为用户"。

### 调整前

```
将【${firstAuthRealName}】注册为平台用户，并按照平台要求完成实名认证
```

### 调整后

```
将【${custName}】注册为平台用户，并按照平台要求完成实名认证
```

## 变更影响

- `${firstAuthRealName}`：取值为经办人/法人的姓名（个人维度）
- `${custName}`：取值为企业名称（企业维度）

此调整体现了法务对授权书法律主体表述的规范化要求，将授权主体从个人层面提升至企业层面。
