# 租户配置默认值与模板初始化

## 概述

租户配置默认值与模板初始化是产融平台V1.35版本的效率优化功能。近期定制化平台需求量较大，为方便方案侧新增和配置定制化平台，创建新租户时系统自动带出自营租户的基础信息配置、注册配置和消息模板。

## 业务规则

### 租户管理列表

租户管理列表字段"短信签名"调整为取基础信息配置新增的"产融平台短信签名"字段。

### 基础信息配置

- 新增"产融平台短信签名"字段，位于"客服电话"前
- 必填，格式为纯文字，无需方括号（例如：讯易链）
- 创建新租户时自动带出自营租户的相关配置，包括本期新增的短信签名字段
- 红框内字段无需带出

### 注册配置

默认带出自营平台的配置。

### 消息模板

- "基础信息配置"完成点击【提交】时，系统按照自营平台的消息模板自动初始化
- 初始化范围：短信（短信签名取基础信息配置-产融平台短信签名）、邮件、通知、待办
- 短信签名变更后，需在基础信息配置调整签名【提交】后，同步更新消息模板配置-短信-短信签名
