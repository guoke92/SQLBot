# 关联关系回滚

关联关系回滚是V1.13版本的数据一致性修复需求，解决建档过程中因租户选择变更导致的关联关系重复问题。

## 问题场景

产融平台建档时选择[[租户]]并关联[[项目产融平台语境|项目]]，提交建档信息报错后，重新选择租户建档成功。此时产融平台会显示关联项目、开通产品重复——同时保留了第一次（失败的）和第二次（成功的）关联记录。

## 解决方案

产融平台建档首次选择租户建档报错，重新选择租户建档成功时：

1. **更新关联状态**：清理旧的关联关系
2. **只展示最新一次**关联成功的租户及项目名称
3. **只展示最新一次**开通的产品

## 设计意义

该修复确保了[[企业关联项目配置]]数据的准确性，避免因操作重试导致的数据冗余和业务逻辑混乱。
