# 建档影像件去重

## 概述

建档影像件去重是产融平台V1.35版本针对企业数据复制场景的优化功能。当企业数据因"统码+手机号"匹配从一个租户复制到另一个租户时，若目标租户已存在影像件，则不再接收接口推送的相同类型影像件，避免影像件冗余。

## 背景

企业在[[晶科畅融平台]]租户下没建档，但企业在自营建档成功。产融通过统码+手机号作为唯一性判断，如果满足条件，会复制自营的企业信息到晶科租户下。晶科推送的企业一般都有影像件，产融复制功能也会复制影像件，导致企业影像树出现两套影像件。

## 业务规则

- 本地化系统对接产融平台企业建档，如触发产融平台侧企业复制功能（即企业数据授权跨平台使用），产融平台侧已有的影像件类型以产融平台历史影像为准，不再接收接口推送的影像
- 除"子账户授权书"外其他影像件均需要复制
- 作为通用需求处理
