# 白名单机制

白名单机制是SSO验证码登录改造中提供的一种管理灵活性手段。它允许通过 [[nacos]] 配置中心设置正则表达式，使特定的系统渠道（`sysChannel`）能够绕过行为验证码校验。

## 工作原理

在 [[sso-code-provider]] 的 `validateCaptcha` 接口中，当检测到行为验证码参数不完整时，会优先检查白名单：

1.  从 [[nacos]] 读取配置的 `behaviorCaptchaWhitelistSysChannel` 字符串。
2.  将该字符串按逗号分割为多个正则表达式模式。
3.  将当前请求的 `sysChannel` 与每个模式进行正则匹配。
4.  若匹配成功，则直接返回 `true`，跳过后续的验证码校验和系统配置检查。

## 安全与管理考量

- **灵活性**：为内部系统、测试环境或特殊渠道提供了绕过验证码的便捷途径。
- **安全风险**：白名单是安全策略的例外，需要严格的管理和审计，避免被滥用。
- **配置管理**：白名单规则通过 [[nacos]] 进行动态管理，便于运维操作。
