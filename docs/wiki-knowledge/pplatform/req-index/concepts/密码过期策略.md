# 密码过期策略

## 概述

密码过期策略是SSO单点登录系统强制用户定期修改密码的机制，包括设置有效期、到期提醒和到期强制修改，满足"要求用户定期修改身份鉴别信息"的合规要求。

## 设计目标

- 满足定期更换身份鉴别信息的合规要求
- 提供灵活的配置能力，支持按业务系统差异化配置
- 平衡安全性与用户体验

## 配置参数

| 参数 | 说明 | 存储位置 |
|------|------|---------|
| pwdUpdateDays | 密码有效期（天数），0表示不强制 | 系统配置表 |
| pwdUpdateRemind | 密码过期提醒天数 | 系统配置表 |
| pwdUpdateTime | 用户密码最后更新时间 | [[sso-user]] 表 |

## 检查机制

系统在用户登录时自动检查密码是否过期：

### 检查逻辑

```
密码已过期：pwdUpdateTime + pwdUpdateDays <= 当前日期
密码即将过期：pwdUpdateTime + pwdUpdateDays - pwdUpdateRemind <= 当前日期
密码正常：pwdUpdateTime + pwdUpdateDays > 当前日期
```

### 处理流程

| 状态 | 处理方式 | 返回码 |
|------|---------|--------|
| 密码已过期 | 强制修改密码，不允许登录 | [[sso-result-code-enum\|30903]] |
| 密码即将过期 | 允许登录，提示用户修改 | [[sso-result-code-enum\|20904]] |
| 密码正常 | 允许登录 | - |

## 密码更新流程

用户修改密码时：
1. 系统记录 pwdUpdateTime 为当前时间
2. 将旧密码保存到 [[sso-user-pwd-history]]（密码历史表）
3. 更新 [[sso-user]] 表的密码字段和更新时间
4. 重置密码过期状态

## 关键代码逻辑

```java
Integer pwdUpdateDays = ssoSystemDO.getPwdUpdateDays();
if (pwdUpdateDays > 0 && null != ssoUserDO.getPwdUpdateTime()) {
    LocalDate plusDays = ssoUserDO.getPwdUpdateTime().plusDays(pwdUpdateDays).toLocalDate();
    long days = ChronoUnit.DAYS.between(LocalDate.now(), plusDays);
    if (days <= 0) {
        // 密码已过期，强制修改
        return new SSOResultDTO<>(SSOResultCodeEnum.SWITCH_CODE_30903);
    } else if (days <= ssoSystemDO.getPwdUpdateRemind()) {
        // 密码即将过期，提醒用户
        SSOResultDTO<String> result = new SSOResultDTO<>(SSOResultCodeEnum.CORRECT_CODE_20904);
        result.setMessage(String.format(result.getMessage(), plusDays));
        return result;
    }
}
```
