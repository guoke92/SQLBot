# "核心企业+资金方"角色组合

V1.21版本新增了【核心企业+资金方】的企业角色组合，扩展了[[企业角色与产品组合校验]]的规则。

## 背景

有项目上的资金方（类型为保理公司），希望以核心企业的身份向企业开单。交易结构为：企业将应收账款转让给保理公司，保理公司再向企业开出一张凭证，企业不会进行融资，持有凭证直到到期。

此前产融平台限制企业同时拥有【核心企业+金融机构】角色时，两个角色不可同时关联到多级流转的项目。本次需求放开该限制。

## 各产品支持的角色组合

| 产品 | 支持的角色组合 |
|------|--------------|
| 多级流转 | 【核心企业+供应商】、**【核心企业+资金方】**、【核心企业+运营方】、【资金方+运营方】 |
| 线上保理 | 【核心企业+供应商】、**【核心企业+资金方】**、【核心企业+运营方】、【资金方+运营方】、【项目公司+供应商】、【核心企业+项目公司】 |
| AMS | 【项目公司+供应商】 |
| 订单融资/经销商融资 | 【核心企业+供应商】、**【核心企业+资金方】**、【核心企业+运营方】、【资金方+运营方】、【供应商+经销商】 |
| 国内信用证 | 【核心企业+供应商】、【核心企业+运营方】、【资金方+运营方】 |

## 跨系统影响

[[讯易链]]1016版本也有该需求，会接收该类组合的推送。

## 潜在风险

角色组合的放宽可能与最初设计限制时的业务逻辑或风险控制考量存在张力，需要评估对现有业务流程和系统校验的影响。

## 优先级

本需求标记为【高】优先级。
