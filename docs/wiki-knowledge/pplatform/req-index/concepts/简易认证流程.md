# 简易认证流程

简易认证是产融平台中最简化的非自主认证方式。运营人员在后台录入企业信息后，系统自动审核通过，企业管理员仅需登录确认并进行人脸认证即可完成认证。

## 流程步骤

1. **后台新增企业**：运营在平台端新增企业并录入信息，提交后自动审核通过，企业状态为待客户确认并发送短信给企业管理员确认
2. **企业管理员确认**：企业管理员收到短信后登录客户端，点击待办确认认证信息并进行人脸认证，通过后企业认证成功

## 处理规则

### 企业管理员确认

企业管理员登录客户端，通过首页待办进入企业信息确认页，仅可查看审核通过的企业认证信息，并进行企业管理员人脸识别认证：
- 人脸认证不通过时联系运营处理

### CA证书与CFCA协议

- 若简易建档开通了CA，则在人脸认证通过后还需阅读并同意CFCA服务协议
- 若未开通CA，则人脸认证通过后即认证成功

### 人工识别机制

企业联系人页面增加按钮【人工识别】，展示条件：
- 企业状态为"待客户确认"
- 企业认证方式为简易认证
- 系统人脸识别状态为"识别失败"

点击人工识别按钮弹窗展示客户的人脸认证视频，可点击"识别成功"人工修改人脸认证状态为"识别成功（人工）"。

### 运营中台数据同步

需推送至运营中台生成审核通过的数据（影像和字段），核查项均为待核查。推送审核通过建档信息时触发信息同步到在途资产。

## 简易认证的特殊性

简易认证在变更流程中具有特殊地位：
- **企业信息变更**：默认平台变更，需运营中台处理数据同步
- **增加企业角色**：默认平台变更，自动生效，无需运营中台处理
- **企业管理员变更**：默认平台变更，自动生效，无需运营中台处理
- **重新建档**：根据变更方选择走对应建档流程，需要运营中台处理

详见 [[非自主认证变更流程]]。
