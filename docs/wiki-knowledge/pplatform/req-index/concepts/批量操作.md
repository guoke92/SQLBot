# 批量操作

批量操作是产融平台中通过文件导入方式一次性处理多条数据的功能，是提升运营效率的重要手段。V1.13版本新增了"批量关联项目"功能。

## 批量关联项目

### 功能入口

企业信息维护列表增加【批量关联项目】按钮。

### 操作流程

1. 点击【批量关联项目】展开弹窗
2. 下载Excel模板（"批量关联项目"sheet页）
3. 填写企业-项目关联信息
4. 上传文件

### 校验规则（按顺序执行）

| 序号 | 校验项 | 说明 |
| --- | --- | --- |
| 1 | 模板样式、文件格式 | 校验是否为系统模板及文件 |
| 2 | 字段内容 | 查询企业信息是否存在；企业认证状态=变更中不支持导入 |
| 3 | 业务逻辑 | 支持不同企业同时关联多个项目，不支持企业重复关联同一项目 |

### 导入限制

- 单次最大导入条数：**30条**

### 结果反馈

提示"本次共计导入x条，导入成功y条，失败x-y条，请下载文件查看错误原因"，支持下载错误原因文件。

## 与其他批量功能的关系

V1.13版本在已有"批量更换运营"功能基础上，新增了"单笔更换运营"功能，体现了批量与单笔操作的互补设计。
