# CA证书收费

## 概述

CA证书收费是产融平台V1.32版本推出的全新商业模式/产品功能点，对使用电子认证服务（CA证书）的用户开通收费模式。

## 需求背景

该功能体现了产融平台从基础功能向增值服务延伸的产品方向，由产品经理[[张彬伟]]（Vincent）负责。
