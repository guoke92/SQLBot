# 运营配置整合

运营配置整合是V1.13版本的架构优化需求，将分散在[[多级流转]]和产融平台的运营配置页面集成到产融平台一处，以提升运营操作效率。

## 背景

产融平台有【运营】配置的一级菜单，下有"租户运营配置"和"项目运营配置"两个二级菜单。在产融平台上线前，多级流转侧也实现了运营相关的配置功能，导致菜单分散在两个系统。

## 整合方案

### 租户运营配置合并

整合后的页面包含三个模块：

| 模块 | 来源 | 说明 |
| --- | --- | --- |
| 产融门户相关配置 | 产融平台原"租户运营配置" | 保留原有功能 |
| 多级公告配置 | 多级流转原"公告管理" | 迁移至产融平台 |
| 多级门户相关配置 | 多级流转原"贴牌配置" | 已迁移产融的贴牌，【自主注册】按钮置灰 |

### 项目运营配置合并

整合后的页面包含三个模块：

| 模块 | 来源 | 说明 |
| --- | --- | --- |
| 产融相关项目配置 | 产融平台原"项目运营配置" | 保留原有功能 |
| 多级相关项目配置 | 多级流转原"客服配置"-项目管理 | 已迁移产融的项目，【邀请信息配置】和【客服名片配置】置灰 |
| 邀请信息配置 | 产融平台新增 | 基于配置信息，客户登录且已关联项目时弹出指引页面 |

## 存量数据处理

多级流转侧存量已配置好的信息需要同步至产融平台。

## 与指引配置的关系

整合后的项目运营配置中新增的【邀请信息配置】功能，与[[指引配置]]概念直接关联——当客户完成登录且已关联项目时，可以弹出指引页面。

## 实施风险

本需求涉及跨系统的功能合并和存量数据迁移，实施复杂度较高，存在技术风险。多级流转侧已迁移至产融的项目/贴牌需要做按钮置灰处理，该部分需求产品需单独向多级流转提。
