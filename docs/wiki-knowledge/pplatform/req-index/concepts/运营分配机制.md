# 运营分配机制（产融平台语境）

运营分配机制是[[产融平台]]在[[数据迁移]]后新增的企业联系人管理功能，用于将企业联系人与运营人员进行关联。该机制与[[运营中台]]的派单功能紧密相关。

## 核心功能

### 分配运营

- 新增企业联系人时需要选择"运营"，调用运营中台的接口
- 对于联系人信息已在维护企业信息时新增的场景，在"企业联系人维护"列表的操作栏上新增【分配运营】按钮
- 仅当"运营"字段为空时该按钮才亮起
- 发送邀请短信和客服名片时需校验该字段是否有值，如无值则提示"请先完成分配运营，再向企业发送邀请码"
- 企业信息维护处的自动发送邀请短信功能取消

### 更换运营

- 支持单个【更换运营】和【批量更换运营】
- 批量更换时需上传excel模板，系统校验企业名称、项目名称、新运营人员姓名是否准确
- 下载的模板内企业名称、项目名称字段是动态生成的

### 发送客服名片

- 向客户发送短信，短信内包含客服二维码名片
- 派单的规则及生成客服名片的功能在运营中台生成，产融调用

## 表单字段

- **建档经办人**：产融自己使用，运营中台派单后产融从运营中台获取，不需要产融侧录入
- **运营**：产融录入，再传给业务系统，业务系统传给运营中台

## 与其他系统的关系

- 运营客服字段除产融自身派单时需要使用外，各业务系统资产/审核派单时也需要使用
- 产融要将运营字段传给业务系统
- 该部分由运营中台牵头，运营中台计划放8月份的版本，产融配合
