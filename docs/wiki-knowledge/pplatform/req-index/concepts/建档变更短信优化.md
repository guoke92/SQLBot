# 建档变更短信优化

## 定义

建档变更短信优化是[[产融平台]]V1.22版本中对建档和变更审核相关短信模板的优化。核心变更为区分线上签署和线下签署授权书两种场景，使用不同的短信模板。

## 背景

此前企业签署授权书提醒短信仅适用于线上签署场景，实际业务中存在线下签署时，短信内容需根据业务场景做调整。

## 业务规则

### 现有短信模板调整

现有短信模板标题增加"-线上"说明：
- "邀请认证-客户录入-审核通过" → "邀请认证-客户录入-审核通过-**线上**"
- "企业变更-客户提交-审核通过" → "企业变更-客户提交-审核通过-**线上**"

适用于线上签署授权书场景。

### 新增短信模板

新增短信节点及模板：
- "邀请认证-客户录入-审核通过-**线下**"
- "企业变更-客户提交-审核通过-**线下**"

适用于线下签署授权书场景，包含回寄授权书相关信息。

## 与现有功能的关系

本需求是对现有短信通知体系的增量优化，不改变短信发送的基本机制，仅增加场景区分能力。
