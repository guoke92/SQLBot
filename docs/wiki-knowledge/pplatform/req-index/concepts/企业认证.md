# 企业认证

企业认证是[[chanrong-platform|产融平台]]企业入驻的核心流程，决定了业务开展的起点。企业认证审核流程复用[[operation-mid-platform|运营中台]]的建档自动化设计。

## 认证方式

产融平台定义了四种认证方式：

| 认证方式 | 说明 |
|---|---|
| 注册认证 | 客户通过自主注册触发认证流程 |
| 邀请认证-客户录入 | 平台邀请，客户录入企业信息并提交 |
| 邀请认证-平台录入 | 平台邀请，平台代为录入企业信息，客户确认 |
| 简易认证 | 平台提交客户信息，客户确认即可，审核流程简化 |

## 企业状态机

### 注册认证状态流转

```
待客户提交 → 审批中 → 认证成功 / 认证失败 / 退回
```

- 认证成功后可操作：变更、关联项目、冻结、注销
- 认证状态为冻结时可解冻恢复
- 注销操作不可撤回

### 邀请认证-客户录入状态流转

```
初始化 → 待客户提交 → 审批中 → 认证成功 / 认证失败 / 退回
```

### 邀请认证-平台录入状态流转

```
初始化 → 审批中 → 待客户确认 → 认证成功 / 认证失败 / 退回
```

### 简易认证状态流转

```
待客户确认 → 认证成功 / 冻结 / 注销
```

## 认证与产品开通的关系

企业认证是产品开通的前提条件。根据认证状态不同，产品中心的功能存在显著差异：

- **未认证/认证中/认证失败**：产品全部显示为未开通，无法进行任何产品操作
- **已认证**：根据产品开通状态、用户角色、授权书版本等因素展示不同的操作按钮

## 授权书版本

认证涉及两种授权书版本：
- **新版授权书**：已提供新版授权书的被授权人拥有完整操作权限
- **存量授权书**：存量授权书的被授权人在开通新产品时需补签新版授权书，或需要联系平台客服

## 不同角色的认证处理

| 企业角色 | 认证处理方式 |
|---|---|
| 新供应商 | 发起认证跳转运营中台认证界面 |
| 核心企业 | 自动建档暂不支持，可能需走旧非自主建档流程 |
| 资金方 | 简易建档不做审核，提交后自动审核通过 |
| 经销商/项目公司 | AMS旧客户跨产品开通需走企业升级流程 |

## 经办人认证

经办人在首次签署合同前，需补充个人身份证件信息并完成人脸识别，认证通过后才能签署合同。这与企业认证是独立的流程。
