# 银行账户维护权转移

银行账户维护权转移是V1.13版本的一项架构调整，将简易认证企业的银行账户信息维护责任从产融平台转移至业务系统。

## 背景

此前，产融平台首次同步企业信息及银行账户至业务系统后，再次进行银行账户信息修改不会同步至业务系统，造成数据不一致。

## 变更内容

### 产融平台侧

认证方式=[[简易认证升级建档|简易认证]]的企业进行建档时，支持维护银行账户信息。建档信息提交成功、企业认证状态变为"认证成功"、企业信息推送各业务系统后：

- 产融平台-企业信息**不再展示"账户信息"模块**
- 后续银行账户需在各业务系统自行维护

### 多级流转侧

[[多级流转]]需放开企业信息-银行账户信息的编辑功能，以承接从产融平台转移过来的维护职责。

## 设计影响

这一变更改变了原有的数据管理集中模式，将银行账户维护权下放到业务系统。虽然旨在解决旧的数据同步不一致问题，但可能带来新的数据一致性挑战——各业务系统需独立维护银行账户数据。
