# 产融平台V1.31版本需求文档（0604）.docx

产融平台V1.31版本

需求说明书

修订记录

需求目录

【运营配置】未迁移租户在产融平台配置及应用

用户故事

目前产融平台已有项目运营配置、租户运营配置功能，同时讯易链也有相关配置，入口较多，运营侧提出归集统一入口，本期需进行调整。

业务流程

详见需求

配置项

无

业务规则描述

内管端

租户运营配置

数据范围

产融平台租户运营配置列表数据调整为全部租户，包括产融平台现有租户和未迁移产融平台的租户，即后续全部租户均在产融平台侧维护（微企链贴牌除外）。

业务逻辑

未迁移租户在产融平台配置租户运营配置后，支持在客户端应用。

在线客服

本期产融平台增加“智能客服按钮颜色”配置项，开启智能客服时该字段必填，迁移产融平台的租户默认展示租户主题色，支持修改。该字段同步影响产融平台侧边栏颜色展示。

产融平台-租户运营配置-“开启智能客服、智能客服渠道号、智能客服按钮颜色”字段内容与讯易链-客服配置-贴牌配置-【在线客服】内容对应。该配置项双方维度一致：均为租户维度（贴牌维度）。后续讯易链【在线客服】调整为产融平台配置，仅调整数据维护入口，应用逻辑仍由讯易链实现。

产融平台

讯易链

自主注册配置

产融平台-租户运营配置-建档相关配置-“项目码是否必填、默认关联的项目”字段内容与讯易链-客服配置-贴牌配置-【自主注册配置】-“项目专属服务码必填、默认关联项目”内容对应。该配置项双方维度一致：均为租户维度（贴牌维度）。后续讯易链该内容调整为产融平台配置，仅调整数据维护入口，应用逻辑仍由讯易链实现。

产融平台

讯易链

回收授权书标识

产融平台-租户运营配置-建档相关配置-“是否需回收授权书标识”字段内容与讯易链-客服配置-贴牌配置-【修改】-“授权书归档”内容对应。该配置项双方维度一致：均为租户维度（贴牌维度）。后续讯易链该内容调整为产融平台配置，仅调整数据维护入口，应用逻辑仍由讯易链实现。

产融平台

讯易链

项目运营配置

数据范围

产融平台项目运营配置列表数据调整为全部项目，包括产融平台现有项目和未迁移产融平台的项目，即后续全部项目均在产融平台侧维护（微企链项目除外）。

业务逻辑

未迁移项目在产融平台配置项目运营配置后，支持在客户端应用。

邀请信息配置

产融平台-项目运营配置-“邀请信息配置”模块与讯易链-客服配置-项目管理-【邀请信息配置】内容对应。该配置项双方维度一致：均为项目维度。后续讯易链【邀请信息配置】调整为产融平台配置，仅调整数据维护入口，应用逻辑仍由讯易链实现。

产融平台

讯易链

客服名片配置

本期产融平台增加“建档运营名片配置”配置项，非必填，单选，枚举：是（默认值）、否。微企链渠道不展示该字段。

产融平台-租户运营配置-“客服名片类型”字段内容与讯易链-客服配置-项目管理-【客服名片配置】-“客服二维码配置”内容对应。该配置项双方维度不一致：产融为租户维度，讯易链均为项目维度。后续讯易链【客服名片配置】调整为产融平台配置，仅调整数据维护入口，应用逻辑仍由讯易链实现，涉及映射关系处理，详见下文“关联系统及相关改造”部分。

产融平台

讯易链

产融平台-项目运营配置-“建档运营名片展示”字段内容与讯易链-客服配置-项目管理-【客服名片配置】内容对应。该配置项双方维度一致：均为项目维度。后续讯易链【客服名片配置】调整为产融平台配置，仅调整数据维护入口，应用逻辑仍由讯易链实现。

产融平台

讯易链

是否回填建档运营

产融平台-项目运营配置-“是否回填建档运营”模块与讯易链-客服配置-项目管理-【修改】-“建档运营回填”内容对应。该配置项双方维度一致：均为项目维度。后续讯易链该自动调整为产融平台配置，仅调整数据维护入口，应用逻辑仍由讯易链实现。

客户端

上述配置内容在客户端的展示效果取值逻辑调整为取产融平台维护的内容。

存量数据/在途数据的处理

升级原则：产融平台本期新增未迁移租户和未迁移项目，需要讯易链将已配置内容同步至产融平台；

客户名片类型：产融平台为租户维度，讯易链为项目维度。本期讯易链按照产融平台维护的内容处理历史数据，即某租户下项目全部处理为产融租户维度配置的内容；

建档运营名片展示：产融平台本期新增该字段，需要讯易链将已配置内容同步至产融平台。

关联系统及相关改造

本期讯易链客服配置部分功能调整为产融平台实现，讯易链侧需同步改造。

取值逻辑

项目管理：

【邀请信息配置】：取产融平台-项目运营配置-“邀请信息配置”，见“4.4.1内管端-项目运营配置-邀请信息配置”。

【客服名片配置】：

客服二维码配置：取产融平台-租户运营配置-“客服名片类型”。产融平台为租户维度配置，讯易链为项目维度配置。后续产融平台维护后，讯易链需将该贴牌下项目的客服二维码类型同步处理为产融平台贴牌维度维护的名片类型。

建档运营名片展示：取产融平台-项目运营配置-“建档运营名片展示”，见“4.4.1内管端-项目运营配置-客服名片配置”。

贴牌配置

【在线客服】、【自主注册配置】、【授权书归档】：见“4.4.1内管端-租户运营配置”需求内容。

入口屏蔽

按钮屏蔽

客服配置-项目管理：顶部按钮【修改】，操作列按钮【邀请信息配置】、【客服名片配置】、【查看邀请信息】均做屏蔽。

客服配置-贴牌配置：顶部按钮【修改】，操作列按钮【在线客服】做屏蔽。

字段隐藏

客服配置-贴牌配置-【自主注册配置】-“项目专属码服务码必填、默认关联项目”字段隐藏。

页面样式

页面样式调整为步骤条样式，共3个步骤：①人员管理、②配置管理、③文件管理

人员管理：

模块即小标题样式，参考样式如下：

【项目基础信息】模块

字段：项目ID、项目名称、租户名称、项目归属、产品类型、立项审批编号、项目码、项目标签、运营项目归属

【人员信息配置】模块

字段：运营对接人A、运营对接人B、运营组别、查验对接人、查验组别、风控对接人A、风控对接人B、风控组别、方案经理、业务经理、关联业务部门、同步修改企业对接人

【关联企业】模块

字段：现有【关联企业】模块内容及样式。

配置管理

项目基础信息：项目ID、项目名称、租户名称、产品类型

【项目配置】模块

字段：是否发送邮件（微企链不展示）、运营对接人名称（微企链不展示）、运营对接人邮箱（微企链不展示）、是否回填建档运营（微企链不展示）、建档运营名片（本期新增，微企链不展示）、自定义字段一、自定义字段二、自定义字段三

该模块字段微企链不展示

【邀请信息配置】模块（微企链不展示）

字段：现有【邀请信息配置】模块内容及样式。

【公告配置】模块（微企链不展示）

字段：现有【公告配置】模块内容及样式。

文件管理

模块：注册建档、整理资料、资产查验、风控审核、其他

样式：每个模块支持【新增】多条数据，模块字段：标题（文本框）、描述（文本框）、创建人（系统自动生成）、创建时间（系统自动生成）、更新人（系统自动生成）、更新时间（系统自动生成）、文件上传（不限制文件大小及份数），前述字段均为非必填。
