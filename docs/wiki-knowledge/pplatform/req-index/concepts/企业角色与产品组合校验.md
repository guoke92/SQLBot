# 企业角色与产品组合校验

## 概述

企业角色与产品组合校验是产融平台V1.6版本新增的强制校验规则，在内管端新增企业、企业关联项目时，强制校验企业角色与产品的兼容性以及角色组合的合法性，防止无效配置。该规则直接服务于首批数据迁移前的数据质量保障。

## 各产品支持的角色

| 产品 | 支持的角色 |
| --- | --- |
| [[多级流转]] | 供应商、核心企业、资金方、运营方、平台方（唯一，即环融联易） |
| [[线上保理]] | 供应商、核心企业、项目公司、资金方、运营方、平台方（唯一，即环融联易） |
| 订单融资/经销商融资 | 供应商、经销商、核心企业、资金方、运营方、平台方（唯一，即环融联易） |
| 国内信用证 | 供应商、核心企业、资金方、运营方、平台方（唯一，即环融联易） |
| AMS | 供应商、核心企业、项目公司、资金方 |

**特殊说明**：【核心企业管理机构】角色是搭建产融时新增的用于开展集团业务的角色，目前业务系统还未正式使用。

## 支持的角色组合

| 产品 | 支持的角色组合 |
| --- | --- |
| 多级流转 | 核心企业+供应商、核心企业+运营方、资金方+运营方 |
| 线上保理 | 核心企业+供应商、核心企业+运营方、资金方+运营方、项目公司+供应商、核心企业+项目公司 |
| AMS | 项目公司+供应商 |
| 订单融资/经销商融资 | 核心企业+供应商、核心企业+运营方、资金方+运营方、供应商+经销商 |
| 国内信用证 | 核心企业+供应商、核心企业+运营方、资金方+运营方 |

> 后续可能会根据业务诉求增加支持更多的角色组合。

## 校验行为

### 新增企业

当【企业角色】和【产品】不匹配时，立即提示"当前产品不支持该角色，请调整"：
- 先选角色再选产品：出现提示并清掉已选产品
- 先选产品再选角色：出现提示并清掉已选角色

### 给企业新增角色

产融侧给企业增加角色时**不做校验**。

### 企业关联项目

- 角色与产品不匹配：同新增企业的校验逻辑
- 角色组合不支持：点击【提交】时提示"系统暂不支持该角色组合：X（已有角色）+X（计划新增角色），请调整"，提交不成功

## 与数据迁移的关系

该校验规则是 [[数据迁移]] 准备工作的重要组成部分，确保迁移前后的数据配置符合业务规则，避免无效的角色-产品组合进入系统。
