# 渠道码

渠道码是[[chanrong-platform|产融平台]]为每个[[project-chanrong|项目]]生成的唯一标识码，用于邀请注册等场景。

## 生成规则

- **生成时机**：项目同步至产融侧时自动生成，生成1次即可
- **生成规则**：产品名称的首字母组合+数字串
- **格式示例**：XSBL00997971973、DJLZ19376193619730
- **长度限制**：32字符

## 使用场景

渠道码主要用于邀请注册场景。平台端通过企业关联项目的邀请注册功能，可向企业发送包含项目渠道码的邀请短信。

## 与营销的关系

渠道码是实现从项目营销转平台营销模式的技术手段，通过渠道码可以：
- 精准关联客户与具体项目
- 实现注册来源溯源
- 支持平台营销场景下的精准化运营
