# 移动端H5/小程序方案

## 概述

移动端H5/小程序方案是[[产融平台]]V1.14版本的核心新增功能，旨在为各贴牌迁移后的移动端业务提供统一入口和交互逻辑。该方案采用复用[[讯易链]]小程序外壳、内部跳转产融平台H5页面的混合架构。

## 技术方案

### 系统交互架构

```
用户 → 讯易链小程序（外壳） → 产融平台H5页面
                                    ↓
                              运营中台（蜜蜂e证）
```

- 讯易链小程序提供外壳和入口
- 产融平台H5页面承载业务功能
- [[蜜蜂e证]]小程序完成企业建档和变更操作

### 业务流程

1. 产融平台录入企业信息
2. 根据认证方式生成待办，发送短信
3. 客户点击H5链接或扫码小程序二维码登录
4. 选择企业（多企业场景下）
5. 点击首页待办
6. 自动跳转"蜜蜂e证"小程序

## 功能清单

### H5/小程序端功能

| 功能模块 | 说明 | 样式来源 |
|---------|------|---------|
| 首页 | 不展示注册入口 | 讯易链当前首页样式 |
| 在线客服 | 内容及逻辑同PC端 | 产融平台PC端 |
| 登录页 | 默认账号密码，支持切换验证码 | 产融平台PC端 |
| 忘记密码 | 重置密码页 | 产融平台PC端 |
| 实名认证 | 如有需要 | 产融平台PC端 |
| 默认企业 | 多企业角色时自动进入默认企业 | 产融平台PC端逻辑 |
| CFCA协议阅读 | 如有需阅读的协议，霸屏展示 | 产融平台PC端 |
| 选择企业 | 支持切换企业，抽屉展示全部企业 | 产融平台定制样式 |
| 我的产品 | 展示企业下开通的产品及状态 | 产融平台PC端 |
| 我的待办 | 仅展示产融平台待办 | 产融平台PC端 |
| 我的 | 账号信息、企业名称、用户角色 | 讯易链当前样式 |
| 企业基本信息 | 结构化数据及影像件 | 讯易链当前样式 |
| 退出登录 | 跳转登录页 | — |

### 简易认证流程

简易认证不经过[[运营中台]]，由产融平台自行处理：
1. 信息确认
2. 身份确认
3. 协议确认

### 渠道

- **H5**：产融平台生成H5链接，点击后展开登录页
- **小程序**：产融平台生成小程序二维码，微信扫码后展开登录页

## 业务产品交互

- **多级流转**：产品状态=开通中或已开通但不满足条件时提示"请先前往PC端补充资料"；已开通且满足条件时跳转多级流转小程序
- **其他业务产品**：提示"该功能暂未开通，敬请期待"

## 设计考量

选择该混合方案的主要考量是迁移成本：讯易链侧小程序功能较为完善，复用现有外壳可降低开发和迁移成本，同时通过H5页面实现与产融平台的统一交互。
