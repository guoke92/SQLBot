# 项目名称修改

## 概述

V1.9版本（遗留需求，预计线上保理一月版本实现）支持对项目名称进行修改，需要与多个关联系统协调确认。

## 功能描述

- 项目名称后方增加编辑图标
- 点击后出现修改项目名称的弹窗
- 点击确定后关闭弹窗并更新项目名称

## 跨系统协调

项目名称修改需要与以下系统确认：
- [[讯易链]]
- 订单融资
- 信用证
- [[ams]]

## 开放问题

具体修改后的跨系统同步方案待各系统确认。
