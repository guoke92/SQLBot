# 企业信息变更：平台录入企业支持自行变更

V1.21版本对[[企业信息变更]]流程进行了优化，使通过平台录入方式建档的企业也能够发起"企业自行变更"。

## 背景

此前，使用平台录入方式建档的企业在发起变更时不支持"企业自行变更"。原因是变更时可能触发人脸识别，但[[运营中台]]不支持证件类型非身份证的用户进行人脸识别，导致流程阻塞。

## 业务规则

当满足以下条件时，企业信息变更和联系人变更支持选择【企业自行变更】：

- 企业认证方式 = 平台录入
- 管理员证件类型 = 身份证
- 法人证件类型 = 身份证

## 适用场景

- 企业信息变更
- 联系人变更

## 优先级

本需求标记为【高】优先级。
