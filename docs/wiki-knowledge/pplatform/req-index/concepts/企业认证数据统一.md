# 企业认证数据统一

企业认证数据统一是[[产融平台]][[数据迁移]]的两大核心目标之一，指企业只需在产融平台认证一次，即可申请开通多个产品，简化客户侧的操作。

## 目标

- 通过产融平台新增的用户，其认证数据为一份，基于该份数据可申请开通各产品
- 业务系统存量企业在往产融迁移时，如果在讯易链和AMS上都有建档，需要做[[企业数据合并]]，保留一条

## 实现方式

### 新用户

新用户在产融平台完成注册和认证后，认证数据即为一份统一数据，可申请开通多个产品。

### 存量用户迁移

存量企业从讯易链和AMS迁移至产融平台时：
- 仅在一个平台有建档的企业，直接迁移
- 在两个平台都有建档的企业，通过企业数据合并策略保留一条数据

### 跨租户数据同步

当一个企业在A租户下已建档，且A租户允许数据共享时：
- 企业可将建档数据同步至B租户，无需重复认证
- 同步后需补签新租户的企业授权书
- 使用【统一社会信用代码+手机号】进行匹配

### 企业授权书统一

- 产融平台使用通用版建档自动化流程，授权书为最新版本
- 配置维度在[[租户]]层面（原多级流转、订单融资和线上保理在项目维度）
- 讯易链暂不做改造，项目配置内仍保留企业授权书

## 与其他目标的关系

企业认证数据统一与[[产品入口统一]]互为支撑：认证数据统一是入口统一的数据基础，入口统一是认证数据统一的用户体验体现。
