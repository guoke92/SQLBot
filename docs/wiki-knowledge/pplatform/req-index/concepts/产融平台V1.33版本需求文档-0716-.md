【客户录入】批量导入优化

用户故事

近期大批量客户开展业务，运营侧提出为提升建档审核效率，将对客户录入模式下建档流程优化，包括建档字段必填性，提交客户端流程等。

业务流程

详见需求

配置项

无

业务规则描述

内管端

建档方式：客户录入，走以下逻辑：

批量导入

模板更新如下：客户录入-企业信息导入模板.xlsx

业务逻辑

数据异常：任意一条数据异常，则批量导入失败，并在异常数据后标记原因，支持下载错误文件；

自动提交：导入成功后自动提交建档，即导入成功后认证状态更新为“待客户认证”，同时触发客户端待办和其他建档通知；

异步导入：该功能支持异步导入。

【线下授权书】自动生成电子版授权书

用户故事

法务出于风险管控的角度，优化线下授权书归档及线下签署授权书场景，并调整建档、变更授权环节短信及页面展示内容，同时建档通过后自动调用CFCA签章签署线上电子版授权书。

业务流程

详见需求

配置项

无

业务规则描述

客户端

业务场景

建档：自主建档、客户录入；

变更：企业自行变更（全部建档方式下）。

上述（1）或（2）场景下涉及线下签署授权书，均需生成电子版授权书。

涉及线下签署授权书场景：注册（客户录入、自主注册）、变更

企业类型

供应商、核心企业、金融机构、项目公司

调整内容

租户运营配置：

增加“生成电子版授权书（必填，单选）：是、否（默认值）”配置项，字段悬浮提示：适用于线下签署授权书。

历史数据处理：自营租户配置为“是”，其他租户均为“否”。

页面提示：

运营中台建档、变更页面调整展示内容：查询产融平台-租户运营配置-“生成电子版授权书：是、否”展示对应提示内容，同时影响后续电子版授权书生成。

业务逻辑

在平台线下签署授权书客户，在建档、变更完成且开通CFCA证书后，系统自动生成电子版本的授权书并调用CFCA证书签章，放在企业影像树信息的“企业授权及确认书（电子签约版）”（本期新增文件夹）文件夹下，按照增量保存不做覆盖，客户端企业信息菜单需同步展示，无需同步业务系统。原线下签署的授权书同时需要保留。

端口

PC端和小程序端均需处理。

存量数据/在途数据的处理

无

关联系统及相关改造

无

验收重点描述

以需求为准

用户故事

只有立项审批通过的数据才能进行编辑，现阶段发现很多方案经理会忘记维护立项统计数据，后续影响项目上线审批发起，故期望可以定时进行提示；

配置项

业务规则描述

内管端

需每天早上10点在“产融项目审批”这个应用发送企微消息提醒，要求如下：

消息提醒范围：项目立项统计页面，立项发起时间为2026年之后的立项审批状态为“审批通过”且“方案经理”为空的数据，均需进行提醒；
