# 项目管理看板数据隔离

项目管理看板数据隔离是[[4-需求文档--18-产融平台v126版本需求文档0129--eyrepd|产融平台V1.26版本]]中针对[[项目管理看板]]功能的优化，旨在解决因与项目中心共用底层数据表而导致的操作记录混杂问题。

## 问题背景
项目管理看板功能基于项目中心底层逻辑实现，两者共用一张数据表。在实际业务中，这两个模块由不同部门的同事负责。由于数据未完全隔离，操作记录（如“更新人/更新时间”）会相互覆盖，给后续工作追溯和审计带来不便。

## 优化方案
对“更新人”和“更新时间”字段的取值逻辑进行调整，实现操作记录与业务场景的隔离：

1. **项目管理看板“更新人/更新时间”**：
   - **取值逻辑**：仅记录对“项目运营配置”菜单进行操作的用户和操作时间。
   - **隔离说明**：此字段与项目中心菜单下的“更新人/更新时间”字段**完全无关**。对“关联企业维护”等其他操作不影响此字段。

2. **项目管理看板“关联企业-更新人/更新时间”**：
   - **取值逻辑**：仅记录对关联企业进行“运营人员”维护操作的用户和操作时间。
   - **隔离说明**：此字段与“企业关联项目”的操作和时间**完全无关**。
