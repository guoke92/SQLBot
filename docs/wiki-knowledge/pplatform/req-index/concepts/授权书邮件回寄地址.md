# 授权书邮件增加回寄地址

V1.21版本对[[授权书变更]]相关的邮件模板进行了优化，增加了授权书回寄地址信息，以提升运营同事处理企业业务的效率。

## 背景

此前授权书邮件内容较为简单，实际业务中线下签署授权书发送邮件时需附带相关说明及回寄信息。

## 业务规则

### 回寄信息来源

为保证系统间信息一致性，产融平台侧增加查询授权书回寄信息，信息源为[[运营中台]]，由运营中台提供接口。

### 邮件模板

**企业建档场景**：
- 标题：【${platform}】企业授权确认书
- 正文包含操作指引及回寄地址信息

**企业变更场景**：
- 标题：【${platform}】变更授权确认书
- 正文包含操作指引及回寄地址信息

### 邮件参数

| 参数 | 说明 | 来源 |
|------|------|------|
| `${platform}` | 贴牌平台名称 | 系统配置 |
| `${webUrl}` | 贴牌平台PC端地址 | 系统配置 |
| `${operationUser}` | 回寄信息收件人 | 运营中台 |
| `${operationUserAddress}` | 回寄信息收件地址 | 运营中台 |
| `${operationUserPhone}` | 回寄信息收件号码 | 运营中台 |

## 优先级

本需求标记为【高】优先级。
