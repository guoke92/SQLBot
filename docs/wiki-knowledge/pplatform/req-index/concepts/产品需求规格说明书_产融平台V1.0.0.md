需求概述

1.1.背景及目标

建设产融平台希望实现的价值点：

（1）产融平台“扎下去”：讯易链平台升级为产融平台，即集成现有SaaS产品，未来也可持续上架新产品

支持从项目营销转平台营销模式，提升一个客户多产品业务落地效率

提升客户体验，通过统一门户，自主注册，一次建档即可等产品改进，全面提升客户多产品的业务体验

产品间可互相引流，支持客户营销做广、做深

（2）产品建设“快起来”：建设产融平台底座，提炼通用模块适配新旧产品

提升新产品建设效率，复用产融通用模块，无需重复再造

改善讯易链以项目制需求建设的方式，通过逐步拆解提炼通用模块，实现存量产品改善

（3）赋能本地化客户：SaaS和本地化统一，本地化客户也能享受最新产品和服务方案

客户营销所见即所得，可将最新的SaaS产品进行本地化部署

可实现央国企客户有将SaaS转为本地化建设诉求

验收重点描述

企业审核

对接运营中台流程：

1.新供应商：（1）发起认证——跳转运营中台的认证界面；（2）变更——网关选择是网关发起变更还是客户端发起变更，如是网关发起变更，审核完成之后，客户端需要做【信息确认】，调用运营中台界面；如是客户端发起变更，客户端会收到待办，通过待办进入运营中台变更界面；

2.核心企业：目前自动建档的流程暂不支持，如果产融上线时运营中台仍未实现，需要走旧的非自主建档流程，旧流程产品经理需要再确认一下；

3.资金方：简易建档不做审核，提交企业信息后自动审核通过；变更也不审核；

4.旧的AMS的客户（比如项目公司）要开通其他产品时，需要补充企业材料，可走【企业升级流程】，调用运营中台建档页面；

5.部分客户签署的授权书版本要升级，走变更流程，使用运营中台现有页面；

6.给企业新增角色时，如是新增核心企业角色，先在产融内管发起角色变更，选择要新增的角色并上传授权书，提交后调用运营中台建档流程，待审核完成之后，该企业才算获得核心企业角色；如是核心企业新增供应商角色，可自动生效。
