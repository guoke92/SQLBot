# 短信模板调整（V1.25）

## 概述

V1.25版本对客户开户被授权人发送的邀请码短信内容进行优化，将"邀请码"字样调整为更准确的业务含义表述。

## 背景

客户开户被授权人发送邀请码短信内容中，目前提示"邀请码"字样，实际业务中该邀请码为首次登录密码，为明确业务含义进行优化。

## 业务规则

详见短信模板数据文件，主要调整短信中"邀请码"相关表述，使其更准确地反映实际业务含义（首次登录密码）。
