# 联行号搜索

## 定义

联行号搜索是[[产融平台]]内管端在企业建档添加银行账户信息时，通过联行号进行模糊查询的功能。该功能在V1.19版本中引入，解决了此前银行账户信息查询条件不足的痛点。

## 业务背景

在V1.19版本之前，企业建档添加银行账户信息时，查询条件仅有"省份、城市、支行名称"三项，缺少联行号搜索功能，导致运营人员在查找特定银行账户时效率较低。

## 业务规则（V1.19版本）

内管端新增企业信息 → 账户信息 → 新增账户 → 联行号弹窗查询条件调整如下：

1. **现有查询条件调整**："省份、城市、支行名称"三项查询条件位置调整，从左到右依次排列
2. **新增查询条件**：本期新增"联行号"查询条件，支持**模糊搜索**

## 关联上下文

- 联行号搜索功能属于企业建档流程中银行账户录入环节的优化
- 与需求7（核心企业增加供应商角色时增加录入收款账户）形成配合，共同完善银行账户相关功能
