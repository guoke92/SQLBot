# 客户端置灰优化

## 概述

客户端置灰优化是[[色调配置]]功能的重要增强，解决平台操作人员在全量置灰（如哀悼日）场景下忘记恢复彩色的问题，同时支持按租户灵活控制。

## 背景

在某些特殊场景（如哀悼日）下，需要将所有租户的客户端设置为灰白色调。原有流程存在以下痛点：
- 操作人员容易忘记将灰白色调恢复为彩色
- 个别客户强烈要求不灰白但无法单独处理

## 功能规则

### 定时自动恢复

平台操作人员点击【客户端置为灰白】按钮时：
- 弹窗中选择恢复彩色的日期
- 增加一个置为灰白的**开始日期**设置
- 到达设定时间后，所有租户客户端自动恢复彩色
- 未到置为灰白的开始日期时，可重新点击修改日期
- 已到置为灰白的开始日期时，只有恢复彩色的按钮可用

### 按租户手动恢复

全量租户客户端已置为灰白时：
- 在租户的操作列增加【客户端恢复彩色】按钮
- 点击后弹窗二次确认
- 确认后该租户客户端置为彩色
- 同时该租户的【客户端恢复彩色】按钮禁用或不展示

### 状态切换

灰白色调生效后，顶部【客户端置为灰白】按钮变为【客户端恢复彩色】，点击弹窗提示确认。

## 与色调配置的关系

本功能是[[色调配置]]概念下的特定场景增强，增加了定时恢复和按租户控制两个维度。
