# 互通产品展示

## 概述

互通产品展示是产融平台V1.23版本中在企业信息列表中新增的互通产品查询条件和展示字段，用于展示企业开通的AMS产品和投行产品信息，解决此前查询困难的问题。

## 业务背景

此前企业信息列表未显示AMS产品，实际业务中查询较为困难，运营人员需要在多个系统间切换才能确认企业的产品开通情况。

## 功能规则

### 查询条件

- 企业信息列表查询条件增加"互通产品"，位于现有查询条件最后
- 枚举值：投行产品、AMS

### 列表展示

- 列表字段"开通产品"后增加展示"互通产品"
- 多企业角色时若同时开通AMS产品，则展示多个AMS产品名称（沿用现有逻辑）

## 与其他功能的关联

- 与[[ams建档互通]]相关，AMS产品的展示依赖于产融平台与AMS之间的数据互通机制
- 与投行产品的集成展示形成统一的互通产品视图
