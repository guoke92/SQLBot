# 经办人手机号姓名一致性

## 概述

V1.9版本要求产融平台新增经办人时，同一个手机号码对应的姓名必须一致，以保障用户数据的一致性和准确性。

## 一致性规则

按**租户维度**进行校验：

| 规则 | 说明 |
|------|------|
| 一个手机号 → 一个名称 | 同一租户下，一个手机号只能对应一个姓名 |
| 一个名称 → 多个手机号 | 同一租户下，一个姓名可以对应多个手机号 |

## 冲突处理

已存在该手机号的情况下，若名称不一致：
- 系统提示更名
- 补充提示语告知原因

## 设计要点

1. **租户维度隔离**：校验在租户范围内进行，不同租户间不受影响
2. **单向约束**：手机号→姓名为一对一，姓名→手机号为一对多
3. **防错机制**：通过提示而非强制限制，引导用户保持数据一致性
