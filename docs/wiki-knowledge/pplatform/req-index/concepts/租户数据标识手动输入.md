# 租户数据标识调整为手动输入

V1.21版本对新增租户时的数据标识字段进行了优化，将自动生成改为手动输入。

## 背景

此前新增贴牌时数据标记支持自动生成，但实际业务中该字段均为手动输入。自动生成标记的逻辑为租户名称全拼，造成数据标记字段过长，影响系统处理效率。

## 业务规则

新增租户时隐藏"生成标记"按钮，数据标识字段改为纯手动输入。

## 优先级

本需求标记为【高】优先级。
