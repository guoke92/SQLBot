# 按钮权限细化

按钮权限细化是[[4-需求文档--18-产融平台v126版本需求文档0129--eyrepd|产融平台V1.26版本]]中提出的权限管理优化功能，旨在将平台的权限控制精度从菜单级别提升到操作按钮级别。

## 问题背景
前期上线经办人功能时，要求在角色权限分配时能展示菜单下对应的按钮并进行分配。但实际上线后发现，系统仅支持菜单级的权限分配，未能实现更细粒度的按钮级权限控制。

## 功能描述
在V1.26版本中，对角色权限分配页面进行优化。当管理员为某个角色分配菜单权限时，页面将展示该菜单下包含的所有具体操作按钮（如“新增”、“删除”、“导出”等），并支持管理员独立勾选或取消勾选每个按钮的权限。

## 价值
提升了权限管理的精细度和安全性，使得企业能够根据员工岗位职责，精确控制其可以执行的操作，避免越权操作。
