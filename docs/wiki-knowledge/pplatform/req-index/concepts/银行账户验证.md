# 银行账户验证

银行账户验证是[[chanrong-platform|产融平台]]中[[enterprise-chanrong|企业]]管理银行账户的重要流程，通过小额打款认证确保银行账户的有效性。

## 功能规则

### 无数据状态
无银行账户数据时展示"暂无数据"，支持新增账户。

### 新增账户
- 首个新增账户自动设为默认账户
- 录入字段包括：账户名称、账户账号、账户开户行
- 新增后账户状态为"待验证"

### 账户验证
- 新增账户完成后，点击"账户验证"按钮展开小额打款认证弹窗
- 小额打款认证通过后，账户状态变更为"已验证"
- 已验证的账户不支持编辑

### 编辑与删除
- 仅账户状态为"待验证"时显示编辑按钮
- 编辑和删除前需校验是否存在在途交易
- 存在在途交易时提示不允许操作

### 默认账户
- 点击"设为默认账户"后，账号名称后显示默认账户标签
- 设置后原默认账户的"设为默认账户"按钮重新显示

## 数据来源

银行账户信息的补充来源包括：
1. 内部员工在内管平台端手动新增
2. 客户在客户端新增，经运营审核通过后入库，可供其他客户使用
