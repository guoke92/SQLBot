# 企业协议查看优化

## 变更内容

V1.10版本对产融客户端查看企业协议的功能进行两项优化：

### 1. 增加"对应产品"列

客户端企业协议列表中，在"签署模式"列前增加"对应产品"列，便于用户识别协议所属产品。

### 2. 协议名称为空时的命名规则

当协议名称（specify_file_name）为空时，使用"文件夹名称_文件名"拼接方式命名：

```
协议/合同名称 = catg_name + "_" + file_name
```

## 存量数据处理

存量数据需要处理（按新规则重新生成协议名称）。

## 关联系统改造

推送接口需要讯易链改造，以获取影像文件夹名称（catg_name）。

## 关联概念

- [[讯易链]]：需要配合改造的关联系统
