# 银行账户归集

## 定义

在客户端新增统一的"账户中心"菜单，聚合展示企业角色在不同业务产品（如融易单、线上保理、订单融资、交e保）下已维护的银行账户信息，仅作展示无维护功能。

## 功能结构

- 原【银行账户】菜单更名为【账户中心】
- 新增【交e保】、【银行账户】二级菜单
- 银行账户页面内分两层tab联动：
  - 第一层：选择业务产品，仅展示已开通产品，产品名称同贴牌下产品名称保持一致
  - 第二层：自动带出该企业角色在该产品下的账户类型

## 各产品-企业角色的银行账户展示

### 融易单

| 企业角色 | 账户类型 | 主要字段 |
| :--- | :--- | :--- |
| 供应商 | 收款账户 | 账户名称、账户账号、开户行、开户行所在城市、联行号、认证状态、是否默认、更新时间 |
| 核心企业 | 付款账户 | 项目名称、付款渠道、账户名称、账户账号、开户行、开户行所在城市、联行号、更新时间 |
| 核心企业 | 付息账户 | 项目名称、金融机构、账户名称、账户账号、开户行、开户行所在城市、联行号、更新时间 |
| 金融机构 | 收款账户 | 账户名称、账户账号、开户行、开户行所在城市、联行号、是否默认、更新时间 |
| 金融机构 | 核心企业回款账户 | 核心企业名称、账户名称、账户账号、开户行、开户行所在城市、联行号、更新时间 |
| 金融机构 | 供应商回款账户 | 供应商名称、账户名称、账户账号、开户行、开户行所在城市、联行号、更新时间 |

供应商回款账户tab显隐跟随业务系统内部，若当前企业有此账户类型则显示，否则不显示。

### 线上保理

| 企业角色 | 账户类型 | 主要字段 |
| :--- | :--- | :--- |
| 供应商 | 收款账户 | 账户名称、账户账号、开户行、联行号、是否默认、更新时间 |
| 核心企业 | 付款账户 | 账户名称、账户类型（付息/兑付）、兑付方式、关联项目、金融机构、账户账号、开户行、联行号、更新时间 |
| 金融机构 | 回款账户 | 账户名称、核心企业名称、兑付方式、账户类型（回款/收款）、账户账号、开户行、联行号、更新时间 |

### 订单融资

| 企业角色 | 账户类型 | 主要字段 |
| :--- | :--- | :--- |
| 供应商 | 收款账户 | 账户名称、账户账号、开户行、联行号、账户归属（企业自身/第三方）、更新时间 |
| 供应商 | 订单回款账户 | — |
| 核心企业 | 付款账户 | 账户名称、账户账号、开户行、开户行所在城市、联行号、更新时间 |

## 展示规则

- 仅作展示，无维护功能
- 只有已开通的业务系统才会展示对应的银行账户菜单
- 各产品均支持筛选条件（支持模糊搜索）和列配置器
- 权限配置中【银行账户】更名为【账户中心】，新增【交e保】、【银行账户】勾选项
