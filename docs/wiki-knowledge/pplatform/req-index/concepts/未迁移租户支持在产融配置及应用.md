# 未迁移租户支持在产融配置及应用

## 定义

将原本在讯易链等系统维护的租户/项目运营配置，统一迁移至产融平台进行维护和管理，并支持在客户端应用。这是V1.31版本的核心需求，旨在归集统一配置入口，是平台架构整合的关键步骤。

## 背景

此前产融平台已有项目运营配置、租户运营配置功能，同时讯易链也有相关配置，入口较多。运营侧提出归集统一入口的需求。

## 迁移范围

### 租户运营配置

数据范围调整为全部租户（微企链贴牌除外），迁移的配置项包括：

| 配置项 | 产融平台字段 | 讯易链对应字段 | 维度一致性 |
| :--- | :--- | :--- | :--- |
| 在线客服 | 开启智能客服、智能客服渠道号、智能客服按钮颜色 | 客服配置-贴牌配置-在线客服 | 一致（租户维度） |
| 自主注册配置 | 项目码是否必填、默认关联的项目 | 项目专属服务码必填、默认关联项目 | 一致（租户维度） |
| 回收授权书标识 | 是否需回收授权书标识 | 授权书归档 | 一致（租户维度） |

本期新增"智能客服按钮颜色"配置项，开启智能客服时该字段必填，迁移产融平台的租户默认展示租户主题色。

### 项目运营配置

数据范围调整为全部项目（微企链项目除外），迁移的配置项包括：

| 配置项 | 维度一致性 | 备注 |
| :--- | :--- | :--- |
| 邀请信息配置 | 一致（项目维度） | — |
| 客服名片配置-客服二维码 | **不一致**（产融租户维度 vs 讯易链项目维度） | 需映射关系处理 |
| 客服名片配置-建档运营名片展示 | 一致（项目维度） | — |
| 是否回填建档运营 | 一致（项目维度） | — |

## 讯易链侧改造

### 取值逻辑调整

配置内容的取值逻辑调整为取产融平台维护的内容，应用逻辑仍由讯易链实现。

### 入口屏蔽

- 客服配置-项目管理：顶部按钮【修改】、操作列按钮【邀请信息配置】【客服名片配置】【查看邀请信息】均屏蔽
- 客服配置-贴牌配置：顶部按钮【修改】、操作列按钮【在线客服】屏蔽
- 自主注册配置："项目专属码服务码必填、默认关联项目"字段隐藏

## 存量数据处理

- 讯易链需将已配置内容同步至产融平台
- 客服名片类型：产融平台为租户维度，讯易链为项目维度，按产融平台维护内容处理历史数据（某租户下项目全部处理为产融租户维度配置的内容）
- 建档运营名片展示：讯易链需将已配置内容同步至产融平台

## 影响

此需求标志着产融平台与讯易链在功能配置上的整合趋势，后续讯易链的客服配置功能将逐步由产融平台统一管理。
