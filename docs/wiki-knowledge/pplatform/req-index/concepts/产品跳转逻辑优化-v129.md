# 产品跳转逻辑优化（V1.29）

## 概念定义

在V1.28版本已实现的[[开通产品跳转业务系统|产品跳转业务系统]]基础上，优化多产品场景下的自动跳转逻辑，使其智能跳转至有待办的业务系统。

## V1.28现有逻辑

- 登录产融平台后，只开通一个产品，则自动跳转进入对应的业务系统
- 如有产融平台待办时则不自动跳转业务系统

## V1.29优化逻辑

- 登录产融平台后，开通**多个产品**时，自动跳转进入**有待办的业务系统**
- 如多个产品均有待办，则**弹窗进行待办提示**，由用户选择跳转目标

## 优化意义

解决了多产品场景下用户无法快速定位到需要处理的业务系统的痛点，提升了运营效率。
