# 授权书多文件上传

## 概述

V1.25版本将企业授权及确认书的上传数量从1份扩展至最多10份，以适应客户实际文件情况，减少运营中台审核时需补充上传的操作。

## 业务规则

### 建档场景

- 企业授权及确认书调整为支持上传多个（最多10个）
- 多个文件推送运营中台时自动增加序号进行命名及排序

### 变更场景

企业信息变更涉及授权书的需同步调整，支持上传多个。

### 其他影像件

其他影像件仅支持上传1个，不受本次调整影响。

### 文件格式限制

- 支持文件类型：jpeg/jpg/png/pdf
- 单个文件大小不超过20M
- 取消文件上传框下方的原提示说明
