# 企业信息维护-运营人员字段

## 概述

企业信息维护-运营人员字段是产融平台V1.23版本中在企业信息维护列表页新增的"运营人员"字段，用于展示建档时的经办运营人员信息，便于后续流程的专人跟进。

## 业务背景

此前企业信息维护列表页未展示建档时经办运营人员，后续建档流程处理需要专人跟进时无法快速定位，影响运营效率。

## 功能规则

- 企业信息列表增加"运营人员"字段，位于现有字段"客户状态"后
- 取值逻辑与企业联系人列表同名字段一致
- ~~同步增加查询条件（下拉选，支持模糊搜索，缺省值"请选择运营人员"）~~——该查询条件在最终版本中被划掉
