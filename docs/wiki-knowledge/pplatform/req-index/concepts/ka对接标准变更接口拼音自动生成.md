# KA对接标准变更接口拼音自动生成

## 概述

KA对接标准变更接口拼音自动生成是产融平台V1.30版本的产品优化需求，在[[KA]]（关键客户）通过标准接口推送变更信息时，系统自动根据中文姓名生成英文姓和名，减少客户重复操作。

## 背景

接口推送变更信息时，英文-姓和英文-名现状是会被清空，客户进入变更待办中需要重复点生成拼音。

## 业务规则

1. 被授权人或法人的英文-姓和英文-名**为空**时，系统根据中文姓名自动生成拼音
2. 被授权人或法人的英文-姓和英文-名**不为空**时，不自动生成拼音

## 适用对象

- 法人
- 被授权人
