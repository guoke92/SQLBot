# 项目运营配置数据同步（V1.29）

## 概念定义

在[[企微立项审批集成|企微立项审批]]列表维护对接人后，通过"企微立项审批编号"字段将对接人信息自动同步至项目运营配置列表下，完善项目运营配置功能的数据自动流转能力。

## 同步机制

### 同步方式

通过立项审批编号进行匹配同步。V1.29版本在0326版本基础上，新增**"系统通过定时任务自动同步"**节点，与现有业务经理、方案经理的同步逻辑一致。

### 同步映射

| 企微立项审批字段 | 项目运营配置字段 |
|------------------|------------------|
| 运营对接人 | 运营对接人A |
| 风控对接人 | 风控对接人A |

### 存量数据处理

企微立项审批列表下的存量数据需在上线前完成初始化。
