# 邀请信息配置

## 概述

邀请信息配置是产融平台V1.28版本在项目运营配置中新增的模块，用于在项目维度配置面向客户端的邀请信息（操作手册、建档指引图片、二维码、客服话术等），并在客户端自主注册时展示。该功能从[[entities/讯易链]]迁移至产融平台。

## 配置内容

| 配置项 | 格式 | 必填性 | 限制 |
| --- | --- | --- | --- |
| 操作手册 | PDF | 必填 | 仅支持1个文件，≤20M |
| 建档操作指引图片 | 图片 | 必填 | 仅支持1个文件，≤20M |
| 小程序二维码 | 图片 | 非必填 | 仅支持1个文件，≤20M |
| 公众号二维码 | 图片 | 非必填 | 仅支持1个文件，≤20M |
| 客服话术 | 文本 | - | 最多500字 |

### 适用范围

仅适用于产融平台的项目，微企链平台项目无需配置。

### 列表展示

项目运营配置列表增加"邀请信息配置状态"字段（枚举：未配置、已配置、无需配置），位于"首笔落地时间"字段后。

## 客户端展示逻辑

### 触发节点

客户端自主注册阅读《用户协议》、《隐私政策》后，点击【我已阅读】按钮，根据以下条件判断是否展示邀请信息弹窗：

1. **自主注册时填写了项目码**：取该项目对应的邀请信息，未配置邀请信息则不展示弹窗。
2. **自主注册未填写项目码**：
   - 该租户已配置默认关联项目：取默认关联项目配置的邀请信息。
   - 该租户未配置默认关联项目，或默认关联项目未配置邀请信息：不展示弹窗。

### 弹窗内容

弹窗展示以下信息：
- 租户配置的PC端内页LOGO
- 客服话术
- 小程序信息（小程序二维码、公众号二维码）——两个二维码均未配置时不展示该模块
- 操作指引图片
- 下载操作手册

### 交互说明

- 点击【我已知晓，继续进行企业认证→】按钮后，弹出行为验证，验证通过后系统自动点击【开始认证】，场景包括：上传营业执照、是否跨租户认证、PC/小程序建档。
- 点击【x】按钮关闭弹窗，自动返回登录页面。

## 存量数据处理

原讯易链处配置的邀请信息需同步至产融平台，并在产融平台页面进行已配置信息的展示。

## 开放问题

邀请信息从讯易链迁移至产融平台后，原有配置的兼容性和数据一致性如何保障？文档给出了存量数据处理方案，但实施效果需关注。
