# 集团成员管理

## 概述

集团成员管理是产融平台中集团公司客户端和内管端的功能模块，用于管理集团公司下属的成员单位。V1.23版本对该模块进行了两项优化：新增删除校验逻辑和企业名称筛选优化。

## 功能说明

### 删除校验逻辑

在集团成员管理中新增删除校验逻辑，防止误删成员单位导致数据异常。具体校验规则详见[组织架构与成员单位模块需求文档](https://doc.weixin.qq.com/doc/w3_AA4AEQa0AAwCNZQxwoHA0R0aZhUM0?scode=ABAA4gf_AAw5jDBPxbAA4AEQa0AAw)P5.1.3.6。

### 企业名称筛选优化

优化集团成员管理中企业名称的筛选功能，提升操作效率。具体优化方案详见上述文档P5.5。

## 应用场景

- **产融内管端**：运营人员管理集团成员单位
- **集团公司客户端**：集团公司自行管理下属成员单位
