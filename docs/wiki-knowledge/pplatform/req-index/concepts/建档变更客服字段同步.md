# 建档变更客服字段同步运营中台

## 概述

V1.9版本要求配合[[运营中台]]联调，在进行企业建档变更时将客服字段传给运营中台。

## 需求描述

- 企业建档变更时，客服字段需同步传给运营中台
- 属于产融与运营中台的联调需求

## 关联

运营中台story：[PROJECT链接](https://aio.llschain.com/iterationPlan/createStory?id=1386296878528981644&from=iterationPlan&projectId=1379979358067212348)

## 设计要点

1. **数据同步**：确保客服字段在建档变更时同步更新到运营中台
2. **联调协作**：需要产融与运营中台双方配合
