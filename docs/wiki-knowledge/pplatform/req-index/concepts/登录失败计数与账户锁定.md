# 登录失败计数与账户锁定

## 概述

登录失败计数与账户锁定是SSO单点登录系统防止暴力破解攻击的核心安全机制，通过记录用户连续登录失败次数并在达到阈值后暂时锁定账户来限制非法登录尝试。

## 设计目标

- 限制非法登录次数，防止暴力破解攻击
- 提供自动解锁机制，减少管理员干预
- 支持按业务系统配置不同的锁定策略

## 配置参数

| 参数 | 说明 | 默认值 | 存储位置 |
|------|------|--------|---------|
| loginFailLockedCount | 最大失败次数 | 5次 | 系统配置表 |
| pwdLockedMinute | 锁定时长（分钟） | 30分钟 | 系统配置表 |
| loginFailCount | 当前失败次数 | - | [[sso-user]] 表 |
| pwdIsLocked | 账户锁定标志 | - | [[sso-user]] 表 |
| pwdLockedTime | 锁定截止时间 | - | [[sso-user]] 表 |

## 核心流程

### 失败计数流程

```
用户登录 → 验证密码
  ├── 密码正确 → 重置失败计数 → 允许登录
  └── 密码错误 → 失败计数+1
        ├── 未达阈值 → 返回登录失败
        └── 达到阈值 → 锁定账户 → 设置锁定时间 → 返回登录失败
```

### 锁定检查流程

用户再次登录时，系统首先检查账户是否被锁定：
- **当前时间 <= pwdLockedTime**：账户处于锁定状态，即使密码正确也不允许登录
- **当前时间 > pwdLockedTime**：锁定时间已过，自动解锁

### 自动解锁机制

锁定时间到期后：
1. 清除锁定状态（pwdIsLocked = false）
2. 重置失败计数（loginFailCount = 0）
3. 无需人工干预

## 关键代码逻辑

```java
// 登录失败处理
if (!matches) {
    ssoUserDO.setLoginFailCount(ssoUserDO.getLoginFailCount() + 1);
    if (ssoUserDO.getLoginFailCount() >= ssoSystemDO.getLoginFailLockedCount()) {
        ssoUserDO.setPwdLockedTime(
            LocalDateTime.now().plusMinutes(ssoSystemDO.getPwdLockedMinute())
        );
        ssoUserDO.setPwdIsLocked(true);
    }
}

// 账户锁定检查
LocalDateTime pwdLockedTime = ssoUserDO.getPwdLockedTime();
if (null != pwdLockedTime) {
    if (LocalDateTime.now().compareTo(pwdLockedTime) <= 0) {
        // 账户仍被锁定
        return new SSOResultDTO<>(SSOResultCodeEnum.CORRECT_CODE_20903);
    } else if (ssoUserDO.getPwdIsLocked() && LocalDateTime.now().compareTo(pwdLockedTime) > 0) {
        // 锁定时间已过，自动解锁
        ssoUserDO.setLoginFailCount(0);
        ssoUserDO.setPwdLockedTime(LocalDateTime.now());
        ssoUserDO.setPwdIsLocked(false);
    }
}
```

## 安全特性

- **防止暴力破解**：限制登录尝试次数，增加攻击成本
- **自动解锁**：锁定时间到期后自动解锁，减少管理员干预
- **失败计数持久化**：失败次数存储在数据库，防止重启后计数丢失
- **可配置策略**：不同业务系统可配置不同的锁定策略

## 日志记录

所有锁定相关的操作均记录在 [[sso-user-login-history]] 中，包括：
- 登录失败记录（operator_result = 0）
- 账户锁定记录（remark包含锁定原因和剩余时间）
