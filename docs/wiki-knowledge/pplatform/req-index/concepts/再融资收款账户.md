# 再融资收款账户

## 概述

再融资收款账户是[[线上保理]]业务中，保理商用于接收再保理融资款项的一种新增银行账户类型。该功能在产融平台V1.32版本中由产品经理[[侯叔彤]]负责。

## 功能描述

### 内管端

- 内管端线上保理银行账户-金融机构账户处，新增展示"再保理融资收款账户"。
- "账户类型"筛选项新增对应枚举，无需按角色区分。

### 客户端

- 客户端银行账户-线上保理，金融机构角色同步新增展示"再保理融资收款账户"。
- "账户类型"筛选项新增对应枚举，无需按角色区分。

## 业务意义

该功能是对线上保理保理商收款账户的功能扩展，因线上保理保理商收款账户改造而同步优化内管端和客户端的银行账户列表。
