# 用户名为空处理

## 定义

用户名为空处理是产融平台V1.20版本针对特定业务场景的流程修复功能。当系统中存在手机号但用户名为空的用户时，允许业务系统手动输入用户名并完成授权操作，解决了因用户名为空导致的流程阻塞问题。

## 问题场景

1. 企业A建档时使用某手机号作为被授权人，但该企业未完成建档。
2. 此时企业B将该手机号添加为经办人，系统根据手机号拉出部分已有信息。
3. 但该用户的"用户名"字段为空，导致业务系统在录入用户名后无法提交"确认授权"操作。

## 业务规则

1. **信息拉取**：业务系统新增用户输入手机号码时，如该手机号码已存在于存量用户数据库中，则将库中存在的信息一并获取并填充至对应文本框。
2. **手动输入**：当该手机号的"用户名"为空时，支持业务系统的用户手动输入用户名。
3. **授权提交**：输入完成用户名与其他必填项后，支持点击"确认授权"功能进行下一步操作。
4. **数据更新**：完成用户新增后，新输入的用户名需覆盖更新为用户手动输入的用户名。

## 与现有概念的关系

- 与[[用户身份管理]]相关：该问题可能是用户身份管理在某些边缘情况下的设计缺陷，属于数据迁移遗留问题或系统设计不完善的补丁。
- 该修复属于特定场景的补丁，暗示用户身份管理在分布式环境下可能存在更深层的一致性问题。
