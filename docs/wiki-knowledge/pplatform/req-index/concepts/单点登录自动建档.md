# 单点登录并自动建档

## 概述

单点登录并自动建档是[[统一门户]]的核心扩展能力，支持从外部系统跳转至产融平台时自动完成企业建档和登录（或反向跳转），无需人工介入。这是V1.9版本的跨迭代需求，支持多种复杂业务场景。

## 业务场景

### 场景一：第三方跳入产融

自营平台上有KA项目从外部系统推送企业信息过来建档（自动完成认证无人工介入），然后免密登录过来做业务，产融需要支持。

**典型流程：** 外部系统 → 推送企业信息 → 产融自动建档 → 免密登录 → 办理业务

### 场景二：产融跳入第三方（AMS）

目前[[ams]]仅有供应商迁移了产融，项目公司未迁移。对项目公司暂以自动建档+免密登录方式与AMS交互。

**典型流程：** 产融 → 企业信息同步 → AMS自动建档 → 免密登录 → 项目公司业务

### 场景三：产融跳入第三方（SaaS贴牌）

部分SaaS贴牌以单点登录+自动建档方式与第三方系统交互，例如小微蜂平台。

**典型流程：** 产融/SaaS贴牌 → 单点登录 → 第三方系统自动建档 → 免密登录

## 关键技术要素

1. **自动建档**：企业信息从源系统自动推送到目标系统，无需人工填写和审核
2. **免密登录**：完成建档后直接登录，无需输入账号密码
3. **双向支持**：既支持从外部跳入产融，也支持从产融跳入外部系统
4. **认证无人工介入**：自动化完成企业认证流程

## 安全考量

文档中未详细阐述在自动建档模式下如何保障企业信息的真实性和认证强度，存在潜在的安全与合规张力。这是一个需要进一步研究的开放问题。

## 与统一门户的关系

本需求极大地扩展了[[统一门户]]的内涵，从简单的登录跳转深入到自动建档和业务状态同步。鉴于其复杂性和重要性，作为独立概念页面从统一门户中分离出来。
