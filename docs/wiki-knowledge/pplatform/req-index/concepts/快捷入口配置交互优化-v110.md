# 快捷入口配置交互优化

## 变更内容

V1.10版本对快捷入口配置的交互进行了两项优化：

1. **去掉左侧菜单**：简化页面结构
2. **增加编辑图标**：快捷入口tab页增加编辑图标，切换至该tab页时可见，点击后进入快捷入口配置页

## 权限规则

不限编辑权限，以人为维度，配置仅本人可见。
