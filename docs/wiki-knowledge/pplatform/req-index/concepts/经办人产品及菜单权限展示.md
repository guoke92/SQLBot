# 经办人产品及菜单权限展示

## 概述

经办人产品及菜单权限展示是产融平台V1.30版本的运营需求，旨在内管端增加企业联系人开通产品及菜单权限的展示功能，减少因权限配置问题导致的开发介入查询和沟通成本。

## 背景

目前内管端未展示企业联系人开通产品情况以及对应菜单权限，实际业务中常出现管理员未给经办人配置权限无法开展业务，需开发介入查询的情况。

## 功能设计

### 入口

企业联系人列表点击联系人【姓名】字段，弹窗展示两个tab页：
- **基本信息**：展示现有联系人基本信息，内容样式与现有一致
- **菜单权限**：展示企业联系人在已开通产品下的菜单及按钮权限

### 权限展示规则

- 该联系人开通某个产品时展示该产品名称tab页，未开通时不展示
- 多个角色菜单权限时取并集展示

### 产融平台、线上保理

- 样式：分为菜单名称、按钮名称，勾选状态为只读样式
- 交互：支持菜单名称切换，展示对应按钮名称的勾选状态
- 业务逻辑：查询该用户所属角色的菜单权限；产融平台存在系统默认经办人权限，本期同步展示

### 多级流转、订单融资

- 样式：分为菜单名称、审核层级，只读样式
- 交互：无交互
- 业务逻辑：查询该用户在对应系统下的菜单名称、审核层级

## 存量数据处理

存量联系人的权限需同步处理。

## 关联系统

菜单权限、按钮权限、审核层级数据由业务系统提供，产融平台查询后或业务系统同步后展示。
