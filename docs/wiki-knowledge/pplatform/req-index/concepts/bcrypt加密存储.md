# BCrypt加密存储

## 概述

BCrypt加密存储是SSO单点登录系统采用的密码存储安全方案，使用BCrypt算法对密码进行不可逆哈希存储，满足"对用户密码进行混淆后进行加密存储"的合规要求。

## 设计目标

- 满足RSA密钥长度不小于2048位或采用国密算法的传输加密要求
- 实现密码的不可逆加密存储
- 抵御暴力破解和彩虹表攻击

## 技术实现

### 传输加密（RSA/国密算法）

**RSA加密传输流程**：
1. 用户到达登录页面，后端生成密钥对，公钥发送给前端
2. 用户输入密码
3. 前端使用RSA公钥加密密码
4. 传输加密后的密码到后端
5. 后端使用RSA私钥解密
6. 获得明文密码用于验证

**RSA配置**：
- 密钥长度：RSA-2048及以上
- 密钥管理：公钥和私钥实时生成，后端保存
- 密钥轮换：支持密钥定期轮换和版本管理

### 存储加密（BCrypt算法）

**BCrypt特性**：
- **随机盐值**：每次加密生成不同盐值，确保相同密码加密后结果不同
- **抗彩虹表攻击**：BCrypt算法基于Blowfish密码算法，具有抗彩虹表攻击能力
- **可配置强度**：支持可配置的加密强度（log rounds，默认10轮）
- **不可逆加密**：密码以哈希值形式存储，无法逆向还原

**存储加密流程**：
1. 明文密码
2. 调用 `BCryptPasswordEncoder.encode()`
3. 生成随机盐值（Salt）
4. 使用BCrypt算法加密
5. 存储BCrypt哈希值到数据库（[[sso-user]] 表的 password 字段）

### 密码混淆机制

- BCrypt哈希：每次加密使用不同的随机盐值
- 不可逆存储：无法通过哈希值还原原始密码
- 盐值随机化：相同密码加密后结果不同

## 安全优势

- 即使数据库泄露，攻击者无法还原原始密码
- 随机盐值防止彩虹表攻击
- 高成本计算（log rounds）增加暴力破解难度
- 支持密钥轮换，降低密钥泄露风险
