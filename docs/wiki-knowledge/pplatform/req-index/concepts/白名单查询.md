# 白名单查询

## 概念定义

白名单查询是在项目上线审批流程中，通过调用[[客户经营系统]]提供的API接口，实时查询企业是否在特定白名单（如核企白名单）内的功能。该功能将线下人工核对转为线上自动化校验，提升效率和准确性。

## 功能设计（V1.34版本）

### 触发条件

当"是否为简易模式项目/常规非低风险项目"选择为"是"时，启用白名单查询功能。

### 核心企业与资金方名称

发起项目上线审批时新增以下字段：
- **核心企业名称**：必填，初始默认1个输入框，支持通过【+】按钮新增，最多5组（核心企业名称1~4）
- **资金方名称**：必填，初始默认1个输入框，支持通过【+】按钮新增，最多5组（资金方名称1~4）

取值逻辑：
- 初始选择"项目立项审批编号"时，自动同步项目立项统计的企业全称和资方分支行
- 仅支持通过【+】新增的字段支持删除

### 查询流程

1. 点击【白名单查询】按钮
2. 校验：若存在核心企业名称为空，提示"请先输入核心企业名称！"
3. 调用客户经营系统API查询下沉客户数据
4. 按照企业分别展示查询时间和结果
5. 提交审批后，查询结果留存至审批流程中，不做更新覆盖

### 提交审批校验

提交审批时新增强校验逻辑：
- 白名单查询结果只要存在某一个为空或查询结果为"暂未在下沉评估清单"
- 强校验提示："核心企业【xxxx、xxxx】未在核企白名单内，请确认核企名称是否准确，如该核企不满足准入要求，则不允许开展简易模式！"

### 数据联动

- 核心企业名称发生调整时，所有企业的白名单查询结果需置空
- 审批被驳回重新发起时，自动带出上一次审批所填写的企业信息，白名单查询结果置空
- 向AMS推送数据时，projectPlan字段拼接：核心企业名称+资金方名称+项目方案

### 白名单/批复截图

选择简易模式时，"白名单/批复截图"文件上传框变更为非必传。

## 依赖系统

- **客户经营系统**：提供下沉企业白名单Dubbo接口
- **AMS**：接收拼接后的projectPlan数据

## 关联需求

该概念在V1.34版本中对应需求10：【项目上线审批】需调用白名单数据进行判断，由产品经理[[林彦湘]]负责。
