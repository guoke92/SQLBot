# 开通产品跳转业务系统

## 概述

开通产品跳转业务系统是产融平台V1.28版本的客户端体验优化，改变了产品开通完成后的跳转行为。此前开通产品完成后自动跳转到产融平台首页，实际业务中各业务系统仍需进行账户激活、协议签署等环节，容易造成歧义。

## 优化内容

### 优化前

产融平台开通产品完成后 → 自动跳转至产融平台首页 → 产品开通状态变为已开通。

### 优化后

产融平台开通产品完成后 → 自动跳转至对应业务系统 → 与从产融平台首页点击已开通产品进入业务系统效果一致。

### 其他说明

- 产融平台产品开通状态无需根据业务系统处理情况显示。
- 如有拦截则正常拦截，维持现状。
