# 异步批量处理

## 概述

异步批量处理是产融平台V1.30版本的基础能力升级，将导入/导出操作转为后台异步任务，突破单次500条数据的性能限制，提升系统处理能力。

## 背景

前期[[项目运营配置]]、租户运营配置已支持导入和导出功能，但考虑系统性能，单次处理最大为500条数据。实际业务中运营需批量或全部处理，同时方案侧提出增加[[项目立项统计]]需求，同样需要批量功能。

## 设计方案

### 异步导出流程

1. 用户选择数据后点击【导出】，toast提示"已加入导出任务，可在文件管理查看进度"，3秒后自动关闭
2. 任务成功：后台生成导出文件，上传至统一文件服务；前端任务中心状态更新为"成功"，操作列显示【下载文件】按钮
3. 任务失败：记录失败原因、失败时间，任务状态更新为"失败"；前端操作列显示【下载异常文件】按钮

### 异步导入流程

1. 导入数据后toast提示"文件已上传，正在后台导入，可在文件管理查看结果"，3秒后自动关闭
2. 任务优先级：默认按任务创建时间排序（先创建先执行）
3. 异常记录：校验失败的数据记录行号、错误字段、错误原因，任务中断
4. 任务成功：所有数据校验通过并入库
5. 任务失败：记录失败原因、失败时间，操作列显示【下载异常文件】按钮

### 异常数据处理

下载异常文件为Excel格式，包含原数据所有字段，新增"错误行号""错误原因"两列。

### 文件管理菜单

新增【文件管理】菜单，用于展示异步导入、导出文件：

- **查询条件**：任务类型（全部/导入/导出）、菜单名称（所有支持导入/导出的菜单）、任务状态（全部/进行中/已完成/失败）、时间范围（默认近7天）、搜索框（任务ID、文件名称模糊搜索）
- **数据范围**：每个用户仅可见自己的任务数据
- **列表字段**：任务ID、任务类型（导入蓝色/导出绿色标签）、业务菜单、文件名称、状态（进行中/已完成/失败标签）、操作人、执行时间、操作
- **操作按钮**：
  - 进行中：无按钮
  - 成功（导出）：【下载文件】【删除】
  - 成功（导入）：【删除】
  - 失败：【下载异常文件】【删除】

## 应用范围

异步批量处理功能应用于以下菜单：
- 项目运营配置
- [[企微立项审批]]
- [[项目立项统计]]（新增）
