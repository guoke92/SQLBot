# 经办人产品可见性

经办人产品可见性是[[产融平台]]V1.7版本的一项权限优化需求，确保经办人只能看到自己分配角色中的产品。

## 业务规则

经办人登录后，系统获取所配置角色中关联的产品，首页只展示所关联产品的入口（左上角产品信息）。

## 场景说明

假设企业开通了产品A和产品B：

| 场景 | 经办人角色配置 | 可见产品 |
| --- | --- | --- |
| 场景1 | 仅开通产品A | 仅产品A |
| 场景2 | 先开通产品A、B，后去掉产品A | 仅产品B（重新登录后生效） |

## 与现有概念的关系

此需求是[[用户角色产融平台语境|用户角色与权限]]管理的细化，将产品可见性与角色绑定，确保经办人只能访问其被授权的产品功能。
