# 项目配置pro

## 概述

[[项目配置pro]]是融易单产品重构后的新版项目配置页面。因为新增项目的入口统一在产融平台，故需要产融平台上也新增可打开"项目配置pro"的入口。

## 业务规则

### 跳转逻辑

新增融易单的项目时支持跳转新的"项目配置pro"配置页面。

### 字段配置

关联产品为"多级流转"时，增加"项目配置版本"字段，枚举值包括"项目配置"和"项目配置pro"，当选择为"项目配置pro"时，"项目配置模式"默认为"管理员配置"。

## 影响范围

- 融易单产品：新增项目时支持跳转新的配置页面。
- 多级流转产品：关联产品为"多级流转"时，增加"项目配置版本"字段。

## 开放问题

"项目配置pro"的引入，是否预示着融易单乃至其他产品的配置体系将发生更大范围的演进？
