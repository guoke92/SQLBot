# 线上保理假项目

## 问题背景

[[线上保理]]的企业数据目前还是会先推[[多级流转]]，再由多级推到线上保理，推多级时要求一定要有项目。

目前的处理策略：
- 每次新增贴牌时都手工创建一个线上保理的项目
- 后续新增的做线上保理业务的企业也先关联到这个项目下
- 操作上具有一定的繁琐度

## 解决方案

### 1. 项目非必填调整

针对线上保理，新增企业时，项目调整成非必填。

### 2. 自动创建假项目

每次新增一个贴牌且开通了线上保理的产品时，系统自动创建一个项目。

### 3. 自动关联

线上保理新增企业时，如果未选择关联哪个项目，在向多级做推送时，就建立企业和自动创建的项目间的关联关系。

## 预期效果

想实现的效果是：线上保理的项目配置可以在一个菜单内完成，不用在项目配置和企业信息列表间频繁做切换。

## 实现状态

该需求标记为"后置"，属于延期缺陷单。
