# 企业组织架构按企业角色区分

## 概念定义

企业组织架构按企业角色区分是指在产融平台中，同一企业的不同企业角色（如核心企业、供应商、运营方等）可以维护各自独立的组织架构，而非共享单一组织架构。

## 需求背景

前期产融平台已上线集团成员单位管理与企业组织架构功能，并应用到业务系统中。近期上线[[企业数据权限隔离|数据隔离]]需求后，开发过程中发现现有企业组织架构未按照企业角色区分。实际业务中，不同企业角色下的组织架构可能不一致，因此需要进行优化以保障后续业务的顺利进行。

## 业务规则

### 客户端

- 企业内组织架构需与企业角色联动，支持不同企业角色下维护不同的组织架构
- **一键同步功能：0416版本暂不处理**——多企业角色下支持在某一企业维护组织架构后，将当前角色下的组织架构自动同步到所选择角色（支持多选）
- 存量经办人的数据权限类型系统初始化为"与所属组织一致"

### 内管端

- 企业信息维护列表【维护组织架构】同步新增区分企业角色
- 多角色场景下，进入详情页按企业角色区分tab页展示
- 单企业角色下无需展示tab页

### 存量数据处理

已维护组织架构的多角色企业，系统需自动对全部企业角色初始化组织架构。

## 平台演进意义

该功能为[[企业数据权限隔离]]等后续功能奠定基础，是产融平台管理粒度从"企业"维度向"企业角色"维度细化的关键一步。
