# CA状态变更同步

CA状态变更同步是V1.13版本的数据同步优化需求，确保电子签章开通状态的变更能及时同步至业务系统。

## 背景

此前，产融平台支持建档时开通或不开通电子签章，后续也支持变更电子签章开通状态，但对变更后的状态未同步至业务系统。

## 变更内容

企业建档时"开通电子签章"状态需同步给业务系统。后续变更开通状态时：

- **不开通→开通**：完成[[cfca|CFCA]]协议签署，成功开通电子签章后，需同步至业务系统开通结果
- 开通→不开通：**本期不处理**（文档中已删除线标注）

## 与供票产品的关系

CA状态是[[供票产品开通校验规则]]的三项校验条件之一。电子签章状态的准确同步对于供票产品的开通校验至关重要。

## 在数据同步体系中的位置

本需求是[[投行产品电子签章处理]]概念的延续和补充，属于产融平台与业务系统之间[[协议同步机制-v111|数据同步]]机制的一部分。
