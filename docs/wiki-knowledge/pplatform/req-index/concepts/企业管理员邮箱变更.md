# 企业管理员邮箱变更

企业管理员邮箱变更是[[产融平台]]V1.7版本新增的变更类型，变更管理员企业邮箱需要触发[[授权书变更|授权书重签]]，需与[[运营中台]]联调。

## 变更流程

企业联系人列表中点击变更按钮，变更类型增加【企业管理员邮箱变更】。

### 注册认证/邀请认证场景

- **需提交材料**：企业授权书
- **流程**：点击"下一步"后弹窗选择验证方式，确认后推送运营中台审核
- **运营中台审核页**：变更信息中变更类型为"联系人邮箱变更"，客户端需提交材料为企业授权书，联系人信息处仅邮箱字段可编辑
- **变更方支持**：
  - 注册认证、邀请认证-客户录入：支持平台变更和企业自行变更
  - 邀请认证-平台录入：仅支持平台变更

### 简易认证场景

- **需提交材料**：无
- 增加企业管理员邮箱变更选项，无需提交材料
- 企业管理员变更时增加邮箱字段

## 与授权书变更的关系

在注册认证和邀请认证场景下，变更管理员邮箱会触发授权书重签，这是因为管理员邮箱是授权书上的关键信息。这是[[授权书变更]]的一个新增触发场景。

## 关联系统

[[运营中台]]已支持邮箱变更，需配合联调。
