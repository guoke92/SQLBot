# 企业在途数据处理

企业在途数据处理是[[产融平台]]V1.16版本为解决历史数据迁移遗留问题而实施的一项关键功能。它旨在处理前期从[[讯易链]]及其他贴牌迁移至产融平台时，未处理的处于审核、变更等中间状态的企业数据，使其能在产融平台继续流程，保障移动端功能上线后的业务连续性。

## 问题背景

前期迁移未处理在途企业数据。随着产融平台移动端功能上线，这部分数据无法使用讯易链移动端功能，若需继续操作，必须拒绝流程后重新发起，导致运营侧重复工作和客户端体验不佳。

## 处理方案

方案明确了讯易链、产融平台和[[运营中台]]三方的职责：

1.  **讯易链**：
    - 拉取全部在途企业数据（包括变更中、审核中、待客户确认状态）。
    - 根据任务类型处理：
        - **任务类型=建档**：将企业数据同步至产融平台，自动流转到人工处理的第一个环节（运营中台审核或待客户确认）。
        - **任务类型=变更**：系统无法处理，需拒绝流程后重新发起。
    - 调用运营中台接口结束在途流程，并屏蔽相关消息通知。

2.  **产融平台**：
    - 接收讯易链同步的在途企业数据。
    - 对接收的数据进行字段检查，并正常发送消息提醒（经测试用例评审后调整为保持流程一致）。

3.  **运营中台**：
    - 配合讯易链结束当前在途流程。
    - 支持产融平台对同步过来的企业数据发起审核流程。

## 意义

该功能是平台移动端战略的重要支撑，通过妥善处理历史数据，减少了迁移阵痛，提升了运营效率和用户体验。
