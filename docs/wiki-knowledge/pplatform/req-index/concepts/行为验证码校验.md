# 行为验证码校验

行为验证码校验是一种在发送短信验证码等敏感操作前，通过第三方服务（如 [[极验验证码]]）验证用户操作是否为人类行为的安全机制，旨在防止机器人攻击。

## 在SSO系统中的实现

在SSO验证码登录改造中，行为验证码校验通过 [[sso-code-provider]] 的 `validateCaptcha` 接口实现，其核心流程如下：

1.  **参数校验与配置检查**：校验必要参数，并根据 [[系统配置驱动]] 和 [[白名单机制]] 决定是否需要进行校验。
2.  **调用第三方服务**：将用户提交的验证码参数（`challenge`, `validate`, `seccode`）发送至 [[极验验证码]] 服务进行校验。
3.  **结果缓存**：校验成功后，根据参数决定是否将结果缓存至 [[redis]]，以便后续登录流程复用（参见 [[验证码缓存机制]]）。

## 与其他概念的关系

- **前置防御**：作为登录流程的前置环节，与 [[登录失败计数与账户锁定]]、[[密码过期策略]] 等共同构成SSO安全体系。
- **缓存复用**：通过 [[验证码缓存机制]] 避免用户在短时间内重复进行行为验证，提升用户体验。
- **安全保障**：依赖 [[参数一致性校验]] 和 [[一次性使用]] 机制确保缓存复用的安全性。
