# 增加企业角色优化

## 概述

[[产融平台]]V1.15版本对[[企业信息变更]]中"增加企业角色"变更类型进行了优化。此前产融平台上线管理员唯一性校验功能后，变更类型为"增加企业角色"需录入管理员信息时未显示邮箱，导致后续变更流程异常。

## 优化内容

### 1. 邮箱字段新增

企业信息变更，变更类型为"增加企业角色"时：

- "增加企业角色"弹窗新增"邮箱"字段
- **位置**：位于现有字段"手机号"后、"证件类型"前
- **必填**：是
- **默认值**：自动带出该管理员的邮箱账号
- **可编辑**：支持修改

### 2. 操作人证件展示调整

调整操作人证件展示样式为左右对称展示。

## 互斥规则

"增加企业角色"变更类型**不支持**与其他变更类型同时选中。点击【下一步】时提示："增加企业角色"和其他变更类型不支持同时变更，请重新选择！

### 校验节点调整

历史逻辑中，校验节点为"增加企业角色"弹窗【下一步】按钮。本次调整为：选择变更类型页面点击【下一步】时即进行校验。

## 与企业信息变更的关系

该优化是[[企业信息变更]]整体优化的一部分。在V1.14版本中，企业信息变更还增加了多企业角色场景下变更时必须指定企业角色的逻辑，解决了与[[运营中台]]逻辑不一致的问题。
