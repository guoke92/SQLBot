# 管理员信息一致性校验

管理员信息一致性校验是V1.13版本新增的关键业务规则，以手机号为唯一标识，确保同一用户在不同企业下的核心身份信息保持一致，防止数据冲突。

## 校验机制

### 唯一标识

以**用户手机号**为唯一标识，按[[租户]]维度进行隔离。

### 校验范围

校验企业认证状态≠认证失败下的用户信息。

### 校验字段

录入手机号后，【暂存】、【下一步】或【提交】时校验该手机号对应的以下字段是否与历史信息一致：
- 姓名
- 邮箱
- 证件类型
- 证件号码

### 不一致时的提示

> "本次录入的企业管理员信息{姓名、邮箱、证件类型、证件号码}与当前手机号已存在的管理员信息不一致，请检查"

## 触发场景

| 场景 | 触发时机 |
| --- | --- |
| 自主注册 | 客户端确认被授权人页面点击【下一步】 |
| 邀请认证-客户录入 | 客户端确认被授权人页面点击【下一步】 |
| 邀请认证-平台录入 | 客户端确认被授权人页面点击【下一步】 |
| 运营中台建档审核 | 审核流程中（产融平台侧提供接口） |
| 企业管理员变更 | 变更流程提交时 |
| 企业管理员手机号变更 | 变更流程提交时 |
| 企业管理员证件有效期变更 | 变更流程提交时 |

## 关联系统

- [[运营中台]]：建档审核需同步增加相关校验，计划在0508版本处理
- 产融平台侧提供校验接口供运营中台调用

## 设计意义

该规则解决了不同企业添加相同用户作为管理员时可能出现的数据不一致问题，是[[用户角色产融平台语境|用户管理]]数据质量保障的重要措施。
