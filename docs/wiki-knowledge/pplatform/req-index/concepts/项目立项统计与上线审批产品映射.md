# 项目立项统计与上线审批产品映射

## 概述

项目立项统计与上线审批产品映射是产融平台V1.35版本定义的数据关联规则，用于在发起项目上线审批时，根据产品名称与产品类型之间的对应关系过滤关联的立项审批数据，确保数据关联的准确性。

## 映射关系

| 项目上线审批-产品名称 | 项目立项统计-产品类型 |
| :--- | :--- |
| 融易单 | 凭证-直保、凭证-再保、凭证-质押、跨境保理、其他（具体在项目描述中说明） |
| 保理易融 | 线上保理-直保、线上保理-再保、线上保理-质押、跨境保理、其他（具体在项目描述中说明） |
| 供应链票据 | 供应链票据、其他（具体在项目描述中说明） |
| 国内信用证 | 国内信用证、其他（具体在项目描述中说明） |
| 应收易融 | 订单融资、经销商融资、其他（具体在项目描述中说明） |

## 过滤逻辑

### 关联审批编号

下拉框枚举需依据当前发起上线审批页面产品名称判断，仅展示与该产品名称一致的审批编号。

### 项目立项审批编号

- 只要项目立项统计的产品类型其中一个类型可映射对应到当前的产品名称，即可展示
- 下拉框枚举需过滤数据库已删除内容
- 当"是否发起上线审批"为否时，若所选择的关联审批编号对应的项目立项编号的产品类型无法对应当前产品名称，则需将项目立项审批编号清空，让用户自行重新选择
