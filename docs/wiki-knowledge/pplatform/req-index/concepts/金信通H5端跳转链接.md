# 金信通H5端跳转链接

## 概述

金信通H5端跳转链接是产融平台V1.28版本的KA需求，为[[entities/地四金信数据科技新疆有限公司]]的[[entities/金信通平台]]移动端（H5）增加自营平台多级流转产品的跳转链接，以支持其开展自营多级流转业务。

## 背景

地四金信贴牌近期将开展业务，考虑到产品备案申请流程较长，与自营平台达成合作，在贴牌平台开展自营多级流转业务。前期已对PC端做了产品定制化调整，本期需同步对移动端（H5）进行优化。

## 功能设计

### 我的产品模块

在金信通贴牌移动端"我的产品"模块添加自营平台多级流转产品（[[entities/融易单]]）H5链接：
- **位置**：固定位于首个产品位置
- **展示**：不展示开通状态

### 交互说明

点击"融易单产品"后，新开浏览器窗口跳转至自营平台H5登录页。

### 限制说明

目前移动端不支持注册。如客户需从移动端开展多级业务，需先在PC端注册，然后使用注册账号到移动端完成建档、开展多级业务。
