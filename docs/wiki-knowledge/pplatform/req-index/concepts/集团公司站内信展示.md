# 集团公司站内信展示

## 概述

V1.25版本增加集团公司站内信展示功能，并取消集团公司进入[[线上保理]]业务系统的限制，同时提供集团成员单位查询接口。

## 背景

各业务系统已接入集团公司角色，近期有项目提出需对集团公司发送转让通知，需要同步站内信功能。

## 业务规则

### 站内信

- 产融平台增加集团公司站内信展示
- 消息中心同步展示
- 点击后支持预览
- 与其他企业角色查看站内信交互一致

### 菜单权限

取消集团公司不能进入线上保理业务系统的限制。

### 集团成员单位接口

产融平台提供查询集团集团单位信息接口给线上保理。

## 与集团成员管理的关系

本功能是[[集团成员管理]]在站内信和权限方面的扩展，使集团公司角色获得与其他企业角色一致的消息通知和系统访问能力。
