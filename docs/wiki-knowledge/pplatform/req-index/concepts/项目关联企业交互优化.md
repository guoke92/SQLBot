# 项目关联企业交互优化

## 概述

项目关联企业交互优化是产融平台V1.30版本的产品优化需求，将项目与企业关联关系的查看和管理从弹窗改为独立页面，并优化默认值逻辑，提升方案侧操作效率。

## 背景

产融平台支持查询企业关联的项目，并支持从关联项目处配置项目。方案侧反馈当前弹窗交互样式不利于操作。

## 优化内容

### 样式调整

点击【关联企业情况】，将现有弹窗样式调整为页面样式。

### 系统默认值

多级流转配置页面增加默认值：
- **企业角色**：只有一个企业角色时无需选择，系统自动带入该企业角色，无需展示弹窗
- **项目配置模式**：系统默认管理员模式，无需选择

### 项目开通状态

项目中心-项目关联企业情况，多个企业角色目前仅展示一条数据。近期上线"项目开通状态"功能后，需要根据企业角色展示对应的项目开通状态，多个企业角色时需展示对应企业角色的项目开通状态。

### 交互说明

多级流转项目下：
- 点击【前往项目关联配置】打开多级流转项目配置页，返回后项目关联企业情况页面保持开启，不做自动关闭
- 点击【查看项目关联配置】打开多级流转项目详情页，返回后项目关联企业情况页面保持开启，不做自动关闭
