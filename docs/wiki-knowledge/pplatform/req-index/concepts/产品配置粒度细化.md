# 产品配置粒度细化

## 概述

产品配置粒度细化是[[产融平台]]V1.3版本引入的一项功能增强，旨在将产品的可见性从租户级别细化到核心企业级别，实现更精准的产品授权控制。

## 需求背景

同一个[[租户]]下不同的KA（核心企业）使用的产品不一样，供应商能够看到哪些产品由其与哪些核心企业有合作决定。原有的产品配置粒度无法满足这一需求。

## 功能描述

### 核心企业管理

对于已开通的产品，操作栏上出现"核心企业管理"按钮，点击后进入配置页面：

- **适用的核心企业**默认为"贴牌下所有的核心企业"
- 配置人员可手工切换为"手动指定核心企业"
- 手动指定时，"核心企业列表"为必填项
- 支持手动选中和批量导入（Excel模板，仅含1个字段：核心企业名称）

### 配置效果

配置完成后，供应商端仅能看到与其有合作关系的核心企业对应的产品，实现产品可见性的精准控制。

## 与其他概念的关系

- 该功能是[[产融平台]]从粗放管理向精细化运营演进的重要体现
- 与[[运营配置]]模块共同构成精细化运营能力
- 产品配置页面同时增加了"最近修改时间"和"最近修改人"字段，增强配置变更的可追溯性
