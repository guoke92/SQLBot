# 企业联系人实名认证字段优化

## 概述

企业联系人实名认证字段优化是产融平台V1.28版本的产品优化，调整了企业联系人列表"实名认证"结果字段的取值逻辑。此前取值逻辑单一，本次优化使其能综合反映多项认证结果。

## 优化内容

### 认证结果枚举

| 枚举值 | 取值规则 |
| --- | --- |
| 未认证 | 默认状态 |
| 认证成功 | 任意一项认证结果通过 |
| 认证失败 | 两项认证结果均不通过，或存在认证失败项和为空项 |

### 认证项

结合以下两项认证结果进行取值（文档修订后从三项减为两项）：
1. 操作人人脸识别
2. 操作人手机号实名认证

~~操作人证件号实名认证~~（已从需求中删除）

### 存量数据处理

历史"实名认证"结果字段中，"自动认证成功"和"人工认证成功"均处理为"认证成功"。

## 与现有概念的关系

与 [[concepts/人脸识别认证]] 相关，人脸识别认证结果是本字段取值的输入之一。
