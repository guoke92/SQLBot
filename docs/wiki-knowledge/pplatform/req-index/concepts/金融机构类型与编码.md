# 金融机构类型与编码

## 概述

"金融机构类型"和"金融机构编码"是[[产融平台]]V1.15版本新增的[[补充字段]]，用于满足[[动产融资统一登记公示系统]]（人行中登）接口切换后的新登记要求。

## 租户配置

在【租户配置-注册配置-补充字段配置】中，现有字段最后新增"金融机构类型（通用）"字段：

| 配置项 | 说明 |
|-------|------|
| 字段名 | 金融机构类型（通用） |
| 枚举值 | 非必填、必填（单选） |
| 适用角色 | 默认"金融机构"，置灰不可编辑 |

## 字段定义

### 金融机构类型

- **必填**：是
- **格式**：级联选择（可搜索）
- **枚举值样式**：一级类型/二级类型（如有）/三级类型（如有）
- **数据来源**：《动产融资统一登记公示系统接口设计说明书V4.0.2》中的担保权人类型分类
- **悬浮提示**：中登登记使用

### 金融机构编码

- **显示条件**：金融机构类型 = 金融机构
- **必填**：是（当显示时）
- **格式**：输入框，文本类型无限制
- **字段长度**：18
- **悬浮提示**：中登登记使用

#### 自动查询功能

点击输入框【自动查询】按钮，调用[[RPA]]接口查询"金融机构类型"对应的"金融机构编码"，将查询结果自动反显。

校验规则：
- 未输入"金融机构类型"时点击【自动查询】，进行必填校验，不触发接口调用
- 如先输入"金融机构编码"再点击【自动查询】，需更新结果

## 业务数据同步

推送业务系统企业信息时需同步推送新增字段：
- **多级流转**：需要同步
- **线上保理**（讯易链同步）：需要同步
- **供票产品**：无金融机构，暂不需要

## 展示位置

- **建档页面**：企业信息补充字段区域
- **非建档页面**：内管端-客户信息（企业信息）-补充字段tab页，现有字段最后同步新增
