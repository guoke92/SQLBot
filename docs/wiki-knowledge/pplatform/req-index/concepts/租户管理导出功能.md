# 租户管理导出功能

## 概述

租户管理导出功能是产融平台V1.23版本中为租户管理列表新增的【导出】功能，支持全局导出和筛选导出，以满足运营人员统计产融平台租户信息的需求。

## 业务背景

此前租户管理页面无导出功能，实际业务中经常需要统计产融平台租户信息，运营人员只能手动记录，效率较低。

## 功能规则

- 租户管理列表顶部按钮新增【导出】
- 支持两种导出模式：
  - **全局导出**：导出所有租户信息
  - **筛选导出**：导出当前筛选条件下的租户信息
- 导出文件命名规则：`产融平台租户管理YYYYMMDD`
