# 非自主认证建档&变更.docx

非自主认证建档&变更

邀请认证-客户录入

步骤：

1、后台新增企业，邀请客户录入：

客户收到短信后登录客户端点击待办开始认证：

处理规则：

内管端在选择邀请认证-客户录入时若填写了企业信息，那么客户登录时点击待办后页面自动回填已填写的信息；

添加收款账户步骤：企业角色为供应商、经销商必填，其他企业角色可不填跳过到下一步；各角色认证的节点及是否必填总结如下，√为有该节点，×为无该节点；其中，无论何角色若企业未开通CA则无授权确认书签署方式弹窗和选择认证方式弹窗：

被授权人人脸认证后，需根据下表判断能否到签署授权书步骤：

签署授权书步骤(产融平台判断推给运营中台)：

企业开通CA && 企业角色为：供应商、经销商和项目公司时，可选择线上 或 线下签署；

企业不开通CA 或 企业角色为核心企业、资金方时，只能线下签署；——直接跳转至线下签署页面

签署完成后，

若企业开通CA,则根据上表“签署授权书方式”列判断是否需要认证，若需要认证时认证方式弹窗的枚举展示；

若企业不开通CA,跳过签署授权书认证方式步骤直接提交;

认证完成提交后:(转成表格)

若企业开通CA,则根据上表“流程提交后的步骤”列展示提交后的对应页面；

企业不开通CA时,根据以下条件展示对应页面：

被授权人手机号过&人脸不过，进入人工核查；

被授权人手机号不过&人脸过，

若上传的授权书签章核验及比对通过，十项核查通过即通过；

若上传的授权书签章核验及比对不通过，进入人工核查；

被授权人手机号&人脸均不过，页面提示无法提交；

邀请认证-平台录入

步骤：

后台新增企业，提交运营中台审核通过后更新企业状态并发送短信给企业管理员确认；

企业管理员收到短信后登录客户端点击待办确认认证信息并进行人脸认证，人脸认证通过后企业认证成功；

处理规则：

被授权人人脸需剔除出十项核查,在审核通过后再做人脸;

运营在平台端新增企业并录入信息，提交运营中台审核：

运营中台审核退回，产融更新企业状态为退回，可删除或编辑后重新提交审核；

运营中台补充材料，仅“邀请认证-平台录入”流程下得待办任务增加“重新ocr并核查”按钮，可对所有影像进行ocr，并根据最新的字段进行核查比对;

运营中台审核拒绝，状态“拒绝”，产融更新企业状态为认证失败，可删除或编辑后重新提交审核；

运营中台提交客户确认，状态“待客户处理”，产融更新企业状态为待客户确认，并发送短信给企业管理员确认；

企业管理员登录客户端，通过首页待办进入企业信息确认页，仅可查看审核通过的企业认证信息：

若信息无误，点击“确认认证信息”按钮，进行企业管理员人脸识别认证，

人脸认证通过后企业状态变为认证成功；

人脸认证不通过时联系运营处理；

若信息有误，可点击下方按钮“信息有误，我要更新”按钮，弹窗展示运营联系方式：（待客户处理运营中台修改后客户重新确认的交互）

配置的联系方式为电话时，展示电话联系的弹窗；

配置的联系方式为企微/微信二维码时，展示二维码弹窗；

c）用户确认信息后，更新状态及运营中台最新建档数据（字段及影像）

简易认证

步骤：

后台新增企业，提交后自动审核通过，企业状态为待客户确认并发送短信给企业管理员确认；

企业管理员收到短信后登录客户端点击待办确认认证信息并进行人脸认证，人脸认证通过后企业认证成功；

处理规则：

运营在平台端新增企业并录入信息，提交后自动审核通过，企业状态为待客户确认并发送短信给企业管理员确认

企业管理员登录客户端，通过首页待办进入企业信息确认页，仅可查看审核通过的企业认证信息，并进行企业管理员人脸识别认证：

人脸认证不通过时联系运营处理；

若简易建档开通了CA，则在人脸认证通过后还需阅读并同意CFCA服务协议；若未开通CA则人脸认证通过后即认证成功；

企业联系人页面增加按钮【人工识别】，人工识别按钮展示条件：

企业状态为待客户确认+企业认证方式为简易认证+系统人脸识别状态为识别失败；

点击人工识别按钮弹窗展示客户的人脸认证视频，可点击识别成功人工修改人脸认证状态为识别成功（人工）；

5、需推送至运营中台生成审核通过的数据（影像和字段），核查项均为待核查；（推送审核通过建档信息时触发信息同步到在途资产）

【变更】简易认证-企业信息变更、增加企业角色（需运营中台处理数据同步）

步骤：

企业信息变更

企业信息变更由平台端在企业信息维护处发起，点击【变更】按钮选择变更类型、变更方、是否需要企业管理员授权、是否需要法定代表人授权，此处为产融平台页面。

变更类型共11项，具体根据企业认证方式（邀请认证-客户录入、邀请认证-平台录入、简易认证）、是否总分公司展示，详见前述文档”非供应商角色建档梳理“。支持多选，多个变更类型取最大并集进行处理。产融平台与运营中台变更类型映射关系：

变更类型校验：简易认证时若同时选中“企业信息变更”和“重新建档”，则进行提示：

变更任务校验：企业联系人变更中，不支持发起企业信息变更，企业信息列表不展示【变更】按钮；当前企业信息变更中，企业信息列表不展示【变更】按钮。

企业管理员变更

企业管理员变更由平台端在企业联系人处发起，点击【变更】按钮选择变更类型、变更方、是否需要企业管理员授权、是否需要法定代表人授权，此处为产融平台页面。

变更类型共3类：企业管理员变更、企业管理员手机号变更、企业管理员证件有效期变更。支持多选，多个变更类型取最大并集进行处理。产融平台与运营中台变更类型映射关系：

变更任务校验：企业信息变更中，不支持发起企业管理员变更，联系人列表不展示【变更】按钮；当前企业管理员信息变更中，联系人列表不展示【变更】按钮。

处理规则：

变更方式：根据变更类型支持的变更发起方式展示。

所选变更类型均支持平台录入、企业自行录入的，两种方式支持选择其一；

所选变更类型存在仅支持平台录入的或不支持企业自行录入的（例：讯易链核企变更管理员手机号），默认选择平台变更，企业自行变更置灰。

详见前述文档”非供应商角色建档梳理“。

验证方式：必填，多选，两种验证方式支持同时选择或选择其一。所选变更类型包含“企业管理员变更、企业管理员手机号变更、企业授权书、增加企业角色-核心企业、简易认证-重新建档”时需展示验证方式字段。

企业管理员授权：若选择需要企业管理员授权，平台变更完成企业信息确认时需进行企业管理员授权，企业自行变更过程中需进行企业管理员授权；若选择无需企业管理员授权，则省略该步骤。

法定代表人授权：若选择需要法代授权，平台变更完成企业信息确认时需进行法代授权，企业自行变更过程中需进行法代授权；若选择无需法代授权，则省略该步骤。

变更类型、企业管理员授权、法定代表人授权、企业是否开通CA（涉及线上/线下签署）需要产融平台推送至运营中台，后续变更由运营中台处理。涉及变更的字段及影像件自动反显历史值支持编辑，不涉及变更的字段及影像件自动反显只读。

变更类型包含“增加企业角色”时，"选择变更方式"展示“增加企业角色”行，必填，单选，已有角色不显示，仅显示待增加的角色。变更方默认为“平台变更”，“企业自行变更”置灰不可选择，仅新增角色为“核心企业”时，展示验证方式字段。

变更方、企业管理员授权、法定代表人授权，产融平台与运营中台变更类型映射关系：

变更企业登录客户端点击待办进行企业信息变更或确认变更信息，此处为运营中台页面：

平台变更：根据所选变更类型进行平台变更，变更完成后对变更企业发送信息确认提醒待办和短信通知（接收人同企业认证接收人）。变更企业登录客户端点击待办【去确认】按钮，根据企业认证方式走相应的信息确认流程，不展示账户信息步骤页，其他同建档信息确认。

客户端待办信息确认

企业自行变更：对企业发送变更提醒待办和短信通知（接收人同企业认证接收人），根据所选变更类型及企业认证方式走对应的企业信息变更流程，同建档页面。

企业认证方式为”简易认证“，企业变更走产融平台页面，是否需要运营中台处理与变更类型有关。

变更类型为”企业信息变更“时：默认平台变更，无需企业管理员、法定代表人授权。需运营中台处理数据同步。

变更类型为“增加企业角色”时：默认平台变更，无需企业管理员、法定代表人授权，自动生效，无需运营中台处理。

变更类型为“企业管理员变更、企业管理员手机号变更、企业管理员证件有效期变更”，由平台端在企业联系人处发起，默认平台变更，无需企业管理员、法定代表人授权，自动生效，无需运营中台处理。

变更类型为包含“企业信息变更、增加企业角色”，默认平台变更，无需企业管理员、法定代表人授权，选择变更方式弹窗点击【确定】跳转至“简易认证企业信息”详情页，页头调整为“变更企业信息”，根据所选变更类型进行后续操作。

变更类型为”重新建档“时：统一社会信用代码不支持变更。变更方=平台变更，默认走“邀请认证-平台录入”建档流程；变更方=企业自行变更，默认走“邀请认证-客户录入”的建档流程，且默认需要企业管理员、法定代表人授权。变更提交页根据认证方式与建档提交页一致，后续流程同建档，需要运营中台处理。
