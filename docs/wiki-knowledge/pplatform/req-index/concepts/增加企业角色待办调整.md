# 增加企业角色待办调整

## 概述

增加企业角色待办调整是产融平台V1.23版本中对"增加企业角色"场景下信息确认待办发送逻辑的修正，将待办发送对象从新管理员调整为变更时录入的管理员手机号。

## 业务背景

此前需求中管理员变更信息确认待办发送至新的管理员，但在"增加企业角色"场景下该逻辑产生了副作用——信息确认待办的发送对象受到影响，需要更正。

## 修正规则

企业信息变更-增加企业角色场景下，企业信息确认待办发送至**变更时录入的管理员手机号**。

## 与其他功能的关联

- 与[[企业信息变更-平台录入自行变更]]相关，均涉及企业信息变更场景下的待办和通知机制
- 本修正说明了跨场景复用逻辑时可能出现的副作用问题
