# 余蔷(王祖贤)

余蔷（花名：王祖贤）是[[产融平台]]的产品经理之一。

## 职责

在V1.21版本中，余蔷负责[[额度管理]]模块的需求设计，具体需求指向外部文档《额度管理模块V1.0》。

## 与其他产品经理的协作

余蔷与[[侯叔彤]]、[[刘维静]]、[[陈秋芸]]等产品经理共同参与产融平台的产品迭代工作。
