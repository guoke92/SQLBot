# Dbass

## 概述

Dbass是与企业微信立项审批流程相关的系统，在V1.25版本中作为企微"【战略客户】项目立项审批"数据的来源系统，其审批通过的项目信息通过接口同步至产融平台进行展示和管理。

## 与产融平台的关系

产融平台通过对接中台"【战略客户】项目立项审批"接口获取Dbass中的立项审批数据，在[[企微立项审批集成|企微立项审批]]菜单中展示审批通过的项目信息。

## 相关功能

- [[企微立项审批集成]]：将Dbass中的审批数据接入产融平台
- [[项目管理看板]]：展示立项审批相关字段数据
