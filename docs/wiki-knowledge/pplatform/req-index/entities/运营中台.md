# 运营中台

运营中台是[[chanrong-platform|产融平台]]依赖的关键系统，负责处理企业建档、审核、变更等核心流程。

## 与产融平台的集成关系

产融平台的企业核心流程高度依赖运营中台，包括：

- **客户审核（建档审核）**：复用运营中台的建档自动化设计
- **企业认证流程**：供应商认证跳转运营中台的认证界面
- **企业信息变更**：变更流程完成需提交运营中台审核

## 认证流程分工

不同企业角色在运营中台上的处理方式有所不同：

| 企业角色 | 认证流程 |
|---|---|
| 新供应商 | 发起认证跳转运营中台认证界面；变更分网关发起和客户端发起两种模式 |
| 核心企业 | 自动建档暂不支持，产融上线时若运营中台未实现需走旧非自主建档流程 |
| 资金方 | 简易建档不做审核，提交后自动审核通过 |

## 风险评估

产融平台对运营中台存在强依赖风险：
- 如果产融上线时运营中台仍未实现，核心企业的认证需要走旧的非自主建档流程
- 部分客户签署的授权书版本升级，需走变更流程使用运营中台现有页面
- 企业升级流程需调用运营中台建档页面
