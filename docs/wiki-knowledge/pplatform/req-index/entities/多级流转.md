# 多级流转

多级流转是[[chanrong-platform|产融平台]]底座的已上架[[product-chanrong|产品]]之一，属于供应链金融领域的核心业务产品。

## 项目状态映射

多级流转系统有两个项目状态需要映射至产融平台：

| 多级流转状态 | 产融平台状态 |
|---|---|
| 待提交 | 待生效 |
| 已生效 | 已生效 |

## 产品类型

多级流转属于供应链金融产品，在[[tenant|租户]]配置上架时需要配置产品介绍信息和开通协议。具体的业务办理页面仍由业务系统提供，产融平台作为入口进行跳转。
