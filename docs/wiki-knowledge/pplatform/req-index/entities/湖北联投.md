# 湖北联投

## 概述

湖北联投是产融平台的一个客户组织和重要租户，具有多租户关联和门户定制化的典型代表特征，其"贴中贴"项目结构是V1.17版本"租户间关联"和"门户登录页定制化"需求的主要驱动方。在产融平台V1.26版本中，针对其特殊的本地化登录跳转对接方式，在移动端进行了登录优化。湖北联投在产融平台迁移中扮演核心角色，是省地共建多租户项目的典型代表。

## 在产融平台中的角色

湖北联投的需求主要体现在：

1. **多租户关联**：湖北联投贴牌及其他贴牌间存在归属关系，讯易链侧支持配置贴牌间关联关系，迁移产融需保留各贴牌间的关系。
2. **门户定制化**：湖北联投的贴中贴项目均从湖北联投本地化单点登录，与讯易链平台做建档互通。
3. **省地共建**：湖北联投是省地共建多租户项目的典型代表。

## 贴中贴清单

以下平台均为湖北联投贴中贴项目：

- 襄链通
- 罗田云链
- 楚堰通
- 江汉云链
- 联链通(AMS)
- 铜都云链
- 应融通
- 利好融
- 邕链通
- 第五师供销社农业社会化服务平台

> **说明**：V1.14&V1.15版本需求文档中列出的贴中贴项目为前八项；V1.17版本需求文档补充了邕链通和第五师供销社农业社会化服务平台，并标注联链通对应AMS。

## 定制化需求

### 租户间关联

租户配置增加"主定制项目标识（中文）"字段，枚举值当前仅包含"湖北联投"。选择主定制项目标识后即与湖北联投建立关联关系。湖北联投可查看所有关联的贴中贴租户。

### 门户&登录页定制化

- **门户页/登录页**：通过租户配置实现，【主定制项目标识(中文)】=湖北联投时隐藏登录入口。
- **单点登录**：产融平台针对贴牌配置单点登录，与湖北联投本地化平台实现单点登录及企业建档互通。
- **退出登录**：【退出登录】按钮隐藏。
- **小程序**：联链通。
- **H5**：无。
- **移动端登录优化**：在产融平台V1.26版本中，针对湖北联投特殊的本地化登录跳转对接方式，进行了移动端登录优化。

## 历史数据迁移

讯易链侧"湖北联投"贴中贴项目已配置主定制项目标识（中文），迁移产融平台需同步迁移该逻辑。

## 与其他实体的关系

- 与[[讯易链]]：贴中贴项目从讯易链迁移而来，迁移需保留贴牌间关联关系。
- 与[[ams]]：联链通(AMS)为湖北联投贴中贴项目之一。
- 与[[产融平台]]：V1.17版本核心改造对象。
