# 侯叔彤

侯叔彤是[[产融平台]]的产品经理，负责多个版本需求的设计与推进。

## 职责范围

### 产融平台V1.14 & V1.15

在产融平台V1.14&V1.15版本需求文档中，侯叔彤负责以下15项需求（共17项中的15项）：

- 工行供应链编号
- 企业信息变更
- 移动端
- 租户间关联
- 门户&登录页定制化
- 跳转AMS
- 山东高速
- 厦门国际银行
- 企业名称格式调整
- 运营方法人信息调整
- 增加总共变更为分公司的变更类型
- 变更类型"增加企业角色"优化
- 企业信息增加补充字段
- 企业信息维护列表增加查询条件

### 产融平台V1.26

在[[4-需求文档--18-产融平台v126版本需求文档0129--eyrepd|产融平台V1.26版本]]的需求文档中，所有10项产品优化需求均由侯叔彤负责。

## 协作关系

与另一位产品经理[[刘维静]]共同负责产融平台产品工作。刘维静在V1.14&V1.15版本中负责"分公司建档时授权书内取总公司的名称"和"增加融易单的项目时支持跳转新的配置页面"两项需求。
