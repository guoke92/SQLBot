# 应收易融

## 概述

应收易融是产融平台提供的供应链金融产品之一，通过[[讯易链]]平台提供服务，与[[融易单]]共享相似的业务规则。

## V1.9版本相关需求

### 租户推送逻辑
- 应收易融有"开通中"状态
- 在开通中阶段即同步租户信息给业务系统
- 同步失败应给出相应提示，无法进入下一步
- 详见[[租户推送逻辑调整]]

### 供应商关联项目即生效
- 应收易融为当前涉及产品之一
- 供应商输入项目码后关联关系即生效，无需运营确认
- 详见[[项目码]]和[[供应商关联项目即生效]]

## 关联

- 所属系统：[[产融平台]]
- 业务平台：[[讯易链]]
- 关联产品：[[融易单]]（同类产品，共享相似规则）
