# 短信中台

短信中台是产融平台的消息服务系统，负责短信的发送和管理。

## V1.13版本变更

### 短信签名自动同步

V1.13版本之前，产融平台导入短信模板后会自动同步至短信中台，但短信签名不会同步，需要手动新增。V1.13版本优化为：在产融侧导入短信模板时，自动将短信签名同步至短信中台侧。

### 与消息模板"无定制"功能的配合

[[租户]]配置消息模板时支持选择"无定制"（使用通用模板），仅需配置短信签名即可实现导入，短信中台需支持此模式下的模板同步。
