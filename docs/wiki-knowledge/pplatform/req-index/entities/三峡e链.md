# 三峡e链

## 概述

[[三峡e链]]是产融平台的一个贴牌，属于AMS类型，与AMS通过建档互通方式实现交互。

## 在产融平台中的角色

三峡e链在产融平台迁移中具有特定需求，主要体现在：

1. **门户定制化**：门户页、登录页通过租户配置实现。
2. **统一入口**：三峡e链贴牌项目的统一入口需求需调整为产融平台实现。
3. **小程序**：小程序定制化。
4. **建档互通**：与AMS通过建档互通方式实现。

## 定制化需求

### 门户&登录页定制化

- 门户页、登录页：租户配置实现。
- 统一入口：三峡e链贴牌项目的统一入口需求需调整为产融平台实现。
- 小程序：小程序定制化。

### 与AMS建档互通

以下需求需AMS系统改造，AMS优化完成后即与产融平台实现建档互通，无需再对贴牌做定制化开发。
