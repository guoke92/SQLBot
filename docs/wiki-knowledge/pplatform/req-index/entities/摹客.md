# 摹客 (Mockplus / llschain.com)

摹客是文档中多处引用的原型设计工具，域名标识为 llschain.com，用于展示[[chanrong-platform|产融平台]]的UI交互原型。

## 在文档中的使用

文档中的多个功能模块都引用了摹客的原型链接，包括：

- 登录注册原型：`idoc.llschain.com/rp/run/ALu71zma-e/qREiA3w43tA`
- 认证原型：`idoc.llschain.com/rp/run/ALu71zma-e/cmJ19eb58B0`
- 首页原型：`idoc.llschain.com/rp/editor/Wb08VQ_jL/a0wHg6EZl`
- 消息中心原型：`idoc.llschain.com/s/G_L2BQsyt`
- 企业中心原型、用户中心原型、个人中心原型等多处引用

## 备注

摹客原型中的大量UI细节（如按钮颜色、弹窗样式、交互流程等）属于实现细节，Wiki中不重复记录。需要查看具体交互时请参照原始原型链接。
