# 动产融资统一登记公示系统

动产融资统一登记公示系统（简称"中登系统"）是中国人民银行运营的动产融资统一登记平台，用于登记和公示动产融资相关信息。

## 与产融平台的关系

[[产融平台]]V1.14&V1.15版本中，因中登登记接口进行切换，按照新增的中登登记要求，金融机构端需要新增传输相关字段。具体影响包括：

- 在企业信息中新增[[金融机构类型与编码]]补充字段
- 金融机构类型字段的枚举值来源于中登系统接口设计说明书V4.0.2中的"担保权人类型"分类
- 金融机构编码支持通过[[RPA]]接口自动查询

## 数据来源

金融机构类型的枚举值参考文档：《动产融资统一登记公示系统接口设计说明书V4.0.2》中的担保权人类型分类，采用"一级类型/二级类型（如有）/三级类型（如有）"的级联选择格式。
