# 中铁四局

中铁四局是产融平台的核心企业（KA）客户，在V1.29版本中提出了标准化接口对接的需求。

## 角色与需求

- **客户类型**：核心企业（KA）
- **需求产品经理**：[[周水平]]
- **核心需求**：标准化接口对接——KA标准化接口的新建对接需求，列为V1.29版本【高】优先级

## 与其他KA客户的关系

中铁四局与[[中交疏浚]]同为产融平台KA标准化接口对接的重点客户。中交疏浚侧重于在已有接口基础上增加变更场景支持，中铁四局则为新建标准化接口对接。
