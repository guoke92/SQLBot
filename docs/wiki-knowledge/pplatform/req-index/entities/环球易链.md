# 环球易链

环球易链是[[产融平台]]的一个贴牌（租户），在V1.18版本中被纳入贴牌迁移适配范围。

## V1.18版本需求

环球易链在建档环节存在定制化需求，迁移产融平台需同步处理。状态为**需改造**。

### 改造点

1. **H5建档的提示文案**：运营中台保持环球易链现有的小程序建档文案，调整为与产融平台对接。产融平台支持小程序建档，无需改造，使用现有逻辑。
2. **资金方数据隔离（金融机构关联项目）**：资金方登录的域名为环球易链的域名。资金方只能关联环球易链贴牌下的项目，不能关联其他贴牌的项目。这是产融平台多租户架构下数据隔离的一个具体实现。
