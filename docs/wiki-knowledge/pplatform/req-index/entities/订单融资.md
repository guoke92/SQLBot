# 订单融资

订单融资是[[产融平台]]对接的业务系统之一，在V1.7版本中涉及多项需求。

## 与多级流转的关系

订单融资目前统一走[[多级流转]]的建档流程，因此企业的首份授权书在多级，变更产生的授权书也统一在多级。

## V1.7版本涉及的需求

### 企业协议迁移

订单融资作为[[企业协议迁移]]的关联系统之一，需要在存量企业数据迁移时同步相关协议数据给产融，包括：
- 产品服务协议（配置在项目上，每新增一个项目企业需签署一次）
- 用户注册协议（同上）

订单融资无隐私协议（由多级传给它）和CFCA协议的独立管理。

### 项目配置与关联状态

订单融资产品在企业关联项目时需要进行企业维度的项目配置，关联状态包括"关联未生效"和"关联已生效"两种（与[[多级流转]]一致）。

### 项目码

订单融资的项目在新增时需要支持[[项目码]]字段。
