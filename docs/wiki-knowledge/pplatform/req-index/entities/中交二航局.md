# 中交二航局

## 基本信息

中交二航局是产融平台的二级贴牌客户，隶属于中交集团体系。在产融平台的租户层级结构中，中交二航局作为二级租户存在，历史归属讯易链侧管理。

## 在产融平台中的角色

- **租户类型**：二级贴牌（二级租户）
- **历史系统**：原在[[讯易链]]侧管理，迁移产融平台后归入自营平台下
- **业务需求**：提出新建线上保理项目的需求，推动了产融平台V1.23版本中[[线上保理支持二级租户]]功能的开发

## 业务影响

中交二航局的业务需求是V1.23版本中线上保理支持关联二级租户功能的直接驱动因素。此前仅多级流转项目支持关联二级租户，本次扩展使线上保理产品也具备了该能力。
