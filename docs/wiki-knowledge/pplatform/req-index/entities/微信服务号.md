# 微信服务号

## 概述

微信服务号是[[产融平台]]V1.22版本中引入的新消息通知渠道。作为短信的补充，用于在短信发送失败时提供备选的消息发送途径。

## 在产融平台中的角色

- 作为[[短信中台]]的补充消息渠道
- 通过[[微信服务号接入]]功能集成到产融平台的消息通知体系中
- 具体接入方案参见外部设计文档《短信自动路由&微信服务号设计文档》
