# 楚道云链

## 概述

[[楚道云链]]是产融平台的一个贴牌/重要租户之一，属于定制类型，具有深度定制化门户/登录页需求，包括代码定制。V1.17版本需要在贴牌配置基础上进行代码级定制化开发，包括门户页、登录页和小程序。

## 在产融平台中的角色

楚道云链在产融平台迁移中具有特定需求，主要体现在：

1. **门户定制化**：门户页、登录页在贴牌配置基础上代码定制开发，需按照迁移前效果进行还原和实现。
2. **小程序**：小程序定制化，需按照迁移前效果进行还原和实现。

楚道云链是V1.17版本中定制化程度最高的租户之一，门户页、登录页和小程序均需要代码级定制开发，且要求"按照迁移前效果进行还原和实现"，体现了从[[讯易链]]迁移过程中保留历史定制化功能的挑战。

## 定制化需求

### 门户&登录页定制化

- 门户页、登录页：贴牌配置基础上代码定制开发，需按照迁移前效果进行还原和实现。
- 生产地址：https://hbjt.xyc.llschain.com

### 小程序

- 小程序定制化，需按照迁移前效果进行还原和实现。

### 历史需求

- 贴牌配置基础上增加代码定制化开发的门户页、登录页，包括小程序为代码定制。
