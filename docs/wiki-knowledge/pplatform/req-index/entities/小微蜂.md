# 小微蜂

## 概述

小微蜂是产融平台V1.10版本需求文档中提及的一个第三方系统，属于尚未迁移至产融平台的我司产品。作为[[系统互通产品]]的目标系统之一，小微蜂可通过产融平台的系统互通功能实现跳转访问和建档信息同步。

## 与产融平台的关系

- 小微蜂未迁移至产融平台，属于系统互通类产品
- 客户开通小微蜂业务后，可通过产融平台（统一门户）获得跳转入口
- 产融平台可将客户已有的建档信息推送至小微蜂，避免客户重复建档

## 关联实体

- [[产融平台]]：提供跳转入口和建档信息同步
- [[AMS]]：同为未迁移至产融的第三方系统
- [[系统互通产品]]：小微蜂所属的产品分类
