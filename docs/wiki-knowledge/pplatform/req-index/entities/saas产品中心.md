# SaaS产品中心

SaaS产品中心是产融平台的内部组织/部门，负责人为[[江彦颖]]。

## 职能

- 与[[saas方案部|SaaS方案部]]共同参与项目立项审批流程。
- 在[[项目立项统计]]的"方案经理"取值逻辑中，SaaS产品中心负责人是"主项目"类型下方案经理的候选审批人之一。
