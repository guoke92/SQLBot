# 城发产融

## 概述

[[城发产融]]（城发产融服务平台）是产融平台的一个贴牌，属于定制类型，是产融平台的重要租户之一。具有深度定制化门户/登录页需求，包括首页分流。

## 在产融平台中的角色

城发产融在产融平台迁移中具有特定需求，主要体现在：

1. **门户定制化**：门户页、登录页通过租户配置+定制开发实现。
2. **首页分流**：点击【银票秒贴、中标贷】跳转至城发产融服务平台。
3. **小程序**：小程序定制化（目前已停用，V1.17版本无需处理）。

## 定制化需求

### 门户&登录页定制化（V1.14/V1.15）

- 门户页、登录页：租户配置+定制开发，按照当前门户页样式及内容实现。
- 点击【银票秒贴、中标贷】跳转以下页面：城发产融服务平台（生产地址）。
- 小程序：小程序定制化。

### V1.17版本改造

- 取消当前"供应商、核心企业"分流样式
- 统一调整为"城发e链"，点击后为产融平台当前登录样式，登录后进入产融平台
- 保留"供票秒贴、中标贷"跳转登录功能
- 点击"银票秒贴、中标贷"跳转至城发产融服务平台（https://lycfjt.llssme.com/#/home，生产地址）
- 生产地址：https://lycfjt.xyc.llschain.com
