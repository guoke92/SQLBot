# 联易融

## 概述

联易融是[[产融平台]]的平台方管理员企业，作为系统的运营主体。在V1.3版本中，联易融被设定为默认的平台方角色及企业。

## 在产融平台中的角色

联易融在产融平台中具有特殊地位：

- 作为平台方管理员企业（1个角色下仅1个企业）
- [[讯易链]]多级流转有平台端，可登录系统查看具体的菜单功能

## 后台预置逻辑

该企业的处理逻辑：

1. 在企业表中插入数据即可，不需要通过前端界面做新增，企业状态为"建档成功"
2. 该企业下的操作员数据也为后台插入，不需要通过前端界面做新增
3. 该企业的管理员登录产融后，可以看到所有的产品入口，且全部为"已开通"状态，不需要再手动去开通产品和签署产品服务协议
4. 企业的管理员点击产品卡片后，如果能找到对应的菜单权限，则可以进入查看具体的菜单，如没有则提示"暂无可使用的菜单"

## 与其他实体的关系

- 与[[讯易链]]同为产融平台生态中的重要组织实体
- [[讯易链]]是[[多级流转]]的实现方
- 联易融作为平台方，对整个[[产融平台]]具有管理权限
