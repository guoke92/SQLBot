# 速链云客商系统

## 概述

[[速链云客商系统]]是山东高速的外部客商管理系统，与产融平台存在客商主数据对接需求。

## 在产融平台中的角色

速链云客商系统在产融平台迁移中具有特定角色，主要体现在：

1. **客商主数据对接**：平台建档审核通过后需通过接口与速链云客商系统交互。
2. **接口监控**：使用讯易链现有接口监控功能，对接方为速链云客商系统。

## 对接需求

### 客商主数据对接

平台建档审核通过后需通过以下接口与速链云客商系统交互：
- 【1.1.1.新增客商申请单（第三方系统到中台）】
- 【1.1.3.客商申请单状态反馈接口（中台到第三方系统）】

### 接口监控

使用讯易链现有接口监控功能，对接方为速链云客商系统，接口名称为新增客商申请单。

### 定时任务及邮件告警

使用讯易联现有定时任务及邮件告警。企业状态=冻结，无需重推，现有逻辑。
