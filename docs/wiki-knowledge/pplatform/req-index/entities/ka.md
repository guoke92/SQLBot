# KA

## 概述

KA（Key Account）是产融平台中的关键合作伙伴/客户角色。KA通过接口向产融平台推送企业数据，是[[接口建档]]功能的主要使用者。

## 与产融平台的数据交互

### 推送方式

KA通过标准接口向我司系统推送企业信息，用于企业建档。推送为**单向**数据同步，产融侧建档状态变化不回传KA。

### 存量与新增项目策略

| 项目类型 | 对接方式 |
|----------|----------|
| 存量项目（迁移产融后） | KA仍对接多级流转原有接口，多级流转透传至产融平台 |
| 新增项目（迁移产融后） | KA对接产融平台定义的新接口，由产融维护 |

### 推送失败处理

推送失败或建档审核拒绝时，KA可再次通过接口推送同一企业信息。

## 变更控制

由KA推送至产融的企业信息，一般不支持在产融侧发起变更。变更需在KA侧完成后再同步至产融（可通过[[授权建档]]配置控制）。
