# RPA

RPA（机器人流程自动化）在产融平台V1.13版本中用于自动查询金融机构编码。

## 应用场景

在[[金融机构]]企业信息维护中，新增的"金融机构编码"字段支持通过RPA接口自动查询。用户点击【自动查询】按钮后，系统调用RPA接口，根据已输入的"金融机构类型"查询对应的"金融机构编码"并自动反显。

## 交互规则

- 未输入"金融机构类型"时点击【自动查询】，触发必填校验，不调用接口
- 如先手动输入"金融机构编码"再点击【自动查询】，查询结果会覆盖已有输入

接口地址参考：`https://doc.linklogis.com/books/63311055da1c1d0012037ef5/view/67c00467073ebb883ebcf6b6`
