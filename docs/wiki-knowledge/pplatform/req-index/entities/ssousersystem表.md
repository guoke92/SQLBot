# sso_user_system表

## 概述

sso_user_system 是SSO单点登录系统的用户系统关联表，存储用户与业务系统的关联关系及各系统的原密码。

## 字段定义

| 字段 | 说明 |
|------|------|
| id | 主键 |
| sso_id | 外键，关联 [[sso-user]] 表的 sso_id |
| user_sys_channel | 业务系统编号 |
| password | 系统原密码（如需要） |
| user_status | 用户状态 |

## 关联关系

- 通过 `sso_id` 关联 [[sso-user]]（用户基本信息表）

## 安全设计

该表是 [[用户信息与身份鉴别信息分离存储]] 策略的组成部分：

- 独立存储用户与各业务系统的关联关系
- 各系统的原密码独立存储，与用户基本信息分离
- 可对密码相关字段设置更严格的访问权限

## 业务用途

- 管理用户在不同业务系统中的身份关联
- 存储各业务系统所需的原密码（如需要对接第三方系统）
- 支持SSO单点登录的多系统统一认证
