# SaaS方案部

SaaS方案部是产融平台的重要业务用户部门，在V1.30版本中扮演核心角色：

- **项目立项统计**（需求7）：该功能的核心目标用户。目前SaaS方案部针对业务立项审批的项目均采用线下人工维护项目表的操作方式，存在耗时长、信息缺漏/未更新等问题。V1.30版本将项目统计表线上化，通过系统实现数据统计
- **批量变更方案经理**：方案经理的取值来源为SaaS方案部人员，通过企微接口获取部门成员信息
- **菜单权限**：新增"项目立项统计"页面权限配置至SaaS产品，SaaS方案人员可见、可编辑

SaaS方案部的需求推动了[[项目立项统计]]这一本版本最复杂新增功能的建设。
