# 金融机构

金融机构是产融平台中的一种特殊[[企业产融平台语境|企业角色]]，V1.13版本为其新增了专门的字段和认证规则优化。

## 新增字段

为满足人行中登登记要求，金融机构企业信息新增两个必填字段：

### 金融机构类型
- 格式：级联选择（可搜索）
- 枚举值样式：`一级类型/二级类型（如有）/三级类型（如有）`
- 数据来源：《动产融资统一登记公示系统接口设计说明书V4.0.2》中的担保权人类型
- 悬浮提示："中登登记使用"

### 金融机构编码
- 格式：输入框，文本类型无限制，字段长度50
- 支持通过[[rpa|RPA]]接口自动查询
- 悬浮提示："中登登记使用"

### 字段位置调整

"是否境外"和"外部机构"字段位置调整到"是否归属集团或核心企业"字段前。

## 字段同步

新增字段需同步推送至[[多级流转]]、[[线上保理]]、[[供票系统]]。

## 简易认证规则调整

企业角色=金融机构且认证方式=[[简易认证升级建档|简易认证]]时：
- **法定代表人信息**：除"姓名"必填外，其他信息（影像件+结构化字段）均调整为非必填
- **企业管理员信息**："邮箱"字段调整为非必填
- 模块名称修正："企业管理员信" → "企业管理员信息"

## 内管端展示

内管端客户信息-基本信息tab页同步新增"金融机构类型"和"金融机构编码"字段展示。
