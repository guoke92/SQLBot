# 秦川

## 概述

秦川是产融平台的信审人员，在V1.35版本中被提及于项目上线审批和项目立项统计的权限配置需求中。

## 在V1.35版本中的角色

- **项目上线审批撤回**：信审人员（秦川）页面权限需要进行更新，仅配置页面数据查看按钮，不配置撤回等功能按钮。
- **项目立项统计**：针对秦川等人员，仅配置页面数据查看按钮，其余功能不进行配置。
