# 赢链

赢链是[[产融平台]]的一个贴牌（租户），在V1.18版本中被纳入贴牌迁移适配范围。

## V1.18版本需求

赢链在建档环节存在定制化需求，迁移产融平台需同步处理。状态为**需改造**。

### 改造点

1. **企业信息查询**：对接"Y01建档状态查询"和"Y02批量建档状态查询"接口。其中批量接口不是标准接口。运营中台不涉及建档流程改造。
2. **企业建档申请**（已取消）：原计划对接企业建档申请接口，但该需求已划删除线，不再实施。
