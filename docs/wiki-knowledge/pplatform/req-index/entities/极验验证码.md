# 极验验证码

极验验证码是SSO系统集成的第三方行为验证码服务，为登录、注册等场景提供防机器人攻击的能力。

## 在SSO中的集成

- **调用方**：[[sso-code-provider]] 和 [[login-captcha-ck]]。
- **调用方式**：通过 `ssoLoginProvider.secondValidate(SecondValidateRequest)` 方法调用。
- **请求参数**：`appId`（通常为 `sysChannel`）、`challenge`、`validate`、`seccode`。
- **返回结果**：`SecondValidateResult`，其中 `success` 字段为 `1` 表示校验成功。

## 作用

作为 [[行为验证码校验]] 的具体实现提供者，是整个验证码登录改造的安全基石。其可用性和稳定性直接影响登录功能。
