# 天合光能

天合光能是[[产融平台]]的一个贴牌（租户），在V1.18版本中被纳入贴牌迁移适配范围。天合光能具有**单独建档渠道**，是本版本中定制化程度较高的贴牌之一。

## V1.18版本需求

天合光能在建档环节存在定制化需求，迁移产融平台需同步处理。状态为**需改造**。

### 单独建档渠道

- **建档渠道号**：`operation-wec-reg-trinasolar`
- 供应商无需进行短信和人脸验证
- 建档流程调用贴牌平台接口查询企业认证状态
- 企业授权书在天合光能本地化签署完成后再同步至平台
- 本期运营中台新增天合光能建档渠道
- 建档角色实际业务仅推送供应商信息，系统层面不做限制
- 企业变更走平台通用变更流程
- 定制化需求：建档不做短信和人脸验证，授权书节点展示但无需签署；变更走平台通用流程，授权书正常签署、短信和人脸正常验证

### 单点登录

- 支持从天合光能本地化系统[[单点登录]]至产融平台
- 单点登录走运营中台渠道，本期需保持该功能
- 天合光能渠道需调整 `sourceSysChannel`
