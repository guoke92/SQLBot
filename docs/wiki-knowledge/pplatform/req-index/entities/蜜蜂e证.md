# 蜜蜂E证

蜜蜂E证是一款微信小程序，用于企业在移动端进行建档认证操作。它是[[产融平台]]数据迁移改造中移动端认证流程的关键工具。

## 功能定位

蜜蜂E证在产融平台的认证体系中承担移动端建档的角色。当企业在PC端发起认证时，可以选择通过蜜蜂E证小程序完成建档流程，实现移动端的企业身份验证和信息录入。

## 使用流程

1. 企业在PC端发起认证，点击页面右上角的【企业认证】或企业认证待办；
2. 出现中间页面供选择PC建档或小程序建档；
3. 选择小程序建档后，页面展示蜜蜂E证的二维码；
4. 用户使用微信扫描二维码，打开蜜蜂E证小程序；
5. 用户的手机号码和密码会自动传递至小程序；
6. 用户在小程序中完成建档操作，传给[[运营中台]]的是产融平台的渠道。

## 能力限制

- 目前小程序建档仅支持供应商走自动化流程；
- 如需支持其他类型的企业（如经销商），涉及[[运营中台]]的开发工作；
- 运营中台需新增支持经销商类型。

## 与其他系统的关系

蜜蜂E证作为独立的小程序工具，通过二维码与产融平台PC端集成。其认证数据最终汇入产融平台的企业认证体系，与[[企业认证数据统一]]的目标一致。
