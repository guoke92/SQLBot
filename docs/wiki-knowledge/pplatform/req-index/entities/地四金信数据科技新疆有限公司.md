# 地四金信数据科技（新疆）有限公司

## 基本信息

- 名称：地四金信数据科技（新疆）有限公司
- 类型：贴牌金融机构
- 业务特征：近期将开展业务的贴牌方

## 业务背景

地四金信是产融平台上的一个贴牌金融机构，近期将开展业务。虽然产品备案申请流程较长，但该机构与自营平台达成合作，将在贴牌平台开展自营多级流转业务。因此需要对该贴牌进行产品定制化调整。

## 主要特点

### 贴牌定制化需求

1. **快捷入口初始化**
   - 在客户端"快捷入口"处系统初始化"融易单"产品
   - 名称：融易单
   - 跳转链接：自营平台生产登录页地址（https://xyc.llschain.com/index.html#/login）
   - 图标：自营平台融易单产品logo

2. **快捷入口配置**
   - 系统初始化的"融易单"快捷入口需隐藏操作列的"编辑"和"删除"按钮
   - 手动新增的快捷入口功能正常

3. **适用范围**
   - 适用于该贴牌下历史注册企业及后续新增企业
   - 按照企业角色系统均需初始化"融易单"快捷入口

## 与其他系统的关联

- 该贴牌将使用产融平台的多级流转/融易单产品能力
- 通过快捷入口可跳转至自营平台进行融易单产品操作

## 数据处理

- 存量企业需初始化"融易单"快捷入口（如有）
