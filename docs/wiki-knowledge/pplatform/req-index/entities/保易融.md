# 保易融

## 概述

保易融是产融平台提供的保理类金融产品，无"开通中"状态。

## V1.9版本相关需求

### 租户推送逻辑
- 保易融没有"开通中"状态
- 菜单权限配置页点击确认时同步租户信息给业务系统
- 同步失败应提示，状态依旧为"未开通"
- 详见[[租户推送逻辑调整]]
