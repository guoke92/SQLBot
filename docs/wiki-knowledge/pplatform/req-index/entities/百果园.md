# 百果园

## 基本信息

百果园是一家客户平台，前期通过讯易链侧进行对接。在产融平台V1.34版本中，因客户提出需使用产融平台额度功能，启动从讯易链向产融平台的迁移工作。

## V1.34版本活动

### 平台迁移

百果园的迁移需求由产品经理[[侯叔彤]]负责，主要改造点包括：

**产融平台侧改造：**
- 对接"企业建档申请、查询企业建档&激活状态"接口
- 供应商角色下的跳转逻辑：
  - 建档通过且开通多级流转产品：直接跳转进入多级流转产品
  - 建档中未建档通过：跳转至产融平台首页
  - 无建档数据未建档：拉起建档流程

**运营中台侧改造：**
- 调整客户公众号平台H5登录页目标跳转系统为产融平台

### 存量数据处理

定制化功能完成后进行企业数据迁移。

## 关联

- 迁移来源系统：[[讯易链]]
- 配合系统：运营中台
- 迁移动因：需要使用产融平台额度功能
