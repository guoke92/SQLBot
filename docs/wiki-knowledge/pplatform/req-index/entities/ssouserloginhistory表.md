# sso_user_login_history表

## 概述

sso_user_login_history 是SSO单点登录系统的登录历史表，记录所有登录/登出操作，用于异常行为审计和安全分析。

## 字段定义

| 字段 | 说明 |
|------|------|
| id | 主键 |
| sso_id | 用户ID，关联 [[sso-user]] 表 |
| login_name | 登录名 |
| sys_channel | 业务系统编号 |
| login_ip | 登录IP地址 |
| login_type | 登录类型（登录/登出） |
| operator_result | 操作结果（0-失败，1-成功） |
| remark | 备注信息（详细描述登录结果） |
| create_time | 操作时间 |

## 记录场景

| 场景 | operator_result | remark示例 |
|------|----------------|-----------|
| 登录成功 | 1 | "SSO密码 登陆成功" |
| 登录失败 | 0 | "SSO密码 登陆失败"、"登陆用户不存在"、"密码错误" |
| 账户锁定 | 0 | "账户已被锁定，剩余锁定时间X分钟" |
| 密码过期 | 0 | "密码已过期，需要修改密码" |
| 登出操作 | 1 | "登出成功" |

## 关联关系

- 通过 `sso_id` 关联 [[sso-user]]（用户基本信息表）

## 业务用途

- **异常登录识别**：通过IP地址、时间、设备信息识别异常登录行为
- **安全审计**：所有关键操作均记录审计日志，支持回溯与审计
- **日志查询**：支持按用户、时间、IP、操作结果等条件查询
- **异常行为分析**：支持异常登录行为分析和统计
