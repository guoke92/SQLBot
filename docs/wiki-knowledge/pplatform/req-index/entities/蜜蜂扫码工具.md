# 蜜蜂扫码工具

## 概述

蜜蜂扫码工具是用于扫描授权书二维码以实现归档操作的工具。在产融平台V1.6版本的 [[授权书归档与二维码]] 机制中，运营同事收到客户回寄的线下签署授权书文件后，使用蜜蜂扫码工具扫描文件上的二维码即可完成归档操作。

## 与蜜蜂E证的关系

蜜蜂扫码工具与 [[蜜蜂e证]] 同属蜜蜂系列产品线。蜜蜂E证主要用于电子签章相关场景，而蜜蜂扫码工具专注于二维码扫描归档场景。

## 使用场景

- 线下签署的授权书回寄后，运营同事使用蜜蜂扫码工具扫描授权书上的二维码完成归档
- 该工具是授权书归档流程中线下环节的关键操作工具
