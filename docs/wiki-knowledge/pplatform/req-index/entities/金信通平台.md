# 金信通平台

## 概述

金信通平台是[[entities/地四金信数据科技新疆有限公司]]运营的贴牌平台，与产融平台存在合作关系。在产融平台V1.28版本中，金信通平台有H5端定制需求（参见 [[concepts/金信通H5端跳转链接]]）。

## 业务背景

地四金信贴牌近期将开展业务，考虑到产品备案申请流程较长，与自营平台达成合作，在贴牌平台开展自营多级流转业务。前期已对PC端做了产品定制化调整，V1.28版本同步对移动端（H5）进行优化。

## 平台特征

- **运营方**：[[entities/地四金信数据科技新疆有限公司]]
- **平台类型**：贴牌平台
- **移动端**：H5端
- **业务类型**：自营多级流转业务（使用[[entities/融易单]]产品）
- **PC端**：已有产品定制化调整

## 与产融平台的关系

金信通平台作为贴牌平台，通过产融平台进行企业建档、产品开通等操作。V1.28版本为其移动端增加了跳转至自营平台H5登录页的链接。
