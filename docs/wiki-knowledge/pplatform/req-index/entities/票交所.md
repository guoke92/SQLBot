# 票交所

票交所是供票产品的监管方，其备案要求是供票产品开通校验规则的来源。

## 在产融平台中的角色

票交所要求供票产品旗下客户进行信息备案，且要求提供完整企业信息。这一监管要求直接驱动了[[供票产品开通校验规则]]的三项核心校验：

1. 企业认证方式不能为简易认证（需完整企业信息）
2. 必须已开通电子签章
3. 必须为总公司

## 与供票系统的关系

[[供票系统]]是产融平台对接的业务系统，而票交所是供票业务的外部监管机构。供票产品的开通条件本质上由票交所的备案要求决定。
