# 中交疏浚

中交疏浚是产融平台的核心企业（KA）客户，在V1.29版本中提出了KA标准化接口支持变更场景的需求。

## 角色与需求

- **客户类型**：核心企业（KA）
- **需求产品经理**：[[周水平]]
- **核心需求**：[[ka标准化接口支持变更|KA标准化接口支持变更]]——为中交疏浚已有的KA标准化数据接口增加企业信息变更场景支持

## 与其他KA客户的关系

中交疏浚与[[中铁四局]]同为产融平台KA标准化接口对接的重点客户，二者需求均在V1.29版本中列为【高】优先级。
