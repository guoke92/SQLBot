# 余安安

余安安是[[saas方案部|SaaS方案部]]的负责人。

## 在产融平台中的角色

在[[项目立项统计]]功能中，余安安作为"方案经理"取值逻辑的审批人之一。具体规则为：当立项审批数据从"企微审批"获取且项目类型为"主项目"时，取值SaaS方案部负责人（余安安）与SaaS产品中心负责人（[[江彦颖]]）中最后一个审核通过的人员作为方案经理。
