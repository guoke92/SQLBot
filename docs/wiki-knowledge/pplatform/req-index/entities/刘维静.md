# 刘维静

刘维静是[[产融平台]]的产品经理，参与V1.14和V1.15版本的部分需求设计。

## 职责范围

在产融平台V1.14&V1.15版本需求文档中，刘维静负责以下2项需求：

- **分公司建档时授权书内取总公司的名称**（第10章）：优化授权书取值逻辑，分公司建档时使用总公司名称和签章
- **增加融易单的项目时支持跳转新的配置页面**（第13章）：在产融平台新增"项目配置pro"入口

## 协作关系

与另一位产品经理[[侯叔彤]]共同负责产融平台产品工作。侯叔彤在该版本中负责其余15项需求。
