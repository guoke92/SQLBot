# 周水平

周水平是产融平台的产品经理，负责KA标准化接口相关需求。

## 职责

在V1.29版本中，周水平负责以下需求：

- **中交疏浚：KA标准化接口支持变更场景**（第4章，【高】优先级）
- **中铁四局：标准化接口对接**（第5章，【高】优先级）

两个需求均聚焦于核心企业（KA）的标准化数据接口对接与增强。
