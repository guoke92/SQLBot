# 投行产品

## 概述

投行产品是产融平台提供的投资银行类产品，无"开通中"状态，开通后即为已开通。

## V1.9版本相关需求

### 租户推送逻辑
- 投行产品没有"开通中"状态
- 菜单权限配置页点击确认时同步租户信息给业务系统
- 同步失败应提示，状态依旧为"未开通"
- 详见[[租户推送逻辑调整]]

### 电子签章处理
- 开通投行产品时不再强制开通电子签章
- 后续办理业务时若需在线签署，联系运营人员开通
- 开通电子签章时需阅读[[cfca]]和上上签协议
- 详见[[投行产品电子签章处理]]
