# 客户营销部

客户营销部是产融平台的数据来源部门，在V1.30版本中：

- **项目立项统计**（需求7）：新增模拟立项功能中，业务经理字段为下拉单选，获取"客户营销"一级部门下所有人员进行选择
- 数据获取方式：通过Knife4j接口文档中的企微对接平台服务接口（getDepartmentInfoUsingPOST、getDepMemDetailUsingPOST）获取部门信息和成员详情
