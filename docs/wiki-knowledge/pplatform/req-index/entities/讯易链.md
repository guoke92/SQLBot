# 讯易链

## 概述

讯易链是[[chanrong-platform|产融平台]]的前身系统，最初以项目制方式建设。在产融平台生态中，它作为关联系统，在存量贴牌业务场景中承担数据来源的角色。

## 与产融平台的关系

产融平台的建设目标之一是改善讯易链以项目制需求建设的方式，通过逐步拆解提炼通用模块，实现存量产品改善。这意味着：

- 讯易链的建设模式是**按项目需求驱动**，每个项目可能独立开发功能
- 产融平台的建设模式是**平台化、模块化**，提炼通用能力复用

同时，在产融平台中，讯易链是存量贴牌企业已开单数据的存储方，通过接口向产融平台推送已占用的额度数据。

## 升级方向

从讯易链到产融平台的升级，体现了以下战略转变：

1. 从项目制到平台化：建设通用底座，提炼通用模块
2. 从单一产品到多产品集成：集成现有SaaS产品，支持持续上架新如[[ams|AMS]]、多级流转、线上保理等产品
3. 从项目营销到平台营销：提升一个客户多产品业务落地效率

## 在产融平台中的具体角色

在[[存量贴牌数据处理]]需求中，产融平台在额度生效时调用讯易链接口获取数据。这体现了讯易链在额度管理中的关键作用。

## 相关需求

- 产融平台V1.22版本需求13：存量贴牌未有过额度管控但是已开单的数据处理
- 产融平台V1.21版本需求中也有涉及讯易链的相关需求
