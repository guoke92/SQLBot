# sso_user_pwd_history表

## 概述

sso_user_pwd_history 是SSO单点登录系统的密码历史表，独立存储用户密码历史记录，用于防止用户重复使用近期密码。

## 字段定义

| 字段 | 说明 |
|------|------|
| id | 主键 |
| sso_id | 外键，关联 [[sso-user]] 表的 sso_id |
| password | 历史密码哈希值（BCrypt） |
| sys_channel | 业务系统编号 |
| create_time | 记录创建时间 |

## 关联关系

- 通过 `sso_id` 关联 [[sso-user]]（用户基本信息表）

## 安全设计

该表是 [[用户信息与身份鉴别信息分离存储]] 策略的核心组成部分：

- **物理分离**：与用户基本信息表独立存储，降低数据泄露风险
- **逻辑分离**：密码历史通过独立的Service进行管理，与用户基本信息管理分离
- **访问权限分离**：可配置更严格的访问权限

## 业务用途

当用户修改密码时，系统将旧密码保存到该表中，用于：
- 防止用户重复使用近期密码
- 密码变更历史追溯和审计
- 配合 [[密码过期策略]] 实现完整的密码生命周期管理
