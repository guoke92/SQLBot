# 宏胜云链

宏胜云链是[[产融平台]]的一个贴牌（租户），在V1.18版本中被纳入贴牌迁移适配范围。

## V1.18版本需求

宏胜云链在建档环节存在定制化需求，迁移产融平台需同步处理。状态为**不做升级**。

### 对接接口

- **白名单查询接口**：供应商建档时调用该接口查询供应商白名单。
- **供应商加入商圈信息保存接口**：企业激活后调用该接口回传激活数据。

### 改造点

1. **运营中台**：调整为与产融平台对接，不涉及运营中台建档流程改造。
2. **产融平台**：该贴牌下供应商建档时调用白名单查询接口查询，企业激活后调用供应商加入商圈信息保存接口同步企业数据。
