# SSOResultCodeEnum

## 概述

SSOResultCodeEnum 是SSO单点登录系统的错误码枚举类，定义了系统操作返回的所有错误码和成功码，是错误处理的基础组件。

## 关键错误码

### 登录与会话相关

| 错误码 | 含义 | 使用场景 |
|--------|------|---------|
| 10900 | 未登录/会话已过期 | [[分布式会话管理与超时机制]]中会话失效时返回 |

### 密码强度相关

| 错误码 | 含义 | 使用场景 |
|--------|------|---------|
| 10918 | 密码强度不符合要求（等级2） | [[passwordutils]]验证等级2失败时返回 |
| 10919 | 密码强度不符合要求（等级3） | [[passwordutils]]验证等级3失败时返回 |
| 10927 | 密码强度不符合要求（等级4） | [[passwordutils]]验证等级4失败时返回 |

### 账户状态相关

| 错误码 | 含义 | 使用场景 |
|--------|------|---------|
| 20903 | 账户已被锁定 | [[登录失败计数与账户锁定]]中锁定期间登录时返回 |
| 20904 | 密码即将过期，提醒用户修改 | [[密码过期策略]]中密码即将过期时返回 |
| 30903 | 密码已过期，请修改密码 | [[密码过期策略]]中密码已过期时返回 |

## 使用方式

错误码通过 [[sso-result-dto]] 包装后返回给调用方，格式为 `new SSOResultDTO<>(SSOResultCodeEnum.ERROR_CODE_XXXXX)`。

## 相关实体

- [[sso-result-dto]]：统一返回数据结构
- [[passwordutils]]：密码强度验证工具类
