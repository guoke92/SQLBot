# 深天马

深天马是[[产融平台]]的一个贴牌（租户），在V1.18版本中被纳入贴牌迁移适配范围。

## V1.18版本需求

深天马在建档环节存在定制化需求，迁移产融平台需同步处理。状态为**需改造**。

### 改造点

1. **门户定制**：此前贴牌背景图、登录页由代码配置，迁移产融平台由租户配置实现，无定制化需求，暂不涉及改造。生产地址：`https://tianma.xyc.llschain.com`。
2. **天马管理平台对接-供应商建档接口开发**：对接"企业建档申请、企业建档状态通知"接口。运营中台不涉及建档流程改造。
