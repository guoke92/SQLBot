# 壹建融

壹建融是产融平台的贴牌客户，近期将开展SaaS业务，涉及在产融平台新增贴牌及部分定制化开发。

## 角色与需求

- **客户类型**：贴牌
- **需求来源**：壹建融SaaS业务上线
- **定制化内容**：
  - 贴牌平台名称：壹建融
  - 登录页左下角增加客户相关平台介绍链接（建发集团、建发股份、企业邮箱、企业VPN）
  - 点击介绍信息新开窗口打开对应地址

## 定制化详情

登录页参考地址：`https://cnd.onescf.com/#/login`

## 平台演进中的定位

壹建融的需求延续了产融平台[[贴牌建档流程定制化|贴牌定制化]]的传统模式，进一步凸显了[[产融平台]]在标准化统一目标与高度定制化需求之间的持续张力。
