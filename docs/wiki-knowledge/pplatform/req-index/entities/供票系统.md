# 供票系统

供票系统是供应链票据业务系统，拟在V1.7版本中接入[[产融平台]]门户。该系统无存量业务数据，因此不需要考虑历史数据迁移。

## 业务模式

供票系统开展供票业务需要资质，公司本身没有资质，但与第三方平台签署了合作协议。业务流程为：有业务进件后，供票系统将业务申请推送给第三方平台，该平台再推送给票交所。

## 支持的角色

供票系统支持两种企业角色：
- **核心企业**
- **供应商**

支持的角色组合仅为"核心企业+供应商"。

## 与产融平台的集成

供票系统在V1.7版本中通过[[供票系统集成]]需求全面接入产融平台，涉及以下方面：

- **客户端**：统一登录、通用建档、产品开通、产品切换、待办接入、消息通知接入、经办人管理、角色权限配置
- **内管端**：产品大类新增"供应链票据"、租户信息推送、企业信息推送、用户信息变更通知

## 待确认事项

- 固定项目的多租户问题处理方式
- 无项目模式的特殊处理方案
- 审批流是否迁移至产融配置
- 供票系统的协议类型确认

## 特殊约束

供票系统侧没有"项目"的概念，暂时先默认使用一个固定的项目，但存在多租户问题需要解决。
