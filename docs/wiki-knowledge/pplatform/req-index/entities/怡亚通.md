# 怡亚通

怡亚通是[[产融平台]]的一个贴牌（租户），在V1.18版本中被纳入贴牌迁移适配范围。

## V1.18版本需求

怡亚通在建档环节存在定制化需求，迁移产融平台需同步处理。状态为**需改造**。

### 改造点

1. **门户定制**：此前贴牌背景图、登录页由代码配置，迁移产融平台由租户配置实现，无定制化需求，暂不涉及改造。生产地址：`https://eascs.xyc.llschain.com`。
2. **建档接口对接**：对接多级流转标准接口中的企业建档接口，推送企业数据。
3. **供应商非自主建档功能**：供应商建档选择"邀请认证-平台录入"，内管端提交建档申请时，产融平台提交建档申请至运营中台。运营中台调整怡亚通贴牌审核及客户信息确认流程为通用流程。
4. **供应商非自主建档功能优化**：走产融平台现有建档逻辑。
