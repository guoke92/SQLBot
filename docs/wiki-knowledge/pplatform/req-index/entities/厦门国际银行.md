# 厦门国际银行

## 概述

[[厦门国际银行]]是产融平台的一个重要租户，具有特定建档规则的客户。其在建档环节存在定制化需求，迁移产融平台时需保留相关逻辑。

## 在产融平台中的角色

厦门国际银行在产融平台迁移中扮演核心角色，其需求主要体现在：

1. **建档定制化**：厦门国际银行在建档环节存在定制化需求，包括非自主建档时供应商收款账户信息改为非必填、增加开关控制是否启用新建档流程。
2. **门户定制化**：厦门国际银行门户页、登录页未通过租户配置实现，通过定制开发实现。

## 定制化需求

### 非自主建档，供应商收款账户信息改为非必填

产融平台新增企业信息，"企业角色=供应商，认证方式=邀请认证-平台录入，租户=厦门国际银行"时，"③账户信息"调整为非必填，同时取消现有必填校验。

### 增加开关控制是否启用新建档流程

实际业务中目前厦门国际银行贴牌均走新建档流程，与产融平台建档新流程一致。待讯易链评估，若不影响业务流程，迁移产融时去掉该开关。

### 门户&登录页定制化

门户页、登录页：定制开发，按照当前门户页样式及内容实现。标注为"【不做】"，原因未明确说明（可能是不迁移或暂不处理）。
