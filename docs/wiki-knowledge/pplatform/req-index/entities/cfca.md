# CFCA

CFCA（中国金融认证中心）在[[产融平台]]语境中指代与其相关的电子签名/认证协议类型，同时也是为产融平台提供证书、签章和二要素校验等安全认证服务的系统/服务。

## 在产融平台中的角色

- **证书服务**：为企业开户提供CFCA证书开通，支持不同类型证书的共用（SaaS证书一证四步），按租户或企业进行隔离。
- **二要素校验**：在企业开户确认时进行人员身份校验，支持两类接口：
  - 带身份证的二要素接口（默认）
  - 仅姓名加身份证号的被授权人二要素接口（可按租户配置）
- **签章服务**：在[[线下授权书自动生成电子版]]场景中，用于对电子版授权书进行证书签章。

## 在企业协议迁移中的角色

CFCA协议是[[企业协议迁移]]中需要同步至产融的五类企业协议之一（授权书、隐私协议、产品服务协议、用户注册协议、CFCA协议）。

## 协议来源

- CFCA协议不在影像树上，需确认在业务系统中的确切存储位置和查询方式（V1.7文档中标记为待确认）
- [[线上保理]]会在登录后再阅读1次CFCA协议，一个企业只会阅读一次

## V1.33版本相关变更

V1.33版本对CFCA相关功能进行了[[cfca优化]]，包括升级提示语调整、校验失败原因细化展示，以及新增二要素接口配置能力。[[湖北联投]]系列租户为首批配置新接口的对象。

## 待确认事项

文档中明确标注：***CFCA、隐私协议等不在影像树上的协议需确认在业务系统的什么地方可查询到。***
