# 陈秋芸(邓紫棋)

陈秋芸（别名邓紫棋）是[[产融平台]]的产品经理。

## 主要职责

在V1.16版本中，她负责**经办人实名认证调整**需求（需求目录第3项）。该需求将经办人实名认证从强制必填改为非必填，旨在优化用户体验，解决[[订单融资]]和[[线上保理]]等业务系统在特定流程中的操作障碍。
