# 联链通

联链通是[[湖北联投]]系列贴牌之一，属于[[产融平台]]的贴牌（租户）。

## V1.18版本需求

联链通存在定制化"门户首页"登录跳转功能需求。

### 门户首页定制

- 湖北联投本地化系统单点登录至联链通贴牌后，导航栏右上角展示"门户首页"按钮。
- "门户首页"按钮固定在导航栏展示。
- 点击后新开浏览器页签，带登录态跳转联链通本地化客户端首页。
- 固定地址：`https://llt.hbsltzb.com`（生产环境）。
