# 微盘

微盘是[[企业微信]]平台提供的云端文件存储与管理功能，支持用户通过企业微信客户端进行文件的上传、查看和下载。

## 在产融平台中的应用

V1.33版本中，【[[项目上线审批流程]]】模块的H5页面增加了"从微盘选择"的文件上传入口。当用户在手机端H5页面上传附件时，可以通过该入口调用微盘API获取当前用户的微盘文件列表，选择文件上传至审批流程中，无需先将文件下载到本地。

## 技术接口

V1.33版本使用的微盘参考接口文档为：[获取文件列表 - 文档 - 企业微信开发者中心](https://developer.work.weixin.qq.com/document/path/93657)

## 注意事项

- 微盘选择功能仅在H5页面生效，PC端上传附件沿用原有方式
- 需要企业微信用户授权访问其微盘数据
