# 渠道映射不是企业配置

cust_config_mapping 是渠道级映射，cust_setting_config 是企业级配置，两者不可混查。

```ground:rule
rule: mapping-not-customer-setting
field_targets:
- cust_config_mapping.outer_channel
- cust_setting_config.cust_id
impact: query_constraint
content: cust_config_mapping 是渠道级映射，cust_setting_config 是企业级配置，两者不可混查。
scope: 渠道配置、企业配置
```
