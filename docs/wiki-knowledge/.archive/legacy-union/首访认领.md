# 首访认领

无行则 INSERT（respondent=String(companyId)，first_visitor_lottery_shown=N，enable=Y）； 有行且 first_visitor_user_id IS NULL 则 guarded UPDATE 认领。并发安全靠 DuplicateKeyException 回读 + isNull 条件双保险。

```ground:process
process: 首访认领
stages:
- stage: 首访认领
  trigger: 首页展示配置 / gotoProduct 跳转决策（隐式写）
  effects:
  - op: insert
    table: cust_company_survey_state
    fields:
    - company_id
    - respondent
    - first_visitor_user_id
    - first_visit_time
    - first_visitor_lottery_shown
    - enable
  - op: update
    table: cust_company_survey_state
    fields:
    - first_visitor_user_id
    - first_visit_time
  transitions: []
```
