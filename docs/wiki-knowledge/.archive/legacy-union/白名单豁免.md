# 白名单豁免

批量加白名单：写项目 special_company_list（WHITELIST, annualFee=0）→ 企业快照 special_config_flag=Y / special_annual_fee=0 → 关闭 PENDING 单 → 生成 0 元 PAID 单 （service_end=2099-01-01）→ 企业 pay_status=PAID。

```ground:process
process: 白名单豁免
stages:
- stage: 白名单豁免
  trigger: 管理端批量加白名单
  effects:
  - op: update
    table: ca_fee_project_config
    fields:
    - special_company_list
  - op: update
    table: ca_fee_company
    fields:
    - special_config_flag
    - special_annual_fee
    - pay_status
  - op: insert
    table: ca_fee_order
    fields:
    - order_status
    - pay_amount
    - service_end
  transitions: []
```
