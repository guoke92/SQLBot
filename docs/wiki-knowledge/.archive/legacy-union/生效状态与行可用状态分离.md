# 生效状态与行可用状态分离

status=Y 才表示已生效；enable 只表示配置行启用，不能用 enable 单独代替生效判断。

```ground:rule
rule: status-separate-from-enable
field_targets:
- tenant_setting_config.status
- tenant_setting_config.enable
impact: query_constraint
content: status=Y 才表示已生效；enable 只表示配置行启用，不能用 enable 单独代替生效判断。
scope: 已生效/待生效配置统计
```
