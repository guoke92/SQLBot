# 答题粒度规则

cust_survey_answer 一行=一道题的一个选项（多选每选项一行，buildRecords 双层 for 展开）。 "答题企业数/答卷数"必须 COUNT(DISTINCT company_id)；按行 COUNT 会因多选题膨胀； "某题选某项的企业数"也要 DISTINCT（同企业同题不同选项会重复计企业）。
