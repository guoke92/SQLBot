# 变更单

一行一次变更审核过程，通过 cust_id 连接企业主键，不能直接当企业数。

## 取值
- `CUST_CHECK_INIT` = 待审核
- `CUST_CHECK_CHECKING` = 审核中
- `CUST_CHECK_PASS` = 审核通过
- `CUST_CHECK_REJECT` = 审核不通过
- `CUST_CHECK_BACKTOCUSTOM` = 待客户确认
