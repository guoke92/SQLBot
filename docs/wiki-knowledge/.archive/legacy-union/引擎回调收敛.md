# 引擎回调收敛

引擎通知驱动节点状态与主表状态：流程结束 pass→wf_status=FINISHED（写 complete_time、 项目置生效、按条件推 AMS）；reject/back→TERMINATED。中间节点 pass 保持 RUNNING、 back 节点回 PENDING。

```ground:process
process: 引擎回调收敛
stages:
- stage: 引擎回调收敛
  trigger: 工作流引擎异步回调（ProjectOnlineProcessOperateListener）
  effects:
  - op: update
    table: tenant_project_approval_flow
    fields:
    - node_status
  - op: update
    table: tenant_project_approval
    fields:
    - wf_status
    - complete_time
    - wf_last_operator
    - wf_last_operate_time
  transitions: []
```
