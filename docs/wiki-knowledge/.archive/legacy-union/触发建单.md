# 触发建单

CA 认证成功/建档审批通过/关联项目/手动/存量扫描/续费任务触发：规则引擎判定需缴费 且年费>0 时建 PENDING 订单 + 确保企业台账行 UNPAID，并发缴费待办。 分布式锁 cafee:order:{certNo}:{projectId}:{orderType} 幂等，同键 PENDING 复用。

```ground:process
process: 触发建单
stages:
- stage: 触发建单
  trigger: CA_AUTH_SUCCESS / BUILD_APPROVED / PROJECT_RELATE / MANUAL / 存量扫描 / 续费任务
  effects:
  - op: insert
    table: ca_fee_order
    fields:
    - order_no
    - company_id
    - certification_no
    - project_id
    - order_type
    - order_status
    - annual_fee
    - pay_method
    - agreement_signed
  - op: upsert
    table: ca_fee_company
    fields:
    - certification_no
    - pay_status
    - fee_locked
  transitions: []
```
