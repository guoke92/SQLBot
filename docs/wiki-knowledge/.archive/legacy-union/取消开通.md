# 取消开通

前置 checkOnTheWay：生效项目谓词（tenant_project.project_status='1' AND enable='Y' AND product_id=本产品 id）或企业开通谓词（cust_auth_application.ref_cust_auth_application_tenant_product=tenant_product.code AND enable='Y'）存在则拒绝取消。通过则 open_status=N + product_ref_num 减量重算（并发不精确）。

```ground:process
process: 取消开通
stages:
- stage: 取消开通
  trigger: 管理端 /tenantProduct/cmd/cancel
  effects:
  - op: update
    table: tenant_product
    fields:
    - open_status
  - op: update
    table: platform_product
    fields:
    - product_ref_num
  transitions: []
```
