# 提交讯易链答题

(company_id, survey_code) 幂等，一对多展开为多行（题×选项）批量 INSERT。 survey_code 服务端强制取 Nacos 配置（默认 XYL_2024_Q1），入参被忽略。

```ground:process
process: 提交讯易链答题
stages:
- stage: 提交讯易链答题
  trigger: 企业端 POST /cust-web/survey/submit
  effects:
  - op: insert
    table: cust_survey_answer
    fields:
    - survey_code
    - company_id
    - user_id
    - question_no
    - answer_value
    - other_text
    - submit_time
  transitions: []
```
