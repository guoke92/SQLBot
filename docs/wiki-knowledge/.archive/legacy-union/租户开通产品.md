# 租户开通产品

幂等（同 tenantId+platformProductCode 已存在直接返回）；新建从 platform_product 拷贝 12 属性字段（name/productCate/productSummary/productDescription/customerGroup/maxFinancingPeriod/maxFinancingAmount/creditMeasures/maxFinancingAmountFlag 等）+ ref 锚（ref_tenant_product_project_code=platform_product.code、ref_tenant_product_tenant_setting_config=tenant.code）。activate 置 open_status=Y 且 platform_product.product_ref_num 全量重算（increment）。ACFLOW/ORDER 特殊：activate 后置 P 等外部多级回调置 Y。

```ground:process
process: 租户开通产品
stages:
- stage: 租户开通产品
  trigger: 管理端 /tenantProduct/cmd/create → active
  effects:
  - op: insert
    table: tenant_product
    fields:
    - tenant_id
    - platform_product_id
    - platform_product_code
    - name
    - ref_tenant_product_project_code
    - ref_tenant_product_tenant_setting_config
    - open_status
  - op: update
    table: platform_product
    fields:
    - product_ref_num
  transitions: []
```
