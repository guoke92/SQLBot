# 创建企业建档



```ground:process
process: 创建企业建档
stages:
- stage: 创建企业建档
  trigger: 平台录入、客户录入或批量导入 createCustCompany
  effects:
  - op: insert
    table: cust_company_info
    fields:
    - id
    - code
    - name
    - certification_no
    - cust_build_status
    - cust_status
    - data_type
    - cust_build_type
    - enable
  - op: insert
    table: cust_person_info
    fields:
    - id
    - code
    - name
    - certification_no
    - ref_cust_company_info
    - cust_company_id
    - user_type
    - enable
  - op: insert
    table: cust_project_rel
    fields:
    - id
    - code
    - project_id
    - product_id
    - ref_cust_project_rel_cust_company_info
    - company_type
    - status
    - enable
  - op: insert
    table: cust_role_info
    fields:
    - id
    - code
    - role_type
    - ref_cust_company_info
    - enable
  transitions: []
```
