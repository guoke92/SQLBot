# 一证四步（门户）

pre4Step（预检：查询证书状态+企业名比对，失效/名称不匹配时 ca_register_status 置 N；变更流程中则阻断）→ realName/verify（实名核验按 verifyMethod 分键：ENTERPRISE_THREE/FOUR→enterprise_four_json、POLICE_TWO→police_two_json）→ intent/sms|face（意愿；人脸通过时回填 intent_h5_face_json）→ protocol/confirm（聚合提交 submitToSignCenter（先总后分）→ openCa（ca_register_status=Y）→ 广播 openCA → 触发 CA 计费）。CHANNEL_OPENAPI 源豁免意愿步骤。confirm 无事务（长 IO 刻意事务外），多次点击安全。
