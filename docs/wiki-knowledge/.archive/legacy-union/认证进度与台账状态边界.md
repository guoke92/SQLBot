# 认证进度与台账状态边界

cust_build_status 回答认证流程进度，cust_status 回答客户台账可用性。终态联动： 审核通过时 BUILD_SUCCESS 与 EFFECT 成对写；但 EFFECT 企业发起变更进入 CHANGE+CUST_CHANGE 双写，注销后仍保留 BUILD_SUCCESS。
