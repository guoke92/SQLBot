# 重新发起（多轮）

拒绝后复制新单：原单 is_latest=N（状态保持 TERMINATED 不改写），新单新编号、 wf_status=PENDING、is_latest=Y、ref 指向原单 code；business_info/flow/五类影像一并复制。 同项目存在 PENDING/RUNNING 审批时禁止再发起。

```ground:process
process: 重新发起（多轮）
stages:
- stage: 重新发起（多轮）
  trigger: 企业端重新发起 / 复制新草稿
  effects:
  - op: update
    table: tenant_project_approval
    fields:
    - is_latest
  - op: insert
    table: tenant_project_approval
    fields:
    - approval_no
    - wf_status
    - is_latest
    - ref_tenant_project_approval_tenant_project_approval
  transitions: []
```
