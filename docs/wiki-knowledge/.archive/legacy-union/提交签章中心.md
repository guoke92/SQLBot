# 提交签章中心

submitToSignCenter：完整性校验（协议+≥1实名+≥1意愿+附件，CHANNEL_OPENAPI 豁免意愿）→ assembleBizRequest 组装（子项 data 超长按叶子属性剔除）→ cbsSubmitBizData（事务外）→ SUCCESS 判定 DBaaS code∈{'0','200'} AND biz.status=SAVED → 回写 submit_status+sign_platform_result（请求+响应全文不截断）+submit_time。已 SUCCESS 短路；异常也写 FAIL。
