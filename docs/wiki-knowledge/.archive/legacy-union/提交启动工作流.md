# 提交启动工作流

两段式：事务内重建流程节点（先删后增，node_order 重排 1..n、node_status=PENDING） 并重置 wf_status=PENDING；事务外调引擎启动，成功则 initiate_time/wf_status=RUNNING/ act_procinst_id，失败降级保持 PENDING。首次正式提交回写 tenant_project.wechat_audit_no。

```ground:process
process: 提交启动工作流
stages:
- stage: 提交启动工作流
  trigger: 企业端提交（isDraft 区分暂存/正式）
  effects:
  - op: insert
    table: tenant_project_approval_flow
    fields:
    - node_code
    - node_name
    - node_order
    - node_status
    - approver_user_id
  - op: update
    table: tenant_project_approval
    fields:
    - wf_status
    - initiate_time
    - act_procinst_id
    - wf_procdef_key
  - op: update
    table: tenant_project
    fields:
    - wechat_audit_no
  transitions: []
```
