# 项目资金方企业

先找企业所在的启用项目关系，再找同项目 company_type='FINANCE' 的启用关系，并对资金方企业套用 BUILD_SUCCESS/EFFECT/data_type='1'/enable='Y'。

```ground:caliber
caliber: 项目资金方企业
field_targets: []
filters:
- .project_rel.enable = 'Y'
- .project_rel.company_type = 'FINANCE'
- .company.cust_build_status = 'BUILD_SUCCESS'
- .company.cust_status = 'EFFECT'
- .company.data_type = '1'
- .company.enable = 'Y'
```
