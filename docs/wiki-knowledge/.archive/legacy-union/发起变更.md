# 发起变更

平台变更或企业自行变更：Redis 锁 + 在途互斥校验后 ChangeRecordService.init/update 落变更单；企业侧同步写 cust_status=CHANGE、cust_build_status=CUST_CHANGE、 check_status=CUST_CHECK_INIT。

```ground:process
process: 发起变更
stages:
- stage: 发起变更
  trigger: 管理端 /change/submit 或企业自行变更推送
  effects:
  - op: insert
    table: cust_change_record
    fields:
    - cust_id
    - oper_cust_id
    - status
    - alter_type
    - alter_mode
    - msg_send
  transitions: []
```
