# 企微同步

企微小时级同步：增量拉取（已存在且 act_procinst_status≠'1' 的 spNo 跳过）→ saveApprovalData 落库（首填不覆盖：立项名称/主项目名称/项目类型/产品类型/方案经理/业务经理/业务中心/项目阶段/发起立项时间/资方与企业等 DB 已有值不写）→ project_phase 按 sp_status 映射初值。dataSource='WECHAT'。

```ground:process
process: 企微同步
stages:
- stage: 企微同步
  trigger: XXL-Job syncWechatApprovalTask
  effects:
  - op: upsert
    table: wechat_project_approval_apply
    fields:
    - sp_no
    - sp_type
    - project_approval_name
    - act_procinst_status
    - sp_pass_time
    - bussiness_manager
    - op_contact
    - solution_manager
    - data_source
  transitions: []
```
