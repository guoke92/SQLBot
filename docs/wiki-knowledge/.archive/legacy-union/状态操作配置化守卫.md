# 状态操作配置化守卫

cust_status 变更走 custStatusOperator：每类操作（ENABLE/FREEZE/UNFREEZE/DISABLE） 配置允许的前置状态列表（allowStatusList）与是否需查在途业务；不满足抛"当前操作不允许"。 例如仅 EFFECT/ADD 可冻结、FREEZE 可解冻、注销需查在途。
