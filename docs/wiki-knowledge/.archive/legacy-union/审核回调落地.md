# 审核回调落地

运营中台工作流回调：通过时 cust_status=EFFECT、check_status=CUST_CHECK_PASS、 cust_build_status=BUILD_SUCCESS 三值成对写；拒绝时 BUILD_FAIL。 变更安全拒绝采用乐观条件更新（eq(custStatus,CHANGE)+在途单存在）防旧回调覆盖。

```ground:process
process: 审核回调落地
stages:
- stage: 审核回调落地
  trigger: 运营中台工作流回调（CustSyncEventProcessor）
  effects:
  - op: update
    table: cust_company_info
    fields:
    - cust_status
    - check_status
    - cust_build_status
  - op: update
    table: cust_person_info
    fields:
    - cust_build_status
  transitions: []
```
