# 缴费闭环

交e保划扣成功（锁 cafee:pay:{orderNo} + CAS 占位 bocom_txn_sts='02'）→ 订单 PENDING→PAID（pay_amount/pay_time/service_start/service_end）→ 同步企业台账 pay_status=PAID + 首缴锁价 → 完结待办 → 异步开票（invoice_status=PENDING）。

```ground:process
process: 缴费闭环
stages:
- stage: 缴费闭环
  trigger: 企业端缴费确认 / 查证补单 / 台账人工标记已缴 / 0元豁免建单
  effects:
  - op: update
    table: ca_fee_order
    fields:
    - order_status
    - pay_amount
    - pay_time
    - service_start
    - service_end
    - invoice_status
  - op: update
    table: ca_fee_company
    fields:
    - pay_status
    - service_start
    - service_end
    - fee_locked
    - locked_annual_fee
  transitions: []
```
