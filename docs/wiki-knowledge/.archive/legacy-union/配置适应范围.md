# 配置适应范围

saveOrUpdateScope：先删 tenant_interworking_project 该产品全部行（先清）；scope=ALL 直接返回（不插任何行=全部项目可见）；scope=SOME 解析 scopeProject JSON 数组逐项目插行（name=产品名-项目名、ref 双锚）。

```ground:process
process: 配置适应范围
stages:
- stage: 配置适应范围
  trigger: 管理端 /tenantInterworkingProduct/cmd/saveOrUpdateScope
  effects:
  - op: upsert
    table: tenant_interworking_project
    fields:
    - name
    - product_id
    - project_id
    - platform_product_code
  transitions: []
```
