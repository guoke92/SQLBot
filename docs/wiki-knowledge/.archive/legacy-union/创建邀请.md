# 创建邀请

单条/批量邀请：invite_time=now、progress=INIT、invite_from=平台邀请(AGW端)/邀请企业名、invite_cust_id=邀请方；级联创建被邀请企业（identify_style=INVITE，AGW_BUILD 时 INVITE_AGW；need_register_ca=Y）+ 角色 + 管理员 + channelCode 匹配租户项目则建 cust_project_rel，最后 submitCust 推审核。后续经回调派生 progress←cust_build_status。

```ground:process
process: 创建邀请
stages:
- stage: 创建邀请
  trigger: 管理端 /invite/save 或 /invite/batch
  effects:
  - op: insert
    table: cust_invite_info
    fields:
    - invite_time
    - invite_from
    - progress
    - invite_cust_id
  transitions: []
```
