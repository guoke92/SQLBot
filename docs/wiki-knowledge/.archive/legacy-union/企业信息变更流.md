# 企业信息变更流

发起变更时主数据行复制为流程行（data_type=0/2、main_data_id 指向主行）， cust_status=CHANGE、cust_build_status=CUST_CHANGE；变更拒绝后乐观恢复 EFFECT/BUILD_SUCCESS；归档时流程行字段拷回主行（apply_data_id 回指）。

```ground:process
process: 企业信息变更流
stages:
- stage: 企业信息变更流
  trigger: 企业端发起信息变更
  effects:
  - op: insert
    table: cust_company_info
    fields:
    - main_data_id
    - data_type
    - apply_type
    - cust_build_status
  - op: update
    table: cust_company_info
    fields:
    - cust_status
    - cust_build_status
  transitions: []
```
