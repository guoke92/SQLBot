# 保存规则

新增：查重(productCode+fundingPartyMark 唯一，重复抛错)→insert 主行(rule_status=PENDING, version=1, code=uuid)。更新：主行 version+1（不新建）。公共：按 frontKey 匹配 funding_rule_front_cfg 批量 upsert 明细——已存在(ruleInfoId+ruleKey+enable=Y)更新值否则新建；版本快照 version=主行当前版本；fund_rule_code_ref=主行 code。ruleMap 中的未知 frontKey 跳过不中断。

```ground:process
process: 保存规则
stages:
- stage: 保存规则
  trigger: 管理端 /fund-web/ruleInfo/saveOrUpdateRuleInfo
  effects:
  - op: upsert
    table: funding_rule_info
    fields:
    - funding_party_mark
    - product_code
    - rule_status
    - version
  - op: upsert
    table: funding_rule_detail
    fields:
    - rule_info_id
    - rule_key
    - rule_value
    - rule_layer
    - version
  transitions: []
```
