# 更新租户运营配置

按列 UpdateWrapper 写 default_project_id、project_code_required 等 15 个运营字段；字符串空串转 NULL；旧值归档 op_update_time/op_update_user（不动 update_by/update_time）；事务后清对接系统元数据缓存 + TENANT_SYNC 推送。project_code_required=Y 时 default_project_id 必填；导入时默认项目仅原值为空才写。

```ground:process
process: 更新租户运营配置
stages:
- stage: 更新租户运营配置
  trigger: 管理端 /setting/updateOperationConfigById 或 Excel 导入
  effects:
  - op: update
    table: tenant_setting_config
    fields:
    - default_project_id
    - project_code_required
  transitions: []
```
