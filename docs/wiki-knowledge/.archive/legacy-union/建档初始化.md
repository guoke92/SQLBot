# 建档初始化

导入/注册/OpenAPI 建档入口创建企业主数据与联系人、角色、项目关系。 写值：cust_build_status=INIT、cust_status=ADD、identify_style 与 cust_build_type 按入口联动（AGW_BUILD→INVITE_AGW，PC_BUILD→INVITE/SELF）。

```ground:process
process: 建档初始化
stages:
- stage: 建档初始化
  trigger: 平台导入 / 用户自主注册 / OpenAPI 建档（independentReg/dependentReg）/ AMS 拉起
  effects:
  - op: insert
    table: cust_company_info
    fields:
    - code
    - name
    - certification_no
    - cust_build_type
    - identify_style
    - cust_build_status
    - cust_status
    - cust_company_type
    - data_type
    - main_data_id
  - op: insert
    table: cust_person_info
    fields:
    - code
    - ref_cust_company_info
    - cust_company_id
    - user_type
    - cust_build_status
    - status
    - company_type
    - main_data_id
  - op: insert
    table: cust_role_info
    fields:
    - code
    - ref_cust_company_info
    - status
  - op: insert
    table: cust_project_rel
    fields:
    - code
    - ref_cust_project_rel_cust_company_info
    - project_id
    - product_id
    - company_type
    - status
    - show_flag
  transitions: []
```
