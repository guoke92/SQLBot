# 企业查询即开通

查询即开通：企业查产品列表时对每个租户互通产品调 activeProduct——(1) 已 OPENED 幂等返回；(2) scopeRole 非空且不含当前企业类型 return null（不开通不展示）；(3) 远程拉统一授权 AgreeAuthorization，授权通过即 insert open_status=OPENED + ref_cust_interworking_product_cust_company_info=company.code + open_time；(4) 授权不通过 return null（前端展示 OPENING）。异常吞掉只记日志。

```ground:process
process: 企业查询即开通
stages:
- stage: 企业查询即开通
  trigger: 企业端产品列表查询（副作用式）
  effects:
  - op: insert
    table: cust_interworking_product
    fields:
    - cust_id
    - product_id
    - open_status
    - open_time
  transitions: []
```
