# 推送运营中台审核

建档数据推送运营中台（写 cust_build_record 含中台返回 id）；推送异常时 cust_build_status 回滚 INIT。

```ground:process
process: 推送运营中台审核
stages:
- stage: 推送运营中台审核
  trigger: build-init 完成（异步 afterCommit）
  effects:
  - op: insert
    table: cust_build_record
    fields:
    - cust_id
    - person_id
    - plat_cust_id
    - plat_person_id
    - channel
    - return_data
  - op: update
    table: cust_company_info
    fields:
    - check_status
  transitions: []
```
