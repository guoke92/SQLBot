# 待重试同步失败

失败记录 enable=Y 且 create_time 满足扫描时间条件；retry_num 用于失败次数上限判断。

```ground:caliber
caliber: 待重试同步失败
field_targets:
- client_api_sync_error.enable
- client_api_sync_error.create_time
- client_api_sync_error.retry_num
filters:
- .sync_error.enable = 'Y'
- .sync_error.create_time lte '<now+intervalSecond>'
```
