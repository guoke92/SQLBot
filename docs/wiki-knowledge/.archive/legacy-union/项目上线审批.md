# 项目上线审批

租户项目上线前的审批单，一行一张审批单，wf_status 描述工作流状态。

## 取值
- `PENDING` = 待发起
- `RUNNING` = 审批中
- `FINISHED` = 审批通过
- `TERMINATED` = 审批拒绝
