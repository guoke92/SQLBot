# 银行账户小额打款认证

三步状态机：申请（APPLY_10，payment_remaining_count-1，trans_id/trace_no 写入；次数为 0 拒绝）→ 银行查询（外部 status '10'/'20'/'30' → APPLY_10/20/30）→ 验证确认（result=0→APPLY_40 成功；result=1/2→APPLY_40 且 error_try_count+1+error_try_time=now；前置 APPLY_10/30 时拦截不能验证）。申请次数由 cust_setting_config.payment_maximum_number 重置。

```ground:process
process: 银行账户小额打款认证
stages:
- stage: 银行账户小额打款认证
  trigger: 企业端小额打款认证流
  effects:
  - op: update
    table: cust_account_info
    fields:
    - auth_state
    - trans_id
    - trace_no
    - payment_remaining_count
    - error_try_count
    - error_try_time
  transitions: []
```
