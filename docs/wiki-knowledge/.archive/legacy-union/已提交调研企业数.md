# 已提交调研企业数

指定 survey_code 下存在答案记录的去重 company_id 数；提交服务以此存在性作为幂等判断。

```ground:metric
metric: 已提交调研企业数
field: cust_survey_answer.company_id
grain:
- cust_survey_answer.survey_code
- cust_survey_answer.company_id
aggregation: COUNT_DISTINCT
```
