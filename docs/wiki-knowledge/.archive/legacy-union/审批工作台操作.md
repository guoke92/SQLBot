# 审批工作台操作

同意/驳回/退回/转审（锁 project_approval:node:{approvalId}）：事务内 INSERT flow_node 操作流水（操作人/意见/时间/是否低风险），法务经办节点同步主表 is_low_risk， 业务经理节点落 flow_credit；事务外调引擎，引擎异步回调收敛状态。业务系统在 RUNNING + 方案经理/方案配置节点 APPROVING 时可推 business_info。

```ground:process
process: 审批工作台操作
stages:
- stage: 审批工作台操作
  trigger: 审批人在工作台操作
  effects:
  - op: insert
    table: tenant_project_approval_flow_node
    fields:
    - node_code
    - node_order
    - operate_type
    - approval_type
    - approve_comment
    - operator_user_id
    - operator_user_name
    - operate_time
    - is_low_risk
    - is_back_agreement
  - op: update
    table: tenant_project_approval
    fields:
    - is_low_risk
  - op: upsert
    table: tenant_project_approval_business_info
    fields:
    - product_code
    - source_system
    - attachment_json
    - ref_tenant_project_approval_business_info_project_approval
  transitions: []
```
