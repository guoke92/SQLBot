# 关闭审核配置

客户配置明确将对应审核开关设为 no 时，服务跳过该审核。

```ground:caliber
caliber: 关闭审核配置
field_targets:
- cust_setting_config.need_auth_verify
- cust_setting_config.need_verify_no_key
filters:
- .cust_setting.need_auth_verify = False
- .cust_setting.need_verify_no_key = False
```
