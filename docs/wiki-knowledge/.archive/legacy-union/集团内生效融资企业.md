# 集团内生效融资企业

以集团根企业筛选 cust_group_rel 成员（含根企业自身），角色包含 CORE，再通过项目关联筛选 FINANCE 企业，并要求企业 BUILD_SUCCESS、EFFECT、data_type='1'、enable='Y'。

```ground:caliber
caliber: 集团内生效融资企业
field_targets:
- cust_group_rel.root_cust_id
- cust_group_rel.enable
- cust_group_rel.cust_type
- cust_company_info.cust_build_status
- cust_company_info.cust_status
- cust_company_info.data_type
- cust_company_info.enable
filters:
- .group_rel.root_cust_id = '<groupCustId>'
- .group_rel.enable = 'Y'
- .group_rel.cust_type like 'CORE'
- .company.cust_build_status = 'BUILD_SUCCESS'
- .company.cust_status = 'EFFECT'
- .company.data_type = '1'
- .company.enable = 'Y'
```
