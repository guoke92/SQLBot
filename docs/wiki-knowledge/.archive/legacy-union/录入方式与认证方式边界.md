# 录入方式与认证方式边界

identify_style 回答"企业由谁邀请/何种模式认证"（认证产品维度：INVITE 邀请-客户录入/ INVITE_AGW 邀请-内管录入/SIMPLE 简易/SELF 自主注册）；cust_build_type 回答"从哪个 操作端录入建档"（PC_BUILD 客户端 / AGW_BUILD 内管平台端）。固定联动：AGW_BUILD→INVITE_AGW、 PC_BUILD→INVITE 或 SELF。用户说"平台录入/内管录入"指 cust_build_type=AGW_BUILD； 说"平台邀请认证"指 identify_style=INVITE。两者混用会得到完全不同的企业集合。
