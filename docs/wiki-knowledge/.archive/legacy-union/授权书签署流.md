# 授权书签署流

建档流程启动建 authed_status=N 行（creation_type 标来源）→ 审批通过回调 pass 置 Y（管理员维度；非管理员置 N+异常备注）→ 管理员变更时旧管理员全部授权 enable=N+authed_status=N、新管理员新建行 Y。已签署判定：platform_product_code=PLATFORM AND authed_status='Y' 存在；外部推送企业（PLATFORM_PUSH）恒真豁免。

```ground:process
    - authed_status
  transitions: []
```
