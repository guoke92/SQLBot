# 整单状态与节点状态两级边界

wf_status 是引擎视角整单状态（仅 RUNNING/终态由引擎回调写）；flow.node_status 是 节点视角。"审批通过"整单=wf_status=FINISHED、节点=node_status=APPROVED； reject 与 back 在流程结束通知时都落整单 TERMINATED+节点 REJECTED。
