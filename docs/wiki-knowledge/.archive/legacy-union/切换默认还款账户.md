# 切换默认还款账户

先把现默认（default_account_flag=1）置 0，再把目标账户置 1（两步非原子）；首账户保存时若无默认则自动置默认。

```ground:process
process: 切换默认还款账户
stages:
- stage: 切换默认还款账户
  trigger: 企业端设置默认账户 / 账户保存 afterSave
  effects:
  - op: update
    table: cust_account_info
    fields:
    - default_account_flag
  transitions: []
```
