# 产品开通

签署事件触发或自动开通：已有 OPENED 幂等返回；新建写 ref_cust_company_info=code、ref_cust_auth_application_tenant_product=tenant_product.code、open_status=OPENED、open_time=now、main_data_id=company.id；并发插入靠 DuplicateKeyException 吞掉。initProduct 在签署前预置 OPENING（待客户确认）。

```ground:process
process: 产品开通
stages:
- stage: 产品开通
  trigger: 签署事件 / 自动开通 / initProduct 初始化
  effects:
  - op: upsert
    table: cust_auth_application
    fields:
    - ref_cust_company_info
    - ref_cust_auth_application_tenant_product
    - open_status
    - open_time
  transitions: []
```
