# 问卷星答卷不在本地

问卷星活动的答卷数据在外部 open.wenjuan.com（get_rspd_list，source=String(companyId)、 respondent_status=1 为有效已答）；cust_company_survey_state 不存完成态。 "问卷星已答企业"本地库查不到，需实时调外部 API。
