# 平台产品生效

新建平台产品默认 product_status='0' 待生效（TO_BE_EFFECTIVE），人工提交 effective 后置 '1'（EFFECTIVE，单向）；列表只取已生效。

```ground:process
process: 平台产品生效
stages:
- stage: 平台产品生效
  trigger: 管理端 /platformProduct/effective
  effects:
  - op: update
    table: platform_product
    fields:
    - product_status
  transitions: []
```
