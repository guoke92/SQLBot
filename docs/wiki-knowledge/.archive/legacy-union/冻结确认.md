# 冻结确认

两步式：先预生成草稿（type=FRZ、enable=N），确认时 enable=Y 落 reason/attach， 同时企业 cust_status=FREEZE 并冻结该企业全部用户。

```ground:process
process: 冻结确认
stages:
- stage: 冻结确认
  trigger: 管理端冻结操作确认
  effects:
  - op: insert
    table: cust_company_lifecycle_info
    fields:
    - company_id
    - type
    - reason
    - attach
    - enable
  - op: update
    table: cust_company_info
    fields:
    - cust_status
  transitions: []
```
