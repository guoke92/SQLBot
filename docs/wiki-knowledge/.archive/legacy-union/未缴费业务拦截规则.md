# 未缴费业务拦截规则

needPay=true 且项目 block_scene_list 含当前场景才拦截；四场景=门户进入业务系统+ 融资申请+确权+转让签收；空列表不拦截。多项目时任一项目豁免（白名单/延期/在期） 即全局放行。拦截对象判定按统码下全部企业行的 SUPPLIER/CORE 角色。
