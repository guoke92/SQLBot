# 规则版本快照

funding_rule_info.version 每次更新 +1；funding_rule_detail.version 记录主行当前版本——同一 ruleKey 的新版本行覆盖旧行值（upsert 同一行），不是追加历史。fund_rule_code_ref 指向主行 code，跨表明绑。
