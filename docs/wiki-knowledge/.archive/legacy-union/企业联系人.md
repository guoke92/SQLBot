# 企业联系人

企业下的联系人账号。状态 ADD/EFFECT/WRITEOFF；类型 accountAdmin/accountNormal/accountGuest。

## 取值
- `ADD` = 新增
- `EFFECT` = 生效
- `WRITEOFF` = 注销
- `accountAdmin` = 管理员
- `accountNormal` = 经办人
- `accountGuest` = 游客
