# 创建审批草稿

新增项目（is_add=Y）且挡板开、产品支持时自动建 PENDING 草稿（is_latest=Y）； 历史项目走向导补建。审批编号 SX+日期+序号。

```ground:process
process: 创建审批草稿
stages:
- stage: 创建审批草稿
  trigger: 新增项目 / 历史项目向导
  effects:
  - op: insert
    table: tenant_project_approval
    fields:
    - approval_no
    - wf_status
    - is_latest
    - is_add
    - enable
    - ref_tenant_project_approval_tenant_project
  transitions: []
```
