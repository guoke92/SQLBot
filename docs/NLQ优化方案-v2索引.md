## v2.1 相对 v2 的补强（决议级）

1. **进卡必须有有效推荐**（否则删题/补全，禁止无推荐题）。  
2. **不可判定的执行前契约差 → 不 pause**（只 warn/降分/repair 耗尽后失败）。  
3. **`outcome.explain` 固定字段合同**（口径、假设、缺口、完成度）。  
4. **无澄清 UI**：全推荐则服务端采用推荐；否则 failed「需要交互确认」。  
5. 自定义后再评估 **不得**扩大第 1 类题；暂停默认 **24h** 过期。
